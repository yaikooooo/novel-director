# 公共声线库

这里存放本机跨项目共用的声线参考。GitHub 只维护本说明和[空白索引模板](声线索引.example.json)，实际 `声线索引.json` 与 `样音/` 不上传，也不随克隆下载。现有本地库继续使用，不覆盖原件；在新机器恢复时，同时复制自己的索引和它引用的样音。

在共用[导演阅读器的声线库](http://127.0.0.1:4318/voices)中搜索、筛选和试听。服务未启动时，运行工作区根目录的 `启动分镜档案.cmd`，再点击“声线库”。首次建库可将 `声线索引.example.json` 复制为 `声线索引.json`，按下方规则添加样音；空白库不是可供03选用的声音资产。

## 数据与标签

- [声线索引.json](声线索引.json)是唯一维护的声线台账；`样音/来源/声线ID/v1.wav`保存原始音频，不重编码。
- `voice_id`为本库稳定编号；`version`为声线记录版本；每个样音另有`sample_id`、版本、相对路径和SHA-256。显示名、标签可修正，已被角色引用的ID和样音版本不更换含义。
- 标签分为语言、声音性别呈现、年龄或听感、口音、音色类别与表演特点。继承来源标签时保留`tag_basis`及原始标签；未实际听审时如实标记，不把音高推算当作年龄或人物身份的证明。
- `source`保存来源、作者或说话人、模型标题、原许可备注、原下载位置及标签来源；签名下载链接移除已失效的访问参数。许可备注是原台账记录，本次未重新核验。公共资源表示项目间共用位置，不表示所有样音都具有相同的使用许可。
- 未试听的记录将`review.status`标为“待试听”。来源语言标签冲突时标为“待核实”并保留两份原值；短于5秒的样音单独标记。入库不等于已经确认适合某个角色。
- `samples[].technical`的时长、采样率、声道和位深由本地WAV读取；旧质量评分与音高仅保留在`legacy_measurements`，不当作本轮听审结果。

这些文件是声线参考样音，不是已安装的TTS模型。内部`voice_id`不能直接作为平台模型参数；已知的平台模型ID单列于`provider_reference`，实际生成时再按所用工具匹配。

## 扩充库

1. 先查索引中的来源说话人／模型ID与样音SHA-256，避免同一声线重复建档。同一声线的新台词或情绪样本，加入原记录的`samples`。
2. 新声线采用唯一、稳定的`VOICE-来源-编号`；将原件放入`样音/来源/声线ID/`，只保留有效样本。原件更换时另设版本，不覆盖已被项目引用的旧样本。
3. 在索引`voices`数组追加记录。沿用现有记录字段：`voice_id`、`version`、`display_name`、`collection`、`labels`、`tags`、`tag_basis`、`review`、`samples`、`source`、`provider_reference`。未知标签明确写“未标注”，不要凭姓名猜年龄、性别或口音。
4. 样音必须填写`sample_id`、`version`、相对`path`、`sha256`、`bytes`与实际技术参数；台词没有可靠来源时留空，并标“未提供”。来源记录只填已知事实。路径以索引所在目录为基准，不引用临时目录。
5. 更新`updated_at`和`summary`计数；本地试听后，才把对应记录改为“已试听”并记录试听结论及日期。公共库的试听状态和项目角色的采用状态分开维护。
6. 在工作区运行一次 `node 前端/导演阅读器/check-voices.mjs`，然后在声线库页刷新，查看新增条目并试听代表样本。校验只核数据、文件和哈希，不判断声线是否好听、适配或拥有特定使用权。

索引是最终数据；下载搜索日志、候选淘汰记录、缓存、分析过程和一次性脚本不复制进此库。

## 以后为角色配置

03先查项目资产库，已有该角色已确认声线时直接复用，不重复询问。首次选配或更换声线时，结合角色成图、性格、身份、语言口音和说话习惯查本库，试听并推荐一条候选，提供可播放样音和一句匹配说明，请用户明确是否采用。确认前记“候选，待用户确认”；确认后将实际样音原样复制到项目资产库内的角色包 `声线/`，绑定本剧角色ID并登记项目路径，按[03声线规则](../../.agents/skills/novel-director-03/SKILL.md#主声线由03推荐用户听样确认后绑定)交接。公共库的“已试听”不等于用户批准用于该角色；已有绑定却无确认依据的声线同样须提审。角色包中的`声线配置`记录声线与样音ID、版本、项目内相对路径、公共库来源、匹配理由、语言口音、音色、语速、气息、表演方向、试听及采用状态、确认依据和日期。后续章节和平台均用项目副本；公共库保留原件，更新不覆盖项目已采用版本。对白、OS、呼吸及笑声沿用同一声音身份，情绪变化不换人。

项目角色包维护绑定，公共库不带入某部作品的身份、经历或伤损。角色的外观、服装变化不会自动更换声线；需更换时保留旧章节的引用版本。没有合适声线则明确列缺口，不擅自生成或拼凑新声线。
