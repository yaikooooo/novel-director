# 导演阅读器数据约定

本文件、contract.mjs 和[示例JSON](示例/05_拍摄设计.json)共同定义当前唯一的阅读接口。示例与真实章节由同一套 public/app.js 渲染。

## 制作和阅读

1. 在 项目/作品/章节/章节名/ 维护 05_拍摄设计.json、阶段文稿与素材原件。
2. 从示例JSON取字段结构，替换作品、剧情、时码、路径与实际状态。
3. 打开根目录“启动分镜档案.cmd”。示例入口为 http://127.0.0.1:4318/example，上方“作品与章节”切换真实章节。
4. 更新数据后点“刷新数据”，读取当前章节原件。章节目录无需生成HTML。
5. 交付前执行一次下面的命令，集中处理输出问题，再在阅读器查看本次新增或更改的代表镜头。

    node 前端/导演阅读器/check.mjs "项目/作品/章节/章节名"

正式程序位于 前端/导演阅读器/。示例目录属于软件模板，作品数据存放在 项目/。

## 唯一数据来源与版本

05_拍摄设计.json 的 schema_version 为4。顶层保留 data_revision、design_revision、design_status、design；07 执行后增加 motion_design。

- 有效数据改变时递增 data_revision。
- 已采用的设计改变时递增 design_revision。
- design_status 使用 working、review_ready 或 approved，依据实际审定记录填写。
- 阅读器保留完整设计对象，正文展示主要字段，折叠区提供完整记录。生成提示词和参考原件在“状态”中读取。
- motion_design 记录 07 的运镜提示词及其依据版本。页面只读当前共用 JSON 和对应原件。

## 05 必须提供的结构

| 路径 | 格式与用途 |
|---|---|
| design.project.title / chapter | 作品与章节名称。 |
| project.fps | 例如 {"num":24,"den":1}。实际帧率为分子除分母。 |
| project.frame_range | [首帧,末帧]，全局帧从1开始，首末均计入。 |
| project.resolution_px / aspect_ratio | 例如 [1920,1080] 与 16:9。 |
| design.shot_order | 当前剪辑顺序中的稳定镜号。 |
| design.shot_groups | 以组号为键，至少含 shot_ids 和 intent，可含观看立场、信息变化、连续状态。 |
| design.scenes | 以场号为键，登记场地、计划示意、轴线、地标和资产引用。 |
| design.shots | 以镜号为键，登记以下每镜内容。 |
| design.sound_timeline | 以声音ID为键，保存完整原词、声源和全局时段。 |
| design.review.plan | 本步已有检查与采用记录。 |

05 每镜提供 kind、group_ref、scene_ref、frame_range、intent、composition（含代表景别 scale_in）、blocking、edit 和 design_frames。camera 可省略；06 如需说明，用它记录代表时刻的静态视点。使用项目拍摄数据约定中这些字段的既有含义。

kind 使用 camera 或 black。各段按全局帧连续排列，单段最多3秒。需要重叠时通过 edit.overlap_frames 显式记录。

每个摄影镜头的 design_frames 只有一项。该项的 display_frame_range 覆盖整镜，representative_frame 位于本镜内。05 定剪辑接点，06 按原图标动作与视线，07 按提示词设计补相机箭头或固定说明。

黑场用 kind=black，按帧段显示纯黑，design_frames 可为空。

## 06 正式分镜、原页与格位

| 字段 | 格式与用途 |
|---|---|
| board_sheets[页号].image_ref | 相对章节目录的原页路径。 |
| width_px / height_px | 原页实际宽高。 |
| group_refs / frame_ids | 原页所含镜组和图号，须与每幅的引用一致。 |
| status / observation / generation | 页级观察、采用输入和实际参考。 |
| design_frames[].id | 稳定图号，示例为 S001-F01。 |
| sheet_ref / panel_id | 原页ID及格位ID。 |
| panel_region | [x,y,width,height]，以原图左上为原点的实际像素。 |
| design_frames[].board_art | 06 彩色正式净图的章节相对路径。多格页按实际 panel_region 无损裁出，单格整页可直接引用 image_ref。05 初排和旧版手稿可省略。 |
| raw_panel_region | 可选，原页格框。采用视口须位于此框内部。 |
| status / observation | 实际生成状态和逐幅观察。 |
| annotations | 阅读器叠加的箭头与说明，具体结构见下节。 |

逐镜画面由同一原页的 panel_region 定位，等比显示。原页模式按真实原图比例显示，并允许点击画格进入对应镜头。“正式分镜”从 06 直接读 board_art。

observation.status 是该幅采用判断，优先于生成状态 status。采用状态不直接推导用户审定。

| 状态 | 页面行为 |
|---|---|
| adopted | 标记为采用。 |
| needs_revision | 显示待修及具体观察，原图仍可阅读。 |
| generated | 已生成、待采用。 |
| required_not_generated | 显示画面需求和时码。 |
| blocked | 显示受阻和已有说明。 |

未生成时省略 sheet_ref 与格位，保留图号、代表帧、显示时段和需求。生成后补入实际路径和测量格位。

## 箭头与短说明

位置以本幅 panel_region 为基准，左上为 [0,0]，右下为 [1,1]。

    {
      "annotations": [
        {
          "kind": "action",
          "points": [[0.65,0.26],[0.44,0.26]],
          "label_at": [0.07,0.13],
          "label": "视线先转，手停在书页"
        },
        {
          "kind": "camera",
          "points": [[0.08,0.82],[0.27,0.82]],
          "label_at": [0.05,0.74],
          "label": "慢移向前，保留门与人物"
        }
      ]
    }

action 显示动作实线箭头，camera 显示机位虚线箭头，note 只显示短说明。points 可用多个点描述弯折路径，label_at 定位说明文字。原页和逐镜共用这组标注。06 阶段只填 action 及相关 note。07 将采用的 camera 箭头或固定 note 补进同一 annotations 列表，填写 author_step="07"。箭头是独立显示层，原图沿用。

## 声音与机位

声音本体保存在 design.sound_timeline[声音ID]。至少提供 kind、source、text 和 frame_range。说话人和原词完整保留，声源变化、重音帧、听点与衔接按已有字段展开。

每镜 sound_cues 通过 cue_ref 引用声音，active_frame_range 为本镜内有效区间，用 continues_from_previous 和 continues_to_next 表达跨切延续。

空间图用 scenes[场号].plan_ref 引用 04 场地图。05 阶段可省略此项。若一张SVG含多个镜组，再写 plan_size=[宽,高] 和 plan_regions，例如 {"G01":[0,0,900,620]}。坐标使用SVG自身viewBox单位。页面据本镜组取对应区域。省略分区时显示完整图。

## 07 运镜提示词

`motion_design` 保存运镜设计，逐镜以稳定镜号关联正式图。镜长、代表时刻和净图路径读取 `design.shots[镜号]`，与 05／06 共用同一来源。

```json
{
  "motion_design": {
    "source_design_revision": 1,
    "status": "working",
    "shots": {
      "S001": {
        "frame_id": "S001-F01",
        "intent": "让门外脚步打断观众对室内的观察。",
        "prompt": "3秒。起幅用远景同时看见左侧房门与右侧桌边的人，右窗光照着书页。前段保持参考图的空间关系，约1.46秒仍处于正式图构图。约2.5秒门外传来脚步，摄影机才朝门的方向横移，把门在画面中的分量加重，桌边的人仍在右侧。刚建立向门的动势便切到人物中景，脚步延续。"
      }
    },
    "review": {
      "scope": "本轮已完成镜头的纸面与图像推演",
      "findings": []
    }
  }
}
```

- `status` 使用 working、review_ready、approved，确认依据另记实际授权或用户反馈。
- `source_design_revision` 对应当前 `design_revision`。05／06 设计变更后，提示词需同步；只改提示词递增 `data_revision`。
- `shots[镜号]` 包含 `frame_id`、一句 `intent` 和可直接复制的完整 `prompt`。每镜对应唯一正式图。黑场沿剪辑时码处理。
- 整章交付覆盖全部摄影镜头；局部委托增加 `shot_ids` 列出本次范围。working 可保留尚未写完的镜号，review_ready／approved 覆盖所声明范围。
- 提示词中说明参考图落在开头、途中还是结尾，时间位置与既有代表帧一致。起幅、触发、运动过程、落幅和跨切承接由 07 设计。
- `review` 集中记录本轮纸面与图像推演范围、结论和待办。阅读器的“运镜提示词”页可逐镜阅读和复制；“状态”保留已有检查。
- `07_运镜提示词.md` 从同一 JSON 导出，列镜号、镜长、图号与图片链接、代表时刻、意图和提示词。修改后两者同步。

## 08 分段声画提示词

08 按 04 连续走戏的段落与银幕时长，读取 02 台词／OS、03 角色与声线、04 动作与声音、05 声画时序及 07 运镜，交付章节内的 `08_分段声画提示词.md`。每段包含时间与镜号范围、实际附图清单，以及以“不要背景音乐，不要字幕”和 `@图片` 说明开头的自然语言提示词；静态构图由分镜提供。

该文稿作为阶段文件在“章节文稿与原件”中读取，不新增 JSON 字段，不改变 `schema_version: 4`，不替代 `motion_design`。版本与范围来源记在文稿中；09 汇报按实际完成情况引用。

当前接口维护分镜设计（`design`）与运镜提示词（`motion_design`）。
