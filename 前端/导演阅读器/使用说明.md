# 导演阅读器

工作区只维护本目录这一套阅读器。示例与作品章节使用同一页面程序。

## 打开

双击工作区根目录“启动分镜档案.cmd”，默认打开示例。地址为 http://127.0.0.1:4318/example。

上方“作品与章节”选择实际作品。程序发现 项目/作品/章节/章节名/ 目录，按需读取其中的05_拍摄设计.json与阶段文稿。

关闭浏览器后阅读器服务仍在本机运行。双击根目录“停止分镜档案.cmd”可停止。

## 使用

- 左栏选择镜头，可按镜号、内容或台词搜索。
- “分镜图册”的“逐镜”从原页读取代表图，“原页”显示整张原图并可点击格位。
- “标注”切换 06 的动作／视线及 07 后补的运镜箭头和短说明，方向键翻阅，＋／−缩放。
- 右侧“拍法、运镜提示词、声音文字、机位、状态”读取本镜及其关联数据。
- “章节文稿与原件”阅读各步骤的Markdown及原始附件。
- 上方“刷新数据”重新读取磁盘中的当前原件。
- 06 交付后点“正式分镜”可单独看对应净图。07 交付后点右侧“运镜提示词”阅读并复制本镜完整提示词。
- 08 交付后，在“章节文稿与原件”打开 `08_分段声画提示词.md`，按 04 的连续段落阅读动作、台词、OS、声音及运镜的自然语言汇总；正文每次切镜就近引用该镜的单张正式图，附图清单对应镜号、`@图片` 和原件路径。

示例素材用于演示字段和界面。后续生产按[数据接口](数据接口.md)与[示例JSON](示例/05_拍摄设计.json)填写。

## 程序结构

- server.mjs 只读服务、资料路径与章节发现。
- public/ 唯一页面程序。
- contract.mjs 阅读器与制作校验共用的数据规则。
- check.mjs 制作交付前的一次结构校验。
- 示例/ 可直接运行的模板数据及界面示意素材。

需要本机Node.js，程序无第三方运行依赖。所有资料经本机回环地址提供。

GitHub 版本包含程序与通用示例，实际 `项目/`、公共声线索引和样音只保存在本机。新克隆可直接打开示例；将自己的作品备份放回 `项目/作品/章节/章节名/` 后刷新即可发现章节。完整同步范围见[目录说明](../../目录说明.md#git-同步范围)。
# 公共声线库

点击顶部“声线库”，或打开 `http://127.0.0.1:4318/voices`。按名称、标签、口音、样音台词或声线ID搜索，并按语言、声音、年龄听感、音色类别、来源筛选。点击条目试听，可复制声线ID、查看原件和来源。数据来自工作区 `公共资源/声线库/声线索引.json`，刷新即重新读取；页面不保存另一套声线数据。

库的扩充与角色绑定规则见[声线库说明](../../公共资源/声线库/使用说明.md)。修改库后运行一次 `node 前端/导演阅读器/check-voices.mjs`；该命令检查索引、样音路径、WAV参数和哈希。角色选择仍由03资产步骤确认，本页只提供筛选试听。
