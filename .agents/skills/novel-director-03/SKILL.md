# 03｜资产检查与新增

02 导演台本确认后调用，资产审定后进入 04 声画走戏。输入用已确认的台本或单测给定的“角色／地点、场次、正在做什么、当前状态”。本步按场次和动作定位，05 设计镜组与剪辑，06 绘制彩色正式分镜并反馈构图，二者共同定稿后确定正式镜号。

## 先打开库里的候选原件

按[主 Agent 的目录约定](../../../AGENTS.md)确定当前项目根，从输入取得最低限度的需求，先查该项目 `资产库/资产索引.md`，依次找同剧角色、可跨剧选用的演员外观、该角色衣橱和已有状态。跨项目候选仅来自用户指定或明确可共用的库，不自动扫描其他作品。按名称、别称和辨识点打开实际原件，同时确认可用范围与版本。索引不存在或无记录时，按同一范围查当前项目已有的角色包或用户指定的库，确认确实无合适原件才判缺。待清理旧项目不作默认来源。

**先认人，再看穿着。** 先对体态与身形比例、脸型与五官辨识点、基准发型及发际轮廓。再对这场穿哪套、是否受伤或有临时变化。演员外观 ID 管稳定外形，本剧角色 ID 管身份与声线，造型／状态 ID 挂回同一角色和母本。

| 查库结果 | 本步动作 | 还要读什么 |
|---|---|---|
| 核心外形、本场造型和状态都符合 | 直接引用已审 ID 和原件，登记本场使用；完整角色建档或补齐资产时，同时检查主声线，缺失则按下节选配。 | 已有角色资料足够时，不重读剧本或索要新参考；完成本次范围内的角色与声线引用后交付。 |
| 人物符合，本场要换工作装、私服或其他搭配 | 先选衣橱里已审的整套。确实缺这套，只基于同一人补服装变体。 | 用台本的任务、场合与换装机会作判断。若缺条件，只查对应场次和上次离场。 |
| 人物符合，本场受伤、污损、包扎、发式临时改变或姿态跛行 | 先查已有状态。命中即用，缺时记部位、左右、轻重及起止，确需画面原件才做同一母本的状态变体。 | 必要时只核对发生变化以及延续到本场的片段。 |
| 本剧还未选角，库里有核心外形相符且可跨剧复用的演员 | 交候选原件与匹配点给用户选角，确认后绑定本剧角色 ID。默认搭配和现场服装优先从已有衣橱取。 | 已给的角色要求足够就用它选。不可把上一部剧的人物经历和伤损带入。 |
| 没有合适的核心外形，或候选与剧本长期身份确有实质冲突、无法据现有设定裁定 | 先锁定缺的是哪项稳定特征，再进入下节研读与新设计。已定角色遇到有剧情依据的年龄阶段或长期外形变化，保留角色 ID，按需补阶段版本。 | 此时才扩展阅读，不因一件衣服或一道伤重新选人。 |

默认造型是通常用来认回角色的基准外观与整套搭配。当场造型由戏内时间和行动决定。同一身份在执勤和休息时可以穿不同套装，若连续从上一场跑到街上，就沿用离场时那套。

## 只有核心外形待定时，才扩展研读和定型

处理第一章的新角色，也可向后读约 **10–20 章**。从中段开始时兼顾首次出场、最近状态和后续重要戏份。先按姓名、别称和角色关系定位，再实际读影响设计的场景，判断长期身份、年龄阶段、叙事份量、反复出现的任务和角色如何变化。按证据回看库中候选，仍无合适者才新增演员外观。章节不足就注明实际范围，把影响永久定型的缺口集中提出。

在角色包里维护一张简短设计卡，写实际章节与两三条依据、角色在剧中的定位、要锁定的体态／脸型／基准发型、默认服装的轮廓层次与材质、哪些稳定特征必须跨镜认回、本场易混淆什么。只把当前剧情允许观众知道的标志画入当场版本。未来揭晓的身份、伤损和服装不能提前出镜。

## 美术风格由用户定

先查库。纯复用且符合本剧已定画风的原件直接引用。新画资产或跨剧借用画法时，按以下两条路径确定本剧风格。

- **用户给了风格参考图**　按指定原图制作，记录路径和适用范围，实际生图时附图。同一剧已确认且仍适用的依据直接沿用，多图用途不清或互相冲突时集中问一次。
- **没有适用的风格图或已确认画风**　先用简短文字给用户可选方向，说明线条、色彩和明暗处理的区别，等用户明确选定再画。如果用户已明确指定文字画风，可按它制作一张本就需要的代表性母本送审。用户认可这张的画法后，记录为本剧的风格样张，后续直接引用。

在本章引用表表头登记本剧的风格依据（用户原图，或用户确认的方向及样张）。画风与定脸、服装、场景参考分别标明用途。用户要求照某人或某件实物设计时，缺对应参考就报缺等待。已定身份的变体沿用母本，未经确认的网图或模型自生图不能替代用户参考。

新建或修改视觉资产统一用 Codex 原生 `imagegen` 的内置 `image_gen`，有用户参考图时必须实附原图。纯文字定风格的首张用已确认描述，后续实附认可的风格样张。变体另附已定身份和原造型。新人物先做能认清脸部与全身比例、穿着的身份／默认造型母本；形象完成后按下节选配一条主声线，连同设计卡和样音一起提审，确认后才派生必要变体。将已确认的风格样张及本场资产原图交 [06 彩色正式分镜](../novel-director-06/SKILL.md) 随镜组实附。

## 角色形象完成后，必须选配一条主声线

为角色制作或补齐完整资产包时，声线选配是必做项，不等用户另外提出。先完成角色形象母本与设计卡，再实际查看成图，结合年龄感、体态、面相与气质，以及剧本中的性格、身份、语言口音和说话习惯，确定声音应有的音色、音区、语速、气息与表演方向。外形与声音需要反差时，应有角色或剧情依据并写明理由，不能只凭男女标签随便配一个声音。已有已定声线则沿用；仅修改服装或临时状态时不重选。

声线缺失时先查[公共声线库说明](../../../公共资源/声线库/使用说明.md)与[声线索引](../../../公共资源/声线库/声线索引.json)，筛选并打开实际样音试听，选出一条最匹配的主声线。角色包同时附上样音和简短匹配理由，说明声音怎样对应成图与人物性格。来源标签、实际试听与用户审定分别记录；未实际听过不能写成“已试听”，语言冲突、短样音和来源许可备注随样本保留。

默认由执行者完成这一条主声线的选择，作为角色资产方案一起交付，不常规列出多个候选后停下等用户代选。采用状态写“制作方案选定”或如实记录已有授权；用户确认后再标为“用户已审”，不混淆选择与审定。确无适配样本、关键语言信息冲突或已有指定声线不可用时，集中说明具体缺口，不把音色形容词当作已配置，也不因补声线自动生成整章配音。用户只要求建公共库时，在公共库交付后停，不给当前项目角色预绑定。

在本剧角色设计卡的“声线配置”中维护：`voice_id`及记录版本、`sample_id`及样音版本、公共索引／音频的相对路径、与角色形象及性格的匹配理由、语言口音、音色、语速、气息、表演方向、试听状态、采用状态、依据与日期。公共声线库只管可选声线，角色ID绑定本剧身份；对白、角色OS、呼吸和笑声沿用该角色同一声线身份。新增情绪样音挂回原声线，换角保留旧章节所用版本。在本章资产引用表中登记选定的声线ID、样本及实际采用状态，未定项集中提审，不伪造“用户已确认”。

场景、区域和关键道具也先查库，格局和物件合用便直接引用。已有场景的日夜、陈设状态、已有道具的磨损都优先复用或补变体。新区域沿用方位与出入口，给会影响走戏的尺度和接触点。只新增本章确实要用的原件，让陈设、光区与材料服务 01 的基调和 02 的拍法。

## 入库与停止点

只把用户确认的原件登记为可复用资产。新原件进入项目资产库，现有原件只链接，保留已完成章节引用的版本与路径。本步交 `03_章节资产引用表.md`，已有指定引用表就沿用。表头登记本剧风格依据，正文记录“场次／动作｜剧内角色或地点｜已定外观、造型／状态或区域 ID｜原件版本与路径｜入场承接”。只写已定资产和场次、状态入场信息，不猜实际出镜或章末状态；缺项集中列入提审说明。

08 从本表读取角色身份、当场造型与声线，汇入分段声画提示词；09 读取本表与实际成果生成 `章节交接.md`。两步均引用现有原件，不回写资产库或修改本准备表。03 不代写全章报告。

命中现有资产，且本次完整角色资产所需的主声线已配置后，交引用表停下。只有角色图而无主声线或明确缺口说明，不能把完整角色资产包标为完成。需选角、缺参考或需新定型时只做到当前提审点，说明影响的场次。用户审定后才进入 04。单测只处理指定角色、造型、场景或道具。
