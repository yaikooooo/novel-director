# 第一轮：基础拍法选型

先由原文与 01 确定观众体验，再用主参照导演的观看组织产生候选。以下是可以实际展开成画面的方案方向，选择依据是本段的人物行动、观众知情和转折。12个维度用于推演候选能否成立，交付保留选定方案。

本文件保留既定的设计与比较方法。表中的画面关系和下方推演例用于判断候选能否成立，不是02交付的画框布局。输出按[02交付写法](../SKILL.md#交付与自检)，用【剧本片段】接一段自然语言拍摄方案，不交推演过程、选择理由或具体摆法。

## 按剧情条件选拍法方案

| 本段需要的体验／成立条件 | 可采用的方案 | 展开成画面的关系 |
|---|---|---|
| 观众应先发现人物尚未知晓的事，现场容得下前后层次 | 同框提前知情 | 留一个尚不知情的人在近层，线索或变化出现在可读的远层；让人物继续原有行为，观众先在后景找到异常，人物随后察觉。由本段决定谁近谁远及显露触发。 |
| 观众应与人物一起寻找、误判或发现，现场存在遮挡或视线限制 | 受限观看与揭示 | 从该人物能接近的视点看，前景障碍只放出局部信息；沿其探看、声源或光区变化逐渐获得视野，直到关键事实完整可见。 |
| 危险已经明确，退路、距离或时间正在减少 | 威胁与退路同框 | 从能够同时读出威胁、行动者与可用空间的一侧组织画面；让逼近、退让或障碍进入实际挤掉余地，转折落在行动者失去选择或找到缺口的时刻。 |
| 要让观众经历突然改变的预期，事件前存在可建立的常态 | 固定预期后打断 | 先给一个可辨的关注对象、空位或稳定动作，让观众等它继续；在剧情触发处由事件闯入该关系，或以画外突声牵走注意，再让后果落入可见范围。 |
| 台词与真实态度、人物目的存在差别 | 行为承载潜台词 | 将暴露态度的操作、物件或身体接触放在注意中心，说话者仍在可读层次或画外；让动作先与话意发生矛盾，随后把注意交给对方的察觉和回应。 |
| 主导权、亲疏或保护关系发生变化，动作能改变站位 | 深度与遮挡中的关系转换 | 从双方有前后、隔断或空间份额差别的位置看；以靠近、退让、占位或让开，改变谁挡住谁、谁被孤立、谁占据观众注意中心。画面随关系的真实变化调整。 |
| 要交代规则、操作因果或新的场所 | 对象、操作与后果的可读关系 | 先让观众认出需要理解的对象及其参照，再把操作和后果连起来；范围由因果所需的对象决定，必要台词与演示同步，环境用能认回的地标和人物行动交代。 |
| 主观感知与客观现实的差别本身承担剧情 | 主观与客观对照 | 先选择观众进入谁的感知；触发时改变可见范围、空间关系、焦点或听点，退出时回到可以辨认的客观参照，使两种状态的差别可读。 |

这些方向可按本场条件变体或组合，也可从导演参照提出其他有效方案。候选之间比较的是观众获得信息和感受的方式；选定后把人物、物件、观看位置和触发填成当前戏的实际关系。段内策略转换发生在剧情转折处，各镜共同推进这一方案。

推演例：谈判者口头同意，却把合同慢慢收回。若采用“行为承载潜台词”，可以试想从桌沿侧面观看，合同和收纸的手在前景，说话者侧脸在后层；答应的话继续时，合同退出对方手边，注意落到对方伸到一半停住的手。比较时判断这种关系能否让观众先从动作发现拒绝，再等对方意识到。这是验证候选的一种假设，不把假设的视点与摆法交成已定画框。实际输出写法如下：

【谈判者说“可以”，却把合同慢慢收回。对方伸到一半的手停住了。】

这一段保持双人关系的拍法，摄影机稳着，谈话中的手部动作逐渐成为观看重点。答应的话还在继续时，注意已经跟着收回合同的动作转移，随后留在对方停住的反应上。

## 12个推演维度

| 维度 | 形成的拍法决定 |
|---|---|
| 观看立场 | 参与、观察、偷窥或人物主观；观众与人物谁先知道，立场何时改变。 |
| 信息显露与画外空间 | 哪些入画、局部可见或暂留画外；由什么动作或声点完成揭示。 |
| 构图与注意力 | 主体、前景、留白、画框边缘及前后景的主次，注意力怎样交接。 |
| 机位、景别与透视 | 比较观看位置、取景范围与远近大小关系如何形成空间感；采用方案说清尺度参照与效果，不把焦距名称当成透视决定。实际机位、裁切与画框由06沿04落定。 |
| 景深与焦点 | 比较近远同时清楚、只认清某层或焦点交接怎样改变知情；选定时写清哪些信息要同时可辨、哪些暂时不可辨及变化依据。06定代表时刻清晰范围并渲染，07细化动态焦点，不能只在内部推演中出现这一维。 |
| 场面调度与表演 | 站位、行动、台词、接触与视线怎样共同改变关系；选择同步、交叠或必要顺序，让话语触发行动变化。 |
| 运镜与画框变化 | 固定或运动的倾向，摄影机怎样响应人物与信息变化。 |
| 光影与色彩 | 在用户画风和叙事约束内比较并采用场级光影美学：主体怎样塑形，明暗与颜色怎样相互衬托，烟雾等空气层次怎样形成空间和情绪。光源合理及内容可辨只是条件，还要有明确的画面美感；冷、暗或有雾不自动等于灰片，也不强套蓝橙、逆光或高饱和。02将采用关系写入拍摄段，04落实现场光源、控光与光区，06在第二轮单张中落实既定光色，第三轮BANANA增强亮暗体块、质感和空气表现；不在02排具体灯位或逐镜受光面。 |
| 声音与声画关系 | 听点、环境声、动作及主观音效、台词／OS的层次、先后与画外提示；无背景配乐，只做文字设计。 |
| 时间与剪辑构想 | 行为与话语共用的时间、需要连续经历的内容、可省略的经过、必要等待与冲击的位置及衔接方式。 |
| 环境交代与场景衔接 | 结合前情判断要补什么环境信息，选择建立、空镜、过门或声画转场。 |
| 主观影像与特殊表现 | 回忆、梦境或感知异常的画面与声音规则，以及进入、退出的依据。 |

逐个候选推演这些维度的相互影响，选定能产生本段体验且现场可执行的方案。12个维度是设计方法，不是12个交付字段，也不授权02替后续步骤定实际画框或相机执行参数。交付用自然语言连贯描述采用的构图与运镜等拍摄方式，写法和边界沿用02正文。高阶资格另按[第二轮选型标准](高阶设计选型.md)判断。
