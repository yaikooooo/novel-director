# 01｜影片基调、节奏预算与逐段表达

流程与编号统一见[项目主Agent](../../../AGENTS.md)：01–04建立表达、台本、资产与连续走戏；05选剪辑方法、节奏和切点，06定逐镜景别、机位、透视、构图及景深，先画几何故事板再完成光影与正式渲染，07设计动态执行，08按04篇幅汇成声画提示词，09按需交接。每步可单测，连续委托按主Agent范围推进。接手旧编号时按内容及确认记录识别。

专业决定的责任与落点沿[分镜设计职责与交接](../novel-director-06/references/分镜设计职责与交接.md)。01只定观众接收的信息、情绪和预算；后文列举的镜头、光学或剪辑方法用于比较表达载体，具体拍法由02采用，逐镜画面与剪辑分别由06、05定案，不在01提前写成执行指令。

续作或复查已有章节时，先读该章的 `章节交接.md`，取得当前结论、最终文件入口、实际资产、连续状态和待办，再按问题打开所链接的原件。它是复查入口，不默认重新扫描全项目；文件缺失或与实际版本不符时注明缺口，不能把归档摘要当作画面已验证的证明。

**输入与单测**　输入本次原文与项目要求。片段单测可用用户给的前情，只对指定范围分配时间。交付一份《01 影片基调与表达决策表》。

只用当前项目或用户指定的测试材料，等价输入可直接代替上游稿。缺关键材料或需变更已确认的上游决定时，合并说明缺项或影响，停在本步。只维护本步交付，方法中的教学示例另行虚构。

## 送审稿怎么写

**表头一行**　先写全章主基调和具体的观众体验（跟着谁、起初担心什么、到哪一拍变成什么），再写总预算及来源（用户指定／项目已确认／本次估算）、共几件事。自行估算时可给合理区间，表内按一个目标数分配。同章旧测试的片长只有经用户指定才可沿用。

**正文只交这一张表**，按观众接收信息的顺序排列。一行是一件观众必须弄懂、亲历或带走的事。跨几个自然段讲同一件事可以合并。同一段里的规则和人物决定需要不同载体，就拆开。只是连续完成一个动作的几个细节，放在同一行的呈现栏。

| 必须交代的事 | 选定的呈现方式 | 要放大的观众情绪 | 呈现时注意什么 | 预算 |
|---|---|---|---|---|
| 写看完能复述的事实、选择或变化，一句 | 写观众具体先看／听什么，再发生什么。确定主载体，辅助声画只补主载体传不到的一层 | 写这一拍让人从什么感受转到什么感受，或期待什么结果 | 只留最影响执行的一点，如此刻须藏住什么、避免哪种误读。无需特别控制填“—” | 独占填秒数与占比。同步填“并入第 X 项” |

**每场的环境必须在这张表里找得到。** 首次进入地点、新区域或空间关系需要重建时，把“环境建立／重建”列为一项，放在本场入口。呈现栏用一两句写观众第一眼看见、第一声听见什么，从而认出地点或关键空间关系，并感到本场的基调。和人物动作同拍就标“并入第 X 项”，单独占画面才分秒数。熟地连续时，在本场第一个动作行标“环境承接”，写哪一个已知地标、动作或声源足以认回。若有意隐藏地点，写眼下给什么线索、哪一拍补足。场中环境变化与转场写在实际发生的行。

**表尾只留合计和一句自检**，有实质待修或未验证项就在这一句点明。用户追问时再解释取舍。

例如，事项“最后一个听众走了，她仍把歌唱完”可以写成“关门铃盖住半句歌词。她看着空桌停一拍，独自接上最后一句”｜“先替她难堪，再被她的坚持打动”｜“门铃退尽，留下清晰孤单的人声”｜“6 秒／本片段 20%”。全场台词、镜号、分镜和逐镜切点留给后续步骤。

## 以下供作决定时使用

前情检索、原文分解、备选拍法、删镜比较、语速与镜数验算都在提交前完成。只把会改变画面、声音、情绪或预算的结论写进上表。交稿时省去推演过程、资料来源、长篇原文摘录和重复的预算表。

### 先定情绪，再处理原文留白

以用户指定的主基调为准。没有指定时，结合项目已定方向与本段冲突，选定本次建议的基调。把它落实到观众的处境：他们替谁担心、有什么迟迟不能确认、何时才获准看清？这项决定先于补环境、选镜和分配声音。若本章定为阴森、压抑的恐怖悬疑，第一处环境就要让观众感觉到这层压力。平常动作可以很熟练，观众的不安可以继续积累，到转折再爆发或暂缓。短暂的明快或松弛需要有明确的反差和回收点。

**补设定时守住两条边界。** 原文明写的时地、人物状态、行为因果和前章已确认的场地事实要保留。原文没写的部分，先从场所用途和人物正在做的事推导，只补对本段情绪或动作可读性有用的细节。人物造型、陈设、光影、视野与运镜、环境声和剪辑节奏都依同一观众体验取舍。恐怖可以发生在明亮整洁的空间里，重点在光照得到哪里、视线在哪里受阻、一个熟悉的声音为什么开始让人不安。无依据的年代、天气、事故或新威胁若会改变故事，就保留为未知。美术参考提供画法和指定色彩，现场给人的感觉由导演决定。

上述取舍在制作端完成。送审表只在有关事项的呈现栏落一两个可见或可听的决定。关键补充容易被误认为剧本事实时，在注意栏短注“导演设定”。

### 认场并回查前 N 章

按成片的叙事顺序处理每一场，包括集内换场、重返旧地和交叉叙事。先定“地点／具体区域、故事时间、跟随谁、此刻做什么”，再查两件可能相隔很远的事。

1. **这个地方上次给观众看过什么？** 按地点、别称、区域和人物线索，查本章较早场次及当前项目前 N 章。用户给定 N 就按其范围查。未指定时，先找同地最近一次出场。若那次只露过局部，再追到真正交代本场所需关系、埋下线索或改变状态的那一场。进过同一栋楼，不等于见过今天要用的房间和出口。
2. **观众刚从哪里来？** 查上一场末尾留下的动作、声音、疑问和情绪。人物可能隔天又回到熟地，也可能在同一分钟切进另一条线。要续什么、跳过什么、让人误以为什么，分别由这两处前情决定。

查到前次章／场／镜号或时码，再判断地标、空间关系、声源或状态是否足以被认回。区分实际成片、按分镜预计交代和按声音设计预计听到。小说提过、库里有图、本章旧测试画过，都不能单独证明观众见过。前情未验证又会影响决定时，注明本次假设。场记按场次和故事日核对连续性是影视制作实践，前 N 章按场回查是本项目采用的规则。[ScreenSkills 场记职责](https://www.screenskills.com/skills-checklists/scripted-film-and-tv/script-supervisor-department/script-supervisor-skills/)

### 从原文找事项，先定优先级与预算

1. **先分配时间，再细化声画。** 依原文列出必要事实、人物动机和情绪转折。锁总预算，把时间给实际要看清的动作、要听懂的话和反应。对原文中功能相同的例证做取舍。按自然语速试估必要解释的时长，先判断哪些走动、操作和听者反应可与话语并行；预算按共同起点至最后落点计算，重叠部分只计一次。开场、过门和余波均计入。独占项合计等于目标时长、占比合计 100%。普通镜头最多 3 秒用于检验方案能否剪开，事项可跨镜；高阶镜头由 02 提出完整构想与预计时长，07 校准执行时间，可超过 3 秒，预算随采用结果同步。
2. **决定谁先知道什么。** 对每件事试一遍。仅靠现场行动能传多少？作者的解释、人物的私人判断和观众应亲历的感受，分别交给能传达它的载体。确定从谁的位置看和听、要在哪个转折改变，再填入对应事项。

### 按叙事任务选声画表达

本流程不设计背景配乐。环境底声、动作音效、主观听觉与惊点音效仍用于营造氛围和情绪；“在背景中持续响”不等于背景音乐。声音范围与落地方法见 [04 听觉设计](../novel-director-04/SKILL.md#声音范围)。

| 原文真正要送达什么 | 怎么决定用什么表达 |
|---|---|
| 可见的行动、选择或人物关系 | 先试行为与后果、物件的使用、人与人的距离或反应。若一个人嘴上答应、手却收回，画面已经能表达犹豫。对白适合请求、拒绝、试探等能改变对手行动的事。 |
| 身份、金额、职业知识、规则或世界背景 | 一个确切事实可由可信的票据、标记或现场对话给出，预算要够读懂。规则及其代价无法从动作推出时，选有理由解释的人或明确身份的讲述者。写清要说的**那条信息**，如操作与解说并行，写清两者各交代什么。 |
| 心理、隐瞒、自我辩解、回忆 | 视线选择、回避和动作停顿能表现态度。观众还必须听懂一条明确且未说出口的权衡时，用本人内心 OS。跨时间回望或带有立场的概括可用旁白。只有过去的具体事件本身值得目睹时才用闪回，并给出进出当下的依据。 |
| 画外事件、威胁、情绪或主观注意 | 决定听点、声源、进入或消失的一拍。声音先到、画面延后可让人等待辨认。动作与重音同拍可使冲击立刻发生。通过环境底声的变化、近声、非音乐性冲击声与留白，组织铺垫、惊点和余波。 |
| 表象与真相有落差、同一件事可被两种方式理解 | 声画互补时，各给一层不同的信息。声画对位时，让一句话或一种声音与可见事实发生有意义的矛盾。也可并置前后两个结果，让观众自己读出变化。选定本场的一种关系和落点。 |

编剧 David Magee 谈《少年派的奇幻漂流》时区分了动作能交代的求生行动和旁白能补足的内在感受。Randy Thom 讨论了在写作阶段怎样用听点和画外空间设计声音。DARIAH 的同画面换声示范可用来比较声画互补与反差。[编剧访谈](https://www.pbs.org/video/-story-writing-fantastical-conversation-david-magee/) · [声音设计者原文](https://www.filmsound.org/articles/designing_for_sound.htm) · [DARIAH 视听教学](https://campus.dariah.eu/resources/hosted/exploring-audiovisual-grammar-hear)

### 逐场决定环境何时交代、看什么、怎样接

在入场、场内发生变化、离场接下场时，对照前情问三件事。**观众此刻还记得什么？理解下一拍还缺什么，或此刻该留住什么感受？这条信息最早可以给、最迟必须给的时刻在哪里？** 首集开场或中途初入一处，选能交代必要时地、人物任务与环境常态的第一眼和第一声。行动依赖方位，就在行动前或行动中建立空间。熟地连续出现且关系清楚，可以直接接戏。隔章重返可用一个熟悉的地标或声音唤回。时段、区域、出口、人物位置或场所意义变了，只补会改变本次读法的部分。想让观众和人物一起迷失，就指定晚些时候让人认清的证据。

**按作用选手段。** 环境交代解决观众对时地、关系和常态的理解。空镜让环境或物件在一拍里独占注意。转场处理前后两段戏的关系。三者可组合，也可分别发生。景别、角度和运镜由后续拍法落实。

| 观众在这一拍需要什么 | 优先比较哪些手段 | 采用标准 |
|---|---|---|
| 认出新地点，或重新认清熟地 | 建立镜头、重建镜头、随人物入场 | 让地标与本场要用的区域发生可见联系。场中改变站位或揭出新区域时也可重建。一个熟悉的声音或动作已足够定位，就随戏交代。 |
| 看懂谁离谁多远、谁挡住谁、能否到达 | 双人／群像关系镜、主镜头中的一段、跟随或出入画镜头 | 使决定行动的双方、路线或阻隔同框。路程本身有变化才跟拍。否则从出发动作接到结果。 |
| 感受场所常态、人的缺席、时间变化或情绪余波 | 环境空镜、与前章呼应的物象、留在原画框等人离去 | 指出环境中具体哪处变化值得单独看。删去后若方位、期待、情绪和节奏都一样，就让人物场面继续。 |
| 看到一个会改变因果的证据 | 插入／细节镜（insert），或在原画框中移焦、露出细节 | 确定物件属于谁、哪一刻要被认出、提前给会泄露什么。待回收的细节还应查前章是否真的给观众看清。 |
| 主动作之外另有值得注意的事 | 切出镜头（cutaway）、画外声 | 说明离开主动作去看什么、切回时发生了什么变化。若只需观众听见，不另占画面。 |
| 看清一件事落在谁身上、改变了谁 | 反应镜、正反打、过肩，或留在双人镜 | 找到听者得到信息后第一个有意义的变化。若说话者和听者同框更能说明关系，就保留两人的表演。 |
| 决定观众比人物先知道、同时发现或更晚才懂 | 视线匹配、主观镜头（POV）、客观机位、遮挡与揭示 | 说清是谁看、能看见多少、何时给答案。视线匹配能让人理解“他在看什么”。严格 POV 还要从其眼位取景。 |
| 跳过经过、换时地或在两条线之间建立联系 | 省略、蒙太奇、平行／交叉剪辑、动作或图形匹配 | 给观众足以理解前后时间和因果的线索。交替两线要能产生等待、碰撞或对照。若一个结果画面已说明经过，可直接切到结果。 |
| 跨场保持情绪、引出未知或制造冲击 | 直切、声音桥、反差硬切、叠化或淡出入 | 点出上场最后看／听什么、下场最先看／听什么。下一场声音先入是 J 切，上一场声音延续是 L 切。关系本已清楚可直接切。用突切、黑场或叠化须说明它带来的停顿、冲击或时空含义。 |

完整动作的主镜头可以为剪辑提供多个可选片段。建立镜头负责交代地点和关系。成片采用哪些片段，取决于观众当时需要的信息。[Adobe 镜头类型与拍摄覆盖](https://www.adobe.com/creativecloud/video/production/cinematography/camera-shots-and-angles.html) · [建立与重建镜头示范](https://learnaboutfilm.com/film-language/sequence/) · [Adobe 声画错时剪辑](https://helpx.adobe.com/premiere/desktop/edit-projects/trim-clips/perform-j-cuts-and-l-cuts.html)

把回查结果用于选择建立、重建、唤回、沿用或暂缓揭示，再按页首格式落入对应场次。单列事项也可以由一个带人物的画面完成。是否另给空镜，由它是否需要独占观众注意决定。

例如，前几章已经让观众跟着乘客穿过渡口的蓝闸门上船。再回渡口，蓝门一角加熟悉的船铃就可唤回方位。若本次冲突是闸门新上了锁，可以让逃跑者尚未赶到时先给锁链，让观众替他着急。也可以等他推门未动才给锁链，让观众与他一起受挫。按本场需要选一个，给整个渡口再拍一遍并不能替代这个决定。

### 提交前自检

先只读每场入口的“选定的呈现方式”，遮住表头、情绪栏、注意栏和后面的惊点。能否从这行指出观众凭什么认出或重认空间，以及哪一处可见或可听的环境细节使基调成立？有意延后时能否找到回收处？只有地名、道具清单、人物手上动作，或关键环境只写在注意栏，这项判待修，先改入口行。再对原文查关键动机、因果与悬念，对预算核独占和并行。各项只留选中的声画决定。

**本步停止点**　按页首格式交决策表及一句“通过／待修／未验证”的自检，提交后停下。审看旧稿时只读，修订仅更新本步成果。
