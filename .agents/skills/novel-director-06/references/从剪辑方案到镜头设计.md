# 从剪辑方案到镜头设计

本文件是06开始设计前的必读操作方法。先完整读取05的[剪辑方法、选择条件与节奏决策](../../novel-director-05/references/按剧情选择镜头组合.md)，再读取当前范围的`shot_groups[].edit_plan`、全部逐镜切点与时间段，并对照02采用拍法和04场地图、连续走戏。以下只把05已经采用的方法落实成可见画框，不新增剪辑方法，也不让06重排镜序或替07设计运动执行。

## 先按整段设计，再写逐镜采用结果

1. **把节奏区间和观看次序连起来。** 沿05的段落方案找到快切、缓落、交替或不切的各区间，将该区间内全部镜号按顺序读完。结合02，辨清这一段让观众持续看同一事件、转向反应、在行动线间往返，还是经历既定的显露过程；逐镜切点必须放回这个顺序理解。保留05的镜数、用时、组织次序及声画错位，不从景别清单或每页宫数开始设计。
2. **逐个接住切口。** 从04连续时间进程找到前镜切出和后镜切入：前镜此刻正让人看谁／什么关系，动作与话语进到哪里，后镜交给谁／什么关系；哪些对象虽离开画面仍在行动，哪段声音跨切。让下一画框接住这个已定进度，并决定注意落点怎样转移或延续。同一动作、同一句话可以跨镜，不要求一个镜头完成一个事件；切回也不重新演上次动作。该步只用于形成连续画框，不另写上游状态表或观看目标表。
3. **从真实现场采用一组可行视点。** 实际看04图中此阶段全部关系、视线和运动轴，按02立场及当前切换关系选摄影主轴和观看侧；保留前镜已经建立的方向。对尚未定下的相邻镜组比较真正不同的可行组织：各自裁到哪里、哪些对象同框、主体多大、从哪里看、谁遮谁、观众能否在既定镜长内读到切口承接。不同组织应在这些可见关系上有实质差别，不能把同一脸加手画框改叫“特写／近景”当成两个候选。采用符合本段拍法与接切的一套；不必让每镜换机位、换轴或机械远近交替，也不为展示选择而生成候选图和推理报告。
4. **在本镜时间内选代表时刻。** 先认清切入、切出状态，再从其间04已经发生的动作和表演中选最能表现本镜观看重点的一刻，写入现有代表时刻。不得提前画出后镜才发生的结果，也不得把切回画成上次离开时的旧状态。动作匹配发生在切口，两个代表图不必恰好是切口前后帧；需分别保持切口可接和各自代表时刻正确。H镜按既定机制选择能体现尺度、透视、遮挡或焦点关系的一刻，保留它在完整变化中的位置，不把代表图自动当起幅。
5. **把选中的组织落到画框。** 先按下文[面向与观看关系](#把现场面向落实到摄影画框)确定本代表时刻的人物朝向与目标，再按项目画幅定身体与对象的实际裁边、完整入画和画外范围；定主体区域、相对大小和留白；用真实前后关系定透视、空间收束及遮挡；最后明确谁清楚、哪些层次同时可辨、哪些此刻仍不可辨。先保住切口指定的接触、视线或关系，再去掉妨碍阅读的多余画内信息。身体、重心和持握仍作完整推演，不能靠移动人物或镜像现场换取构图。第一轮只画几何关系，表演和清晰要求通过文字保留。
6. **分镜文字先交独立检查。** 按下文[一次独立检查](#分镜表完成后的一次独立检查)对照有效上游、完整镜序、同场切回及跨页组合，核对设计内部是否相容、面向关系和无效重复。制作方修订，检查者向主Agent报告通过后才采用画框并生图。
7. **采用结果进入三轮生成。** 摄影选择写入`camera.placement`，取景和清晰关系写入`composition.frame_description`等既有字段，只交自然语言采用结果。先分页用原生imagegen画几何故事板；逐宫裁图经独立检查、必要纠错并放行后，再用原生imagegen实附裁图与03资产生成独立单张；单张获独立检查放行后，才将该原件交BANANA重新渲染。三轮按[06图像审核优先级](../SKILL.md#图像审核优先级)处理，不把P3／P4微差当阻断，也不把裁图当作第二轮完成。实际几何、人体与接触错误在产生错误的原生轮次处理，BANANA不重想构图或修补错骨架。跨页继续同一动作和空间，页面边界不是设计重启点。

## 把现场面向落实到摄影画框

1. **先认定现场中的对象。** 从04当前阶段与代表时刻确认谁在看谁／什么、目标在何处及高低远近，分别辨清躯干朝向、头部转向和目光对象。回头、侧目、背向说话或避开视线按既有行动保留，不把交流一律改成身体相向、持续对视。画外目标仍有实际位置，不能只写“看画外”。
2. **再从采用机位推导可见面。** 将人物与目标放在同一现场中，从06的观看侧判断相机实际看到正面、侧面还是侧后面，目标在人物的近前、远后、上方还是下方。头眼须指向这个真实目标；“朝画右”不能代替“望向右后方较远处的人”，左右相反也不自动构成对视。若既定机位无法同时交代目标和所需面部表演，就在04现场及02拍法内换可行机位、取景或遮挡；不为露眼睛把人扭向摄影机，不用瞳孔侧移弥补不成立的头身朝向。改实际站位或关键行动仍交04。
3. **将互相关联的画框一起定。** 对视、正反打、看与被看及切回，分别放回同一现场核对距离、俯仰、头脸可见面、画外对象和动作进度；换机位不等于人物转头，前后代表时刻不同则按已有行动变化。单向观察不要求对方回看。沿已定观看侧建立可读关系，不靠机械左右互换、镜像或固定一套正反打构图。

采用结果写进现有`composition.frame_description`和实际生图提示词，机位仍写`camera.placement`。自然语言说清目标、头身关系、可见面及必要的深浅高低；已有画框已明确的关系不重复抄写。不新增方向字段、角度坐标或逐镜论证表。

## 按05已采用的剪辑决定画框

只使用本段实际涉及的条件，不把下表全部套进每段。方法名称和时间组织以05为准。

| 05已经采用什么 | 06必须作出的可见决定 |
|---|---|
| 连续性剪辑、动作匹配、插入／切离 | 保持同一次动作的阶段和运动方向，裁边须露出切口所需的接触或后果。前镜看局部接触、后镜接人物说话或反应时，分别确定局部的边界与后镜的表演范围；后镜不必再完整重复前镜局部。若两镜继续看同一对象，就让取景服务各自已定进度，不强制新增情节。插入后回主行动时，接住其在画外已推进的状态。 |
| 反应切换、视线匹配、J切／L切 | 先决定是看正在回应的人还是他看见的对象，再按上文把实际观看目标及头身朝向落实到画框，画外目标也保留高低与纵深依据。话语跨切时，后镜画切点之后实际发生的听者表演，不能等话说完再反应。对象此刻须隐藏，就用被允许的反应、遮挡或可见范围承接，不因视线匹配提前露答案。声音换了来源不等于画面必须跟着换人物。 |
| 正反打 | 在04真实互动关系中采用摄影主轴及观看侧，成对确定双方头脸可见面、目光目标、俯仰及距离感；按当前说听关系分别定取景主次、裁边和清晰对象。无需对称构图、同景别或每人一句轮换；再次回到已有机位可以沿用画框，但必须画此刻的反应、持物和动作进度。 |
| 交叉剪辑／平行剪辑 | 先让每条线有可辨的空间或对象依据，再按05次序设计各线相邻画框。交叉切回要接该线继续推进的阶段，不能把离开画面的时间当暂停；平行按已定对照关系组织尺度、形状或主次，不自行暗示同时发生。沿用同一线的机位有助辨认时就沿用，不为区分两线虚构灯光、方位或动作。 |
| 快切、加速、减速、等节拍或密度转折 | 在已定短镜内，让关键对象、动作方向或接触有直接可读的轮廓和注意落点，减少竞争信息，不在短镜里同时要求观众重建陌生空间、辨认多人再寻找细节。较长镜若由自语、反应或喘息承担缓落，画框就须容纳这些已有变化，不能仍只取无关局部；若上游要求在同一局部持续变化或留驻，则保留这种观看。相邻图如何接注意由事件决定，不强制位置对齐、远近交替或统一景别。 |
| 匹配转场、突切、叠化／淡变 | 匹配转场先落实05指定的两个既有对象：图形匹配确定实际形状、大小、落点及边界的对应；动作匹配转场确定可见姿态和动势的对应，仍遵守各自时空。声音匹配无需强造相似构图。突切的画面反差落实到既定尺度、显露或主次；叠化／淡变按已有区间考虑两画面的叠置可读性，不借转场掩盖接不上。若必须改核心拍法或现场才能成立，交对应步骤。 |
| 已定省略蒙太奇／跳切 | 画出05所选时间跳点两端的不同状态，保留上游允许省略的范围；跳切需要的相近视点可以成立，不擅自改成顺滑动作匹配，也不把连续剪辑中相似的画框事后称为跳切。 |
| 已定长镜／H镜一镜不切 | 保留连续效果及同框关系，从本镜既定进程选代表时刻，画出该刻可见的空间、尺度与清晰状态。视点应能由02既定拍法经过，但06不另定起落幅和相机路径；完整动态执行交07。不能把长镜拆成几个独立画框再当新增摄影镜头，也不以一张代表图宣称运动已经验证。 |

## 分镜表完成后的一次独立检查

06制作方补齐完整委托范围的景别、机位、实际画框、代表时刻与对应指令后，由另一独立检查者按[独立检查与放行](独立检查与放行.md)核对，向主Agent回报，通过后再分页生图。05只有镜序与切点的剪辑表不能替代此关；制作方不再执行同一套自检来代替独立判断。按完整镜序阅读，并把同场、同一行动线的切回集中对照，覆盖非相邻镜、跨段和跨页；局部委托只补读同场已有有效镜作参照，不扩成全章改写。

1. **核对本镜正在发生的观看关系。** 将成对镜头、同框人物和同场切回放回04现场，按上述方法核对采用机位与头身、目光目标是否相容。要求看后方人物却只写向侧边平看、站坐对话却互看同一高度、反打各自朝向无关空间，均须在画框设计中解决；有依据的避视、转头和单向观察照原行动保留。 同时核对文字内部的前后层次、遮挡与背景地标是否能在该机位共同成立；例如同一人物不能既在主体远后方，又无依据成为机位前景肩背。发现冲突须指出依据和影响，交制作方解决，不留给生图模型择一解释。
2. **找出实际重复的画框与组合。** 暂时不看景别名称和情绪形容词，对照观看对象、身体裁边、主体大小、机位拍向、前后遮挡和清晰主次。找出同框反复返回、A／B取景轮换，以及整组画框跨页复用。换名称、轻微偏移或把同一构图改写成另一句话不算设计变化；相似只是待判断的线索，不按次数直接判错。
3. **逐处核对这次为什么切回、画框是否接得住。** 直接对照02拍法、04当时已发生的动作／反应及05切口。相同机位仍能清楚承载这次回应、持续观察或既定对照时保留，代表时刻必须是当前进度。若本镜已转向交接、后果、另一人物反应或双方关系，画框却仍重复旧的注意重心、漏掉切口要求，则重设计。整段机械轮换两个近景，使02已定的同框关系、显露或强弱转折始终没有落实，也不能逐镜各找一句“保持连续”就放行。不能把已经演过的动作起点再次当作切回画面。
4. **把修订变成可见差别。** 检查者指出未完成的观看任务，制作方对无效重复在04现场与已建立方向内重选实际取景范围、主体组合、层次遮挡、视点或清晰主次，使本镜真正承载对应变化；改动必须进入画框描述和实际生成提示词，不能只补一句用途解释。保留合理正反打和固定观察，不为去重机械远近交替、每镜换机位、越轴、挪人或新增动作；已定重复／匹配／跳切按05意图执行。
5. **修订后定向确认并放行。** 制作方在既定镜序和切点内完成06修订，需改剪时按下段交05；检查者只确认本次问题及受影响接切，向主Agent报告对应版本与范围的结果。制作方只维护采用的分镜表，不另建重复率、逐镜论证或自检报告。生图后的独立图像检查核对实际画面是否执行已放行设计；已有设计有效而成图重复，按生成偏差处理，不重开整章文字检查。

只有在既有镜序、时长和切点内，经可行画框比较仍无法实现上游明确要求，才反馈05。例如02规定连续同框成立的接触被既有切点分到两个不能同框的时段，或04明确的必要动作尚未发生就已到05切出点。反馈时只列受影响镜号、上游具体要求、冲突的切点／用时，以及为什么取景或代表时刻调整不能解决；05统一改段落方案及镜表，06据统一版本继续。不因无依据的“看不清”要求加时，不自行删切、并镜、重排或延长。

## 面向关系的采用结果示例

以下为独立虚构片段，不修改章节。第一例中04已定甲站在桌侧、乙坐在对面，彼此看着说话；05已排正反打。06采用同一观看侧，交付如下：

**S301｜甲偏置近景。** 从坐着的乙身旁斜仰看甲，甲的头肩落在左上，躯干朝向乙，头微俯，眼睛落在右下近处乙的脸上。乙的侧后头部和肩缘在右下形成前层，甲的近侧脸与向下的目光可读，桌沿保留两人间的距离。

**S302｜乙偏置近景。** 从甲身旁同一观看侧斜俯看乙，乙落在右下，肩胸仍朝着甲，脸抬向左上近处，目光接住甲的脸。甲的肩臂在左上形成前层，桌边与椅背交代乙仍坐在原位；乙的脸清楚，甲的肩缘稍退。

第二例中04已定甲在前、乙在远处门口，甲回头看乙，乙仍朝门内看；02要求看清回望与门口的关系，没有要求同时露出甲的完整脸。06采用如下同框画面：

**S311｜回望门口的纵深近景。** 甲的肩背占左前景，躯干仍朝近处桌面，头已转向右后方门口的乙。从甲侧后方看，只露一小段侧脸与下颌，头部正面朝入画面深处。乙留在右后门框内，仍侧向门内，没有回望甲。甲的转头轮廓与远处乙的位置共同可辨，桌面一角保留在近处。

第一轮以头部前面与侧面的转折、肩背轮廓画出这些关系，独立标注只补观看目标。第二轮据此落实眼神与表演，第三轮保持；不为显出甲的眼睛把侧后头部改成朝画右平看的完整侧脸。

## 跨页重复修订示例

独立虚构示例：05已排S201—S206，先由甲说、乙听，再由甲递钥匙、乙接住，最后甲追问、乙转看门口；04已定两人原地交接。初排六镜均为甲乙头肩近景轮换，递接被裁在画外，末镜也看不出乙与门口的关系。独立检查指出缺口、制作方修订后只交采用决定，例如：

**S203｜递接的局部近景。** 沿原观看侧贴近两人之间，甲伸出的钥匙和乙迎来的手完整入画，两只手分处斜向两端，接触成为主体，肩背仅在边缘交代归属。

**S204｜乙偏置近景带持钥匙的手。** 乙已接住钥匙，手留在胸前可见范围内，甲的肩缘在近侧轻遮，脸与握钥匙的手共同清楚；不把递接动作重新演一遍。

**S206｜乙侧前近景带门口纵深。** 保持既定观看侧，乙转向门口的侧脸落在一侧，视线前方留出可辨门洞；其他人物按04原位留在画外。

S201、S202、S205继续使用成立的说听取景，按各镜当前表演选代表时刻，不为凑差异全部换机位。

## 相邻镜完整示例：擦汗接自语

以下为独立虚构方法示例，不引用、修改任何章节，也不是所有连续剪辑的固定模板。只演示已有切点怎样形成不同的取景重心；第二镜比第一镜长不构成合并理由。

**输入。** 02采用贴近人物的连续观察，先让擦汗的接触落下，再让轻声自嘲和喘息显出疲惫；无新增揭示。04已定人物背靠门旁墙面，右手攥布第一次触到右额角，沿鬓角向下擦，手下落时低声说“还真够累的”，嘴角苦笑，肩胸随喘息起伏；目光仍落在门内地面，身体没有换位。05的段落方案为“这3秒采用连续性剪辑，先用0.6秒留住第一次接触，再用2.4秒承接同一次下擦、轻声自语和喘息；动作不停，喘息跨切继续”。S101为00:10—00:10.6，布刚触到额角即切；S102为00:10.6—00:13，从布已经接触并向下擦接入，留到苦笑松开。画幅沿项目既定规格。

**06采用的连续关系。** 以右手接触额角并向下擦拭的行动关系组织两镜，从门内一侧观看，沿用擦拭向下的方向；第一镜把接触单独显出，第二镜采用同侧较远的静态视点，容纳说话与喘息。人物留在原处，观看侧不翻转，声音和动作均不重启。

**S101｜额角与手的局部特写｜00:10.5，布第一次贴住右额角**

从门内一侧贴近斜看右额角，额角落在画面左上，攥布的手从右下进入，两者接触处完整露出。画框只保留额角、邻近眉尾与手布，嘴、下巴和肩膀都在画外；背景只剩无法辨认的墙面。手与额角处于共同清晰范围，接触压出的形体可读。第一轮用头部局部体块、手和布的轮廓表示，不画汗珠、五官表情或衣物细节。

**S102｜偏置面部近景带肩胸｜00:12，擦汗的手已下落，自语将完、嘴角仍带苦笑**

从门内同一观看侧的较远处斜看，画框从头顶取到上胸，完整脸部、颈部和一侧肩线落在画面左侧，右侧留出视线朝向的门内空间；门框只在右缘形成窄的纵深参照。右手已经落出画框，不再把布与额角作为主体，肩胸有容纳既有喘息起伏的空间。正式图让嘴角、眼神与近侧肩线清楚，门框可辨而不抢注意。第一轮只画头身朝向、肩胸体块、门框及已有姿态，苦笑、自语和清晰要求由文字交给第二轮恢复。

这里不是把同一脸加手画面分别标成“特写／近景”：第一幅裁掉口鼻和肩部，让观众看接触；第二幅已经容纳说话、苦笑和喘息，手按原有时间退出。两幅代表图之间经过了既定动作，S102的切入仍接住同一次下擦，不能从手再次抬起开始。实际交付只留下采用画框与图，不复制上述输入、比较过程或解释。
