# 从剪辑方案到镜头设计

本文件是06开始设计前的必读操作方法。先完整读取05的[剪辑方法、选择条件与节奏决策](../../novel-director-05/references/按剧情选择镜头组合.md)，再读取当前范围的`shot_groups[].edit_plan`、全部逐镜切点与时间段，并对照02采用拍法和04场地图、连续走戏。以下只把05已经采用的方法落实成可见画框，不新增剪辑方法，也不让06重排镜序或替07设计运动执行。

## 先按整段设计，再写逐镜采用结果

1. **把节奏区间和观看次序连起来。** 沿05的段落方案找到快切、缓落、交替或不切的各区间，将该区间内全部镜号按顺序读完。结合02，辨清这一段让观众持续看同一事件、转向反应、在行动线间往返，还是经历既定的显露过程；逐镜切点必须放回这个顺序理解。保留05的镜数、用时、组织次序及声画错位，不从景别清单或每页宫数开始设计。
2. **逐个接住切口。** 从04连续时间进程找到前镜切出和后镜切入：前镜此刻正让人看谁／什么关系，动作与话语进到哪里，后镜交给谁／什么关系；哪些对象虽离开画面仍在行动，哪段声音跨切。让下一画框接住这个已定进度，并决定注意落点怎样转移或延续。同一动作、同一句话可以跨镜，不要求一个镜头完成一个事件；切回也不重新演上次动作。该步只用于形成连续画框，不另写上游状态表或观看目标表。
3. **从真实现场采用一组可行视点。** 实际看04图中此阶段全部关系、视线和运动轴，按02立场及当前切换关系选摄影主轴和观看侧；保留前镜已经建立的方向。对尚未定下的相邻镜组比较真正不同的可行组织：各自裁到哪里、哪些对象同框、主体多大、从哪里看、谁遮谁、观众能否在既定镜长内读到切口承接。不同组织应在这些可见关系上有实质差别，不能把同一脸加手画框改叫“特写／近景”当成两个候选。采用符合本段拍法与接切的一套；不必让每镜换机位、换轴或机械远近交替，也不为展示选择而生成候选图和推理报告。
4. **在本镜时间内选代表时刻。** 先认清切入、切出状态，再从其间04已经发生的动作和表演中选最能表现本镜观看重点的一刻，写入现有代表时刻。不得提前画出后镜才发生的结果，也不得把切回画成上次离开时的旧状态。动作匹配发生在切口，两个代表图不必恰好是切口前后帧；需分别保持切口可接和各自代表时刻正确。H镜按既定机制选择能体现尺度、透视、遮挡或焦点关系的一刻，保留它在完整变化中的位置，不把代表图自动当起幅。
5. **把选中的组织落到画框。** 按项目画幅定身体与对象的实际裁边、完整入画和画外范围；定主体区域、相对大小和留白；用真实前后关系定透视、空间收束及遮挡；最后明确谁清楚、哪些层次同时可辨、哪些此刻仍不可辨。先保住切口指定的接触、视线或关系，再去掉妨碍阅读的多余画内信息。身体、重心和持握仍作完整推演，不能靠移动人物或镜像现场换取构图。第一层只画几何关系，表演和清晰要求通过文字保留。
6. **采用结果进入生成输入。** 将摄影选择写入已有`camera.placement`，将取景和清晰关系写入`composition.frame_description`等现有字段；按Skill只交一段自然语言采用结果，不新增分析字段或过程文稿。整段决定完成后才按自然衔接分页，原生imagegen的组页提示词直接使用这些画框决定；实际图的构图、镜头视点、景别、透视与接触按[06图像审核优先级](../SKILL.md#图像审核优先级)合并检查，P1／P2修正后才交第二层Gemini；其余差异按实际影响判断，符合P3／P4的放行，不要求像素级复刻；检查方向和示例均不穷尽问题类型，也不固定某类偏差的级别。Gemini读取同一决定及03／04原件，恢复真人质感、表演与更鲜明的光影，不能到渲染时重新想构图或修补错误骨架。跨页继续同一动作和空间，页面边界不是设计重启点。

## 按05已采用的剪辑决定画框

只使用本段实际涉及的条件，不把下表全部套进每段。方法名称和时间组织以05为准。

| 05已经采用什么 | 06必须作出的可见决定 |
|---|---|
| 连续性剪辑、动作匹配、插入／切离 | 保持同一次动作的阶段和运动方向，裁边须露出切口所需的接触或后果。前镜看局部接触、后镜接人物说话或反应时，分别确定局部的边界与后镜的表演范围；后镜不必再完整重复前镜局部。若两镜继续看同一对象，就让取景服务各自已定进度，不强制新增情节。插入后回主行动时，接住其在画外已推进的状态。 |
| 反应切换、视线匹配、J切／L切 | 先决定是看正在回应的人还是他看见的对象，再以04视线和既定观看侧让朝向对应。话语跨切时，后镜画切点之后实际发生的听者表演，不能等话说完再反应。对象此刻须隐藏，就用被允许的反应、遮挡或可见范围承接，不因视线匹配提前露答案。声音换了来源不等于画面必须跟着换人物。 |
| 正反打 | 在04真实互动关系中采用摄影主轴及观看侧，让两方的朝向、距离感和必要环境参照能相互对应；按当前说听关系分别定取景主次、裁边和清晰对象。无需对称构图、同景别或每人一句轮换；再次回到已有机位可以沿用画框，但必须画此刻的反应、持物和动作进度。 |
| 交叉剪辑／平行剪辑 | 先让每条线有可辨的空间或对象依据，再按05次序设计各线相邻画框。交叉切回要接该线继续推进的阶段，不能把离开画面的时间当暂停；平行按已定对照关系组织尺度、形状或主次，不自行暗示同时发生。沿用同一线的机位有助辨认时就沿用，不为区分两线虚构灯光、方位或动作。 |
| 快切、加速、减速、等节拍或密度转折 | 在已定短镜内，让关键对象、动作方向或接触有直接可读的轮廓和注意落点，减少竞争信息，不在短镜里同时要求观众重建陌生空间、辨认多人再寻找细节。较长镜若由自语、反应或喘息承担缓落，画框就须容纳这些已有变化，不能仍只取无关局部；若上游要求在同一局部持续变化或留驻，则保留这种观看。相邻图如何接注意由事件决定，不强制位置对齐、远近交替或统一景别。 |
| 匹配转场、突切、叠化／淡变 | 匹配转场先落实05指定的两个既有对象：图形匹配确定实际形状、大小、落点及边界的对应；动作匹配转场确定可见姿态和动势的对应，仍遵守各自时空。声音匹配无需强造相似构图。突切的画面反差落实到既定尺度、显露或主次；叠化／淡变按已有区间考虑两画面的叠置可读性，不借转场掩盖接不上。若必须改核心拍法或现场才能成立，交对应步骤。 |
| 已定省略蒙太奇／跳切 | 画出05所选时间跳点两端的不同状态，保留上游允许省略的范围；跳切需要的相近视点可以成立，不擅自改成顺滑动作匹配，也不把连续剪辑中相似的画框事后称为跳切。 |
| 已定长镜／H镜一镜不切 | 保留连续效果及同框关系，从本镜既定进程选代表时刻，画出该刻可见的空间、尺度与清晰状态。视点应能由02既定拍法经过，但06不另定起落幅和相机路径；完整动态执行交07。不能把长镜拆成几个独立画框再当新增摄影镜头，也不以一张代表图宣称运动已经验证。 |

## 相似画面与退回05的边界

两镜画得相似时，先对照它们的切口与代表时刻：若05已经从接触转向自语、从说者转向听者，或切回发生了反应变化，06却给出同一取景重心，就在06内完成真实的裁边、层次、视点或清晰关系决定。有效设计已有差别但图未照做，是06生成偏差。不能从“这两张像”反推05多切，更不能先并镜再给出理由。

返回相同机位、同一动作跨切、台词跨切或相同景别本身都不构成问题；成立与否看它们是否按既定时序接住当前观看对象和关系，不设“每镜必须新信息／新情节／新机位”的额外指标。

只有在既有镜序、时长和切点内，经可行画框比较仍无法实现上游明确要求，才反馈05。例如02规定连续同框成立的接触被既有切点分到两个不能同框的时段，或04明确的必要动作尚未发生就已到05切出点。反馈时只列受影响镜号、上游具体要求、冲突的切点／用时，以及为什么取景或代表时刻调整不能解决；05统一改段落方案及镜表，06据统一版本继续。不因无依据的“看不清”要求加时，不自行删切、并镜、重排或延长。

## 相邻镜完整示例：擦汗接自语

以下为独立虚构方法示例，不引用、修改任何章节，也不是所有连续剪辑的固定模板。只演示已有切点怎样形成不同的取景重心；第二镜比第一镜长不构成合并理由。

**输入。** 02采用贴近人物的连续观察，先让擦汗的接触落下，再让轻声自嘲和喘息显出疲惫；无新增揭示。04已定人物背靠门旁墙面，右手攥布第一次触到右额角，沿鬓角向下擦，手下落时低声说“还真够累的”，嘴角苦笑，肩胸随喘息起伏；目光仍落在门内地面，身体没有换位。05的段落方案为“这3秒采用连续性剪辑，先用0.6秒留住第一次接触，再用2.4秒承接同一次下擦、轻声自语和喘息；动作不停，喘息跨切继续”。S101为00:10—00:10.6，布刚触到额角即切；S102为00:10.6—00:13，从布已经接触并向下擦接入，留到苦笑松开。画幅沿项目既定规格。

**06采用的连续关系。** 以右手接触额角并向下擦拭的行动关系组织两镜，从门内一侧观看，沿用擦拭向下的方向；第一镜把接触单独显出，第二镜采用同侧较远的静态视点，容纳说话与喘息。人物留在原处，观看侧不翻转，声音和动作均不重启。

**S101｜额角与手的局部特写｜00:10.5，布第一次贴住右额角**

从门内一侧贴近斜看右额角，额角落在画面左上，攥布的手从右下进入，两者接触处完整露出。画框只保留额角、邻近眉尾与手布，嘴、下巴和肩膀都在画外；背景只剩无法辨认的墙面。手与额角处于共同清晰范围，接触压出的形体可读。第一层用头部局部体块、手和布的轮廓表示，不画汗珠、五官表情或衣物细节。

**S102｜偏置面部近景带肩胸｜00:12，擦汗的手已下落，自语将完、嘴角仍带苦笑**

从门内同一观看侧的较远处斜看，画框从头顶取到上胸，完整脸部、颈部和一侧肩线落在画面左侧，右侧留出视线朝向的门内空间；门框只在右缘形成窄的纵深参照。右手已经落出画框，不再把布与额角作为主体，肩胸有容纳既有喘息起伏的空间。正式图让嘴角、眼神与近侧肩线清楚，门框可辨而不抢注意。第一层只画头身朝向、肩胸体块、门框及已有姿态，苦笑、自语和清晰要求由文字交给第二层恢复。

这里不是把同一脸加手画面分别标成“特写／近景”：第一幅裁掉口鼻和肩部，让观众看接触；第二幅已经容纳说话、苦笑和喘息，手按原有时间退出。两幅代表图之间经过了既定动作，S102的切入仍接住同一次下擦，不能从手再次抬起开始。实际交付只留下采用画框与图，不复制上述输入、比较过程或解释。
