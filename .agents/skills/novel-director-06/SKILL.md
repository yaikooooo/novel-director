# 06｜彩色正式分镜

本步交付观众最终会看到的分镜图。05 决定什么时刻切给观众看、看多大。06 选择代表帧的静态视点，画清**谁在哪里、观众先看见什么、哪部分被遮住或留在暗处**。直接用 Codex 自带的 `imagegen` 生图技能生成彩色净图。采用图是后续运镜提示词中代表时刻的构图与光影依据。

## 定每一宫画什么

读 05 的剪辑初排、景别、时码和 `05_拍摄设计.json`。按剧情中的观看关系分组，在行动或视角自然衔接处翻页。**本页有几个独立摄影镜头，就画几宫。每镜只选一个代表时刻。** 选观众最需要看清的信息落下的那一拍。06 以箭头和短说明标动作与视线，07 在分镜确认后补采用的运镜标注；纯黑段沿时间线显示黑场。

- **先定画框。** 依 05 选定的景别与信息范围、04 的当时现场，选择适合这一刻的机位、视高、拍向与裁切，再落前中后景。按这个视点画人物比例、透视缩短、支撑与接触，保住彼此的大小、遮挡和留白。空镜由场地尺度、地标及关键物件交代空间。
- **再定入画的美术。** 用用户给的风格原图或 03 已确认的风格样张确定线条、色面、材质与明暗画法。用 03 的角色、当场造型与状态、场景区域和必要道具原件确定具体长相与陈设。出现谁、穿哪套、物件在哪里取 04／05 当前时刻。缺关键原件时沿 03 补齐，只标出受影响的镜组。
- **让光线完成本镜的任务。** 从 01／02 的情绪、04 的光区和 05 的显露顺序，决定本格的注意中心，再组织主体的亮暗面与前后景关系。把采用的光影写成画面中能看见的结果，带入本格生图提示词。

## 把光影设计成画面

**光影更有力度，明暗反差更鲜明，体积感和空间层次更突出。具体怎样表现，由当前分镜的内容、情绪和导演意图决定。**

先忽略纹理和小高光，推演这一格的大块明暗，再按需要落实下面的关系：

1. **明暗主次。** 决定观众先读到的关键信息，由怎样的明暗关系承载，其余区域如何退后。按本镜内容安排反差、位置与面积，让光影服务叙事中心。
2. **形体转折。** 根据所摄对象和情绪选择受光、背光及过渡的表现力度。光源软硬、填充、反射与遮挡都是可选手段，采用结果既有体积感，也保住本镜需要读懂的信息。
3. **空间分层。** 比较前景、主体和背景的明度，让重要轮廓落在有区别的背景上。可选亮主体衬暗背景、暗形体衬亮区域、局部侧光或有来源的边缘光；按场景选择。背景有明暗起伏，受光范围随空间展开，轮廓光、光束和窗影各自承担具体作用。
4. **跨镜连续。** 从场内光源推导新机位所见的明暗关系，受光变化随主体、光源及遮挡的实际关系发生。同场可以通过取景突出不同信息，光源位置、日夜与天气继续遵守已定现场。

参考图的用色、材质和塑形质量与本场照明方案分别说明：保留参考中明暗体块、形体转折和主体分离的表现力，光色、方向及覆盖范围由当前戏决定。资产图里便于认清角色的展示光，在正式分镜中换成本场叙事光。

场级决定归入已有 `lighting_setups`，每格根据实际内容，将采用的光影效果直接写进生图提示词。有关塑形、主体分离与填充的原理，参考 [ASC 的布光讲解](https://theasc.com/article/lighting-a-set/)。

## 按镜组调用原生生图

读取 Codex 自带的 `imagegen` Skill，调用其内置 `image_gen` 工具生成组页或编辑已有画格。一次请求画同一镜组的一页，各格按剪辑顺序、以项目画幅独立取景。先实际查看参考图，再通过工具的图像参考参数附入原图；本地文件用 `referenced_image_paths`。把附件各自决定的内容写明。

> **组页提示词**　按［实附风格图］的用色、材质和明暗塑形力度，画［镜号顺序、宫数与排列］的彩色正式分镜净图。各格使用［项目画幅］。［角色／当场造型图、场景图］确定外观，［本场地标、人物位置］贯穿本页。光影更有力度，明暗反差更鲜明，体积感和空间层次更突出；具体表现依据各格内容、情绪与导演意图。本场照明依据［已定光源与光区］。逐宫写「［镜号／代表时刻］从［机位、视高、拍向］看，［景别和画面边界］；［主体状态、空间与遮挡关系］；［本镜采用的光影效果及其叙事作用］；观众首先读到［本镜重点］」。镜号、箭头和文字由阅读器叠加，原图保留完整净画面。

跨页接同一场戏，**把上一页已采用的相邻宫原图实附给下一次调用**，指明页号、格位和继承的关系。上一宫是局部特写时，再附最近能看清该场布局的一宫。新机位的左右、近远与受光面从现场推导，状态变化只取 04／05 已发生的事。补单格时同样实附所在组页、必要前后格和美术依据。首个正式样张按[主 Agent](../../../AGENTS.md)既有审定或本次自主定稿授权进入批量。

## 标注与采用

净图只画这一刻。阅读器在独立图层叠加 `annotations`，动作与视线用 `action` 实线箭头，标明谁动、朝哪里看或碰到哪里。07 采用运镜后在同一图层追加 `camera` 虚线箭头与触发、落点，选定固定时追加 `note` 说明。开关标注始终看到同一张图。

集中连看本组一次。先看净图能否读出机位、透视、景别、人物比例、视线与遮挡，再看造型是否延续。缩小看大块明暗，并对照已确认风格图的塑形力度：光影是否有力度、明暗关系是否鲜明，体积感与空间层次是否符合本镜表达，第一眼是否落在本镜重点；再看必要信息是否可读、明暗有没有提前泄露信息。将“光影力度偏弱”作为可直接指出的画面偏差。同场换镜后核对光向。将这些观察并入已有 `design.review.board`，采用判断依据实际图像。打开标注看镜内变化是否清楚。沿用 05 的单镜时长与相邻景别标准。画错时在原生生图中带参考修对应格；静态视点与构图在本步取舍，涉及改剪、镜数或景别时交 05 同步，再更新受影响的图。

## 交付

- `06_正式分镜/` 保存采用的组页原图。每镜按实际 `panel_region` 从采用页原样无损裁出一张净图，供独立查看和提示词引用；单镜单页且整页就是画框时直接共用原件。
- 在 `05_拍摄设计.json` 的 `design.board_sheets` 登记原页、实际传入的参考图及用途、采用提示词。每个摄影镜头的唯一 `design_frames` 项登记图号、`sheet_ref`、`panel_id`、`panel_region`、代表全局帧、整镜显示帧段、`annotations` 和净图的章节相对路径 `board_art`。在 `design.review.board` 简记实际观察、采用依据与待办。字段见[拍摄数据约定](../novel-director-05/references/拍摄数据约定.md)和[阅读器接口](../../../前端/导演阅读器/数据接口.md)。
- 单独委托正式分镜时，交图册、逐镜净图与已有审定状态即到达终点。继续设计运镜时，[07](../novel-director-07/SKILL.md) 据剧本、已审净图和前后切点，写出起幅、触发、运动过程、落幅与承接的提示词。
