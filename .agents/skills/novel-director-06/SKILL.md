# 06｜故事板设计与单镜渲染

本步分两层完成：**第一层由 Codex 原生 `imagegen` 负责镜头设计图，构图、镜头视点、机位、景别、透视必须准确、正确，并落实人体、接触和跨镜连续；第二层在第一层实际检查通过后，将有效单镜图与必要资产实附给 Gemini Nano Banana 2.1，完成真人棚拍质感、更鲜明的光影塑形及既定景深。** 制作顺序是“整段镜头设计 → 原生生图的几何故事板 → 逐宫裁图 → 镜头几何与跨镜关系合并检查 → 必要的原生图纠错及定向验收 → Gemini 真人质感与光影重绘 → 一次正式图检查”。原生生图承担准确的镜头依据，Gemini承担该镜头的画面表现，两层不得倒置；分页服务展示与生成，不能把一场戏拆成互不相干的单图设计。

**镜头准确是放行条件，不能被画面好看代替。** 原生图必须能直接读出采用的取景边界、视高与拍向、人物及物件相对大小、前后层次、透视收束、遮挡、视线和接触；写对“景别／镜头／透视”标签不等于图画对了。Gemini没有重新决定这些关系的权限，不能用真人化重摆人物、补造空间、修改动作或修理尚未通过的几何错误。第一层只测试构图时就在原生图交付后停。

直接读取01表达要求、02采用拍法与场级光影美学、03风格与资产、04场地图及连续走戏、05的`shot_groups[].edit_plan`和逐镜切点。空间、调度、表演、全部实际关系轴／视线轴／运动轴及光声继承04；摄影主轴、观看侧、机位与镜头间的方向衔接由06选择，不要求04预先决定。拍法、高阶效果与本场光影表达取向继承02。镜序、镜数、切点和镜长改变交05；核心拍法或整场光影表达取向改变交02，现场改变交04；07继续负责起落幅、运动或留驻的执行。原有景别、视点、人体与接触、光影及连续性推演保留，交付只留采用结果。

开始设计前完整读取[分镜设计职责与交接](references/分镜设计职责与交接.md)及[从剪辑方案到镜头设计](references/从剪辑方案到镜头设计.md)，并按后者读取05的剪辑方法定义，再按其顺序完成整段设计。主动处理本段涉及的视点、画幅、视线、透视、景深、动作状态、光色材质与跨镜衔接。02未细定的常规画面决定由06在既定观看任务内完成，不把它们留给生成工具默认选择，也不为每项细化退回02。方法参考不复制成交付检查表。

**禁止中景居中。** 单人半身／全身居中摆放、双人居中平排对峙的展示式画面均禁用；不以改称全景、轻微偏移或斜拍绕过，按实际画面关系判断。中景可以采用明确的非居中组织；两人对峙可以采用非中景取景、人物分居两侧，并以机位、纵深、遮挡或留白建立明确关系。基础、高阶、故事板与正式单图同样遵守。不用歪斜地平线或强加遮挡来装饰性规避，也不能为此越轴、挪人或改变既定接触。

## 图像审核优先级

这是一套按影响程度决定处理方式的原则，不是检查项目的封闭清单。用户和文中的例子只帮助理解轻重，不限定检查范围，也不预先决定同类问题的级别。执行者须结合本镜任务、有效设计、实际画面和前后关系主动识别问题；未列举的情况同样适用，不能因未在例子中出现就漏判，也不能按物件名称或关键词机械判级。

判断依据是：画面是否成立，放回上下文是否造成实质矛盾，是否影响观众理解、主要表达或动作完成，以及影响有多明显、多重要。这些也是综合判断的方向，不是要求逐项填满的表。先看正常观看时的实际效果，再为具体疑点查看局部；不放大寻找无关瑕疵。先处理P1、P2，生成仍以采用设计为目标，验收不要求逐像素一致。

| 优先级 | 按实际影响判断，不限定问题类型 | 处理 |
|---|---|---|
| P1：画面本身明显不成立 | 不论发生在哪个对象或表现环节，实际画面存在明确、显著的错误，已经破坏其基本可信性与可用性；不能用有意设计或正常观看变化合理解释。 | 必须修。在已委托的制作／修复范围内直接定向修正，无须再问用户；几何源图错误先修原生图，正式图新增错误由06修正式图。 |
| P2：内容或关系存在重大错误 | 单张可能看似成立，但与有效设定、本镜表达任务或前后关系存在明显、实质性的冲突，使观众误解事件，或破坏连续性、关键表达与行动成立条件。 | 必须修。在已委托范围内直接处理，无须再问用户；查明真实来源，按原负责步骤修正必要成果及依赖，不改已定剧情来迁就错图。 |
| P3：影响有限的可选调整 | 差异可察觉，但主要表达、剧情理解、动作与连续关系仍成立；影响次要，或属于有选择余地的表现取舍，尚不足以判定成图不可用。 | 先放行，可继续交付和下游。一次集中列为可选调整，让用户决定；用户未要求修改前不重画，不记为阻断或待修。 |
| P4：无影响的微小差异 | 不指出便难以察觉，且不违背剧情、不影响动作、连续性和主视觉阅读。 | 完全放行；不列待办、不要求确认、不触发重画。 |

同一种偏差在不同镜头中可能属于不同级别，按本镜实际作用和后果判断，不给某类对象设置永久必修或永久豁免。例如一个锁扣是否重要，取决于它是否参与当前表达或行动；这是判断方法的示例，不是“锁扣规则”。任何拒收都须有具体可见影响，不能仅以“与文字不完全一致”为理由。用户明确的构图禁令和内容约束仍执行，但不得把无影响的微差包装成违反设计。

06在已有的一次合并检查中作出上述判断并负责定向修复，主Agent只核对交接、范围及代表镜组，不另起全章复审。修后只确认本次P1／P2问题及受影响接切；按既有限次规则处理仍未解决的实质问题，不滚动搜新瑕疵、不自动循环全章。P3仅在现有观察备注或汇总中一次说明，P4无需记录；不新增评分、审核矩阵或逐镜优先级字段。用户明确只检查不改、只讨论方法或指定停点时，遵守该范围，不据此启动生产或扩大修改。

## 第一层：把镜头设计落实为画框指令

先按必读方法把05整段`edit_plan`、节奏区间及镜表还原成连续观看顺序，明确每个切口从什么对象／关系接到什么对象／关系、动作和话语推进到哪里，再选摄影主轴、观看侧及相邻画框。不能读一条镜表就独立生成一张图。决定整段观看关系后，在04连续进程与05各镜入出点内选代表时刻，落实实际裁边、透视、遮挡和清晰关系，最后才写提示词、分页和渲染。

每个摄影镜头只选一刻，每宫对应一个镜号；黑场沿05时间线保留，不另造摄影画面。代表时刻不默认等于首帧，也不等于前后切口；同场、跨页及切回同一对象时，共用原有位置、持物、朝向与动作进度，分页不会重置现场。同一动作或台词跨切可以正确成立，返回已有机位也可以成立；06须按既定进程安排取景重心和可见关系，不强迫每镜新增情节，也不靠远近交替或每镜换轴制造差别。

### 先从04全部轴线中决定怎样观看

实际查看04场地图，找到当前阶段所有实际关系轴、视线轴、运动轴及成立／改变事件。按02拍法和05当前切换的对象选择本镜头组的摄影主轴，决定初始观看侧，再逐镜设计相对位置、高低、拍向和画框。04未选观看侧是正常交接，不是缺材料；不能要求04代定摄影主轴或把现场方位直接抄成银幕左右。

多条轴同时存在时，按当前要表现的交流、观看或行动关系组织摄影，保持其他关系可理解；不能把所有轴两侧的限制同时求交，把相机挤到唯一位置。选择另一条主轴不等于可以清空前镜已经建立的方向。需要换主轴或换侧时，06采用能看清关系转接的共同画面、可见的人物转向／位置变化或连续过轴等具体承接；插入特写、翻页或改轴名称本身不算重新建立空间。05同步必要切点，07落实已定连续运动。实际观看侧可以保持而拍向、远近、高低和主体组合变化，不能以保持轴线为由固定所有画框。

把04阶段与所用关系引用、06采用的摄影主轴／观看侧、相对机位和必要方向承接简写进已有`camera.placement`。有既存`axis_ref / axis_events`时沿用引用记录采用关系及转换，不新增逐镜轴线分析表，也不把摄影选择回写成04现场。普通镜沿既定组内决定简写，变化处才写清承接。缺的若是人物／目标位置、朝向、路线或遮挡事实，交04补齐；改变观看侧或摄影主轴由06处理，改变切点交05，改变人物行动才回04。不能镜像现场、挪人或反转运动方向来拼构图。

### 再把设计写成能画出来的指令

依02观看任务、04现场和05剪辑，对尚未定下的相邻镜组比较真正不同的可行画框组织，再采用一套；比较须落到实际裁边、可见对象、相对大小、观看位置与遮挡，不能只是换景别名称或情绪词。推演尺度、方向、注意交接及动作阶段的方法见[从剪辑方案到镜头设计](references/从剪辑方案到镜头设计.md)。相同景别可以承载不同有效信息；使用已有机位时承接当时已经推进的表演和状态，不为远近交替增加镜头。

逐镜采用的自然语言必须落下以下可见关系，而不只是术语或情绪：

- 根据04实际关系和06本组采用的方向衔接，从哪一侧、什么相对高度和拍向看，形成何种透视。
- 景别对应的实际取景边界：身体裁到哪里，哪些对象完整入画或留在画外。
- 主体在画框的具体区域、相对大小与留白方向，画面主次怎样形成。
- 前后层次、谁遮住谁、空间边线怎样收束；必要的视线、持握和接触在哪里可读。
- 代表时刻谁必须清楚、哪些层次同时可辨、哪些只能认出轮廓或仍不可辨；清晰关系用文字交接，不让几何线稿承担虚化渲染。

以上是设计必须解决的内容，不作为交付分栏。已有`composition.scale_in`记录代表景别，`camera.placement`记录合法视点，`composition.frame_description`以一段自然语言记录实际画框和清晰关系；必要时用现有`note`标注清晰要求。几何关系进入组页绘图输入，景深文字随采用画格交接给第二层，不精画虚化。少量必要的相对关系说准即可，不填米数、角度、焦距、光圈或位置百分比。不能只给“中景、侧拍、有压迫感”，把画框设计留给生图模型。

人物采用简化形体，仍需推演完整身体的比例、关节、重心和接触。表演取04这一刻已有的姿态与视线，不在此新增动作或神情；空镜也只选择完成本镜任务所需的空间骨架。高阶按H编号落实代表时刻的尺度、透视、遮挡等关系，完整运动留给07。图形信息要能在05采用的镜长内被读懂；先在06职责内调整取景、信息层次及代表时刻。只有具体证明既有切点或用时与已定上游相冲突、用可行画框仍无法实现，才按必读方法反馈05统一修订；相邻图相似、同一动作跨切或景别相同都不是并镜依据，06不得自行放长、并镜或删切。

### 定清透视、景深与观看条件

**透视决定空间怎样被看见。** 比较本镜需要明显的近大远小、较平缓的尺度差还是纵深压迫，在本组采用的方向关系与04真实空间内选相对观看位置和取景范围。采用指令必须指出哪些对象构成大小参照、遮挡如何变化、空间向哪里收束；不能只填“广角感／长焦感”。透视关系、焦距带来的取景变化及光学畸变分开判断；身体比例异常不能借“广角”合理化。特殊形变沿02采用方案。

**景深决定哪些空间层次能被认清。** 从02的信息关系作选择：近远事件须同时读懂，就让对应层次同时可辨；此刻只应认清一人，就明确其他层只能辨认到什么程度；本镜要焦点交接，就选定代表图处于交接前、中或后的哪一刻及该刻清晰对象。普通深景深不自动算高阶，已定双焦点等特殊机制保留02依据。明确“谁清楚、哪些同时清楚、模糊层还能辨出什么”，不能仅写“浅景深”或默认人物清楚、背景全虚。前中后景的空间分层、雾遮挡、暗部隐藏和景深虚化分别落实，不能相互替代。

第一层线条保持简单，统一粗细不代表所有层次最终都清晰；景深以画框文字或独立短注表达，第二层据此渲染。07承接该清晰状态与02方案决定焦点变化的触发和过程，不从另一焦点状态开始却把本图误作首帧。

**画框还要承接观看立场与剪辑。** 严格POV按角色眼位关系成立，普通近身观察不冒称主观视点；视线要能对应04的实际对象。按项目真实画幅设计裁切、头部余量、视线及动作所需空间，不机械套居中或三分法，不靠生成后裁切修正主体位置。检查关键轮廓是否无意粘连、背景线是否穿过重要接触、遮挡是否改变知情；这些属于几何设计，不需增加细节。沿05方法比较相邻镜的注意落点、动作阶段与方向，按既定密度保持可读，不因轻微换角度就认定有有效切换。

### 故事板只画几何镜头示意

第一层固定采用**无五官人体块＋场地几何骨架＋必要道具轮廓**，白底、清楚的轮廓线；确需区分人物或遮挡层时使用少量平涂，跨页沿用同一对应。不能把“线稿”“草图”理解为精细素描或完成度较低的插画。

| 对象 | 第一层实际画到哪里 |
|---|---|
| 人物 | 无五官的头部体块、躯干和简化四肢。保留身份可区分的体型、头身朝向、重心、视线方向与关键接触；手只画清抓、握、推等必要关系。不画表情、发丝、服饰轮廓装饰、褶皱和人体肌肉细节。 |
| 场地 | 地面与墙面的边线、门洞、必要高差、遮挡块和辨认空间所需地标。只保留支持机位、透视、位置或行动关系的结构，不画砖缝、破损纹理、陈设装饰和环境气氛。 |
| 道具 | 支持本镜因果的基本轮廓、位置、持握和朝向。刀与符纸要能分清，雕花、材质和装饰不画。 |
| 明暗 | 常规光影、投影、渐变、排线、光束、雾效与材质高光全部留到第二层。只有02已定的剪影、暗处隐藏或亮区揭示直接决定画框时，才以单一明暗块或遮挡块标出可见范围；不画照明效果。 |
| 景深 | 不绘制模糊、散景或镜头质感。清晰对象、清晰范围及不可辨区域用画框文字／独立短注记录，单镜渲染执行；文字决定不可因简化线稿被省略。 |

**删去某个绘画细节若不改变机位判断、景别、透视、主次、遮挡或关键动作关系，就删去；影响清晰、显露或表演的采用决定仍通过文字保留。** 第一层的表情和服装不细画，不代表取消04表演或03状态；第二层从原件恢复，不能从几何人偶自行猜测。镜号、名字、清晰短注及动作／视线箭头由独立标注层承载，净图不画说明文字。

> **故事板提示词**　绘制［镜号顺序、宫数与排列］的几何镜头故事板，每宫一镜，各格使用［项目画幅］。用无五官头部体块、简化躯干和四肢表示人物，用门洞、墙地边线和遮挡块表示场地，用基本轮廓表示必要道具；白底、轮廓线和区分主体的少量平涂，不画表情、服饰细节、材质、装饰、排线或渲染光影。［04图］提供真实空间、全部实际轴线及其阶段变化，不是摄影机位图；［前页采用宫］只衔接既定关系。逐宫写「［镜号／代表时刻］：依据［04阶段及关系引用］，采用［06已定摄影主轴、观看侧与必要方向承接］，从［相对机位、视高和拍向］看；［景别及实际裁切边界］；［主体区域、大小、留白、前后层次、透视与遮挡］；［已有姿态、视线或必须露出的接触］」。禁止单人半身／全身居中摆放、双人居中平排对峙及其他中景居中画面。各宫净图不含文字，镜号与箭头另层叠加。

跨页生成时，实附上一页已采用的相邻宫，指明继承的空间、体型、状态与方向；上一宫为局部时，再附最近能说明同场关系的一宫，同时读取相同04阶段。画框按本镜决定变化，现场不能随页面改变。

## 第二层：Gemini 真人质感与光影塑形

调用项目内的 [Nano Banana 2.1 技能](../nano-banana-2-1/SKILL.md)，使用 `gemini-nano-banana-2.1`，保持同一个06执行者承接。先明确原生图的镜头约束，再写本镜的真人表现与布光，实际传入图像字节；仅写路径、镜号或“参考上一张”不算附图。调用、密钥、尺寸、格式及错误处理遵循该技能，不自行更换模型。

当前默认目标为**真实演员在搭建实景内拍摄的电影画面，具有专业摄影棚控光、自然肤质和更鲜明的明暗塑形**。保留年龄、身份特征、体型、服装与当场状态，落实自然毛孔、细纹、发丝、布料及实物反射；棚拍指受控实景布光，不把剧情场景改成影棚背景纸，不新增灯架或摄制人员。避免蜡皮、塑料感、游戏渲染感、插画描边与全局锐化。用户另有明确画风要求时按该要求处理表现，镜头几何仍必须锁定。

第一层采用后，镜头设计作为单张的约束，但原页已采用、已有`adopted`记录或用户已授权，都不能代替本轮实际裁图检查。每一镜必须完成下面的检查与放行，才可发出任何正式单镜渲染调用；错误骨架、比例、透视和跨镜关系先在几何草稿中修正，不能交给彩色渲染“顺便修好”。通过后的单张只发展画面表现，不另选景别、机位、透视、主体位置或动作时刻；设计本身需要改变时，先同步对应故事板和设计数据，涉及上游则沿既有职责交回。

接续已有原生单镜图的重绘时，可直接使用其有效镜头设计和原图完成同等范围的几何检查；通过后作为Gemini的镜头依据，无须为套新流程另画一次故事板。源图是既有彩图也不代表真人质感已经完成，仍须按本次要求重绘。有效原生设计图属于必要交付依据，保留可追溯的正式来源；只保存采用来源与最终图，不保存多轮候选、失败样张或API请求响应。

### 裁图检查与放行：每镜必经

1. **裁出并实际查看本镜。** 由有效`sheet_ref`及实际`panel_region`无损提取完整画框，保持项目画幅，不挤压拉伸。裁图放本次`临时/`目录，正式依赖仍由采用源页和裁切区域重建。实际打开裁图，不能只看缩略组页或用文件存在、尺寸正确代替画面检查。
2. **带着相邻关系看。** 同时查看上一剪辑镜的采用画格；已有正式图时也对照。遇交叉剪辑、切出后返回或场景切换，另找同一行动线最近的有效画格及04现场，不能只比最近一张图。读取05切点和各图代表时刻，把04在两时刻间已经发生的动作、画外推进计入比较；代表图通常不是切口帧。首镜没有前镜时按上游现场建立依据。前镜也可能画错，冲突必须回查02／04／05和有效06设计确定源头，不把前图当绝对真值。
3. **一次合并检查本阶段实际画面，按上述优先级判断影响。** 以下是主要观察方向，并非穷尽清单；结合本镜内容识别其他实质问题，不另建逐项矩阵。关键关系无法辨认、缺少必要依据或尚未实际查看时不能算通过。P3／P4差异不构成未通过。
   - **裁切完整：** 镜号与画格对应正确，已定画框没有被裁掉，无挤压、拉伸或邻宫残留。
   - **形体与归属：** 主体、肢体和道具的数量与身份符合03及当场状态，没有无依据新增、缺失或重复的手、脚、头；按03既定体型与风格判断骨架比例，关节方向合理，手能归到对应人物，持握、支撑、重心和接触成立，没有穿模或断接。正常遮挡、裁出画外、无五官体块和简化手轮廓不是缺肢或结构错误；不把风格化比例改成写实，不强迫草稿补五指或服饰细节。
   - **镜头、景别与几何投影：** 实际画面与采用的镜头视点、相对视高、拍向、景别及取景边界一致；主体大小、留白和前后层次落实构图，近远大小、透视收束、地平与地面、遮挡先后一致，人体与场地服从同一视点的几何投影。不能只看标签或用拉伸、换构图补救错误景别。有空间依据的透视缩短可以成立；无依据多肢、归属不明或关节反向不能用透视掩盖，也不能用变形的人体或道具凑接触。
   - **现场与跨镜连续：** 人物位置、人与人及固定地标的真实间隔、出入口、道具尺度、视线方向与对象关系有04依据；动作阶段、用手、接触和持物沿05切点及各代表时刻接续，没有因切镜换手、重置或无依据移动。
   - **采用画框：** 草稿执行了本镜已定景别、裁边、主体区域、机位、遮挡和代表时刻，没有禁用构图；关键接触与需可读的关系未被遮掉，清晰与隐藏要求有对应画内依据。此轮不查五官精度、服装纹理、材质或光影细节，仍保持几何草稿。
4. **判明真实距离，再集中纠错。** 景别、相机位置／朝向或透视改变可以使主体大小和画面像素间隔改变，不等于人物走动。用04固定地标及对象关系、05经过时间和04已定动作判断真实移动是否能到达，不补米数，不按前镜像素间隔硬拉本镜，也不为接图偷偷挪人或改切点。将本镜P1／P2问题集中直接修复：裁错就从正确源页重裁；画格错误用原生`imagegen`按有效设计、04现场和相关画格修正，保持其他正确关系。P3先放行交用户决定，P4直接通过。实际源头在前镜时只修受影响的错误来源，不能让当前镜迁就它；需要变更现场或时间的，交04／05统一处理。
5. **只验收本次问题，随后放行或待修。** 修后实际查看修正版，只验收本次问题及受影响的相邻接切，不另起整章循环检查。采用源页中的对应画格必须同步为修正版，并同步已有`sheet_ref`、`panel_region`及受影响引用、标注；其他正确画格保持，不能只留临时修图而正式源页仍错，也不能把新旧两图同时当有效参考。实际检查完成、关键依据齐全且无未解决P1／P2问题，就将当前有效源页取得的实际画格放行并实附用于单镜渲染；P3／P4不阻断。仍有P1／P2则本镜待修，缺必要依据则待补，不发渲染调用，不自动循环重绘。

### 承接资产与同场光影

先读02已采用的场级光影美学：本场怎样组织主体塑形、明暗色彩、空气与情绪；再读04为它落实的光源、控光、亮暗光区、补反光及人物进出这些区域的变化。06把它们落实为当前画框中的可见关系，不能只抄光源方向或情绪词。02未细定的常规塑形、背景衬托、色彩和空气细化，由06按既定风格、故事和现场直接采用；需要重选整场表达取向才交02，不把每镜常规设计变成审批。

实附03已确认的风格原图、角色当场造型／状态、场景和必要道具原件；人物母本只供体态身型、长相和发型辨识，当场服装、妆造与状态由对应剧情变体提供，母本的瑜伽衣或背心短裤不作为出演服装。风格按当前用户明确要求确定用色、材质与表现方式；本轮要求真人化时，03原图仍锁定身份、固有色和本场可见状态，不把旧画法或展示照明覆盖到Gemini的真人棚拍表现，也不能把冷灰场景母本的中灰覆盖直接铺满正式图。04确定姿态、表演、持物及现场照明条件。沿[03状态规则](../novel-director-03/SKILL.md#让变体符合本场出演状态)使用真实版本，不能把病弱、伤损等状态恢复成角色母本的常态。缺关键原件时沿03补齐，只标受影响的镜组；若资产需求仍不确定，由03先问用户，明确后制作，06不得在故事板或重绘中自行选定人物妆造、场景和道具设计。

同场沿用已有`lighting_setups`等共用记录，按04光向、遮挡、反射及光区变化推导各镜实际受光，不为每张另造灯位，也不新增重复美术方案。光源合理是现场约束，不能代替光影美感的选择；只有一个主光源时，仍可用已有遮挡、反射和对象受光方向组织明暗。造型所需的控光与补反光须有04条件，不必都变成画内可见灯具，也不为好看擅自增加火把、出口光或月光。人物外观、表情、服装和场景细节在这一层完整落实，新增装饰不能挡住第一层保留的因果与接触。

色彩先分清03的固有色、04的现场光色和02采用的色彩关系，再决定本镜肤色、衣物和关键物体哪些颜色保留、受光与暗部怎样变化、如何与环境分开。同场沿用已有`look_setups`或实际采用输入，不每镜另套滤镜，也不靠统一增饱和或提高对比度替代设计。材质的反射、透射、粗糙或湿润表现依据资产和当场状态；镜像与实体、影子与光源要对应，不凭渲染增加人影或线索。光晕、拖影、颗粒只沿已定风格／机制采用。

空气表现也要选择：04已有雾、烟或尘时，明确它位于哪些空间层，哪些受光、哪些压暗，主体周围及关键接触怎样保留可读范围；雾可以有明暗、色彩和已有侧逆光形成的层次，不默认整场铺灰。没有现场依据就不添雾。黑暗、冷色、恐怖和有雾均不自动等于大面积同一中灰；亮部、暗部与空气要共同保住本场采用的主次、颜色和情绪，不能用泛白高光、通篇提亮、浓雾或强虚化遮掉关键关系。

**光影更有力度，明暗反差更鲜明，体积感和空间层次更突出；具体表现服从当前分镜内容、情绪和导演意图。** 力度按02采用的美学建立，可以是高反差、柔和漫射、低调或其他既定方案下更明确的主次与塑形，不等于所有镜头硬光、大黑、逆光、蓝橙、脸必亮或高饱和。裁图检查放行后，以有效草稿为依据，先忽略纹理与小高光，按以下四项作出本镜实际选择：

1. **明暗主次。** 选出当前画框先读的形体或关系，明确它的哪一片形成阅读亮面，哪一片保留暗，次要区域显露到什么程度；用亮暗面积与边界组织先后顺序，不把每个人、雾和地面都抬到同一中灰。
2. **形体转折。** 按04实际光方向、本镜视点和对象朝向推导受光面，选定亮面怎样转入暗面、边缘怎样保留；需要时使用已有软硬光、填充、反射或遮挡，让本镜关键形体有体积。不要只写“重光影”，也不把每张人物脸补成同样正亮。
3. **空间分层。** 决定用哪片背景衬托主体，它比主体更亮、更暗或在色彩上怎样分开；近中远哪些区域退下、哪些保留辨认。把采用的肤色、衣物和物体颜色落实到这套关系；有空气介质时同时定其受光层、暗层与不遮主体的区域。侧光、边缘光、光束或窗影仅按当前场地需要选用，不机械加满。
4. **跨镜连续。** 随本镜机位与人物朝向重新推导同一现场的受光、遮挡和背景衬托，日夜、天气、光色及变化遵守04。不能直接复制前镜的银幕左亮右暗；真实关系相同时可以沿用，不为每镜不同而换色、改灯或改变整场审美。

同场通用段只统一光源条件和色彩关系；实际每镜`board_art_generation.prompt`必须把本镜采用的明暗主次、形体转折、背景衬托、颜色及适用的空气表现放在前部写清，不能全场只复用一段“重光影／冷灰漫射光”，也不能被长串服装细节和通用限制挤成末尾一句。已由裁图与资产明确的内容精简引用，必要约束保留。已有关系确实相同可沿用具体决定，不机械制造差异。改变现场灯位、控光或光区交04，重选整场美学交02；06常规细化直接采用。用户已明确“灰、不美”的旧样张不能继续充当同场光影美感基准，也不能沿旧采用记录声称这套美学已获用户认可。保留03风格的色面、材质与塑形表现力，第二层不换构图；第一层简单明暗块仅限定隐藏或显露，仍不画渲染光影。塑形与填充方法可参考[ASC布光讲解](https://theasc.com/article/lighting-a-set/)。
