# 06｜故事板设计与单镜渲染

本步固定三轮：**①原生imagegen画几何故事板；②裁图检查后，原生imagegen另行生成独立单张分镜；③单张检查通过后，Gemini Nano Banana 2.1重新渲染真人质感与光影。** 制作顺序为“整段镜头设计 → 独立文字检查放行 → 原生故事板及裁图 → 独立几何检查放行 → 原生单张分镜 → 独立单张检查放行 → BANANA重新渲染 → 独立成图检查放行”。裁图、放大或草稿纠错不能充当第二轮，即使裁图无错，每镜仍须完成独立单张生图。三轮使用同一镜号、画框和代表时刻，不能跳过第二轮直接把故事板裁图交给BANANA。

**镜头准确是放行条件，不能被画面好看代替。** 原生图必须能直接读出采用的取景边界、视高与拍向、人物及物件相对大小、前后层次、透视收束、遮挡、视线和接触；写对“景别／镜头／透视”标签不等于图画对了。Gemini没有重新决定这些关系的权限，不能用真人化重摆人物、补造空间、修改动作或修理尚未通过的几何错误。第一轮只测试构图时就在原生图交付后停。

直接读取01表达要求、02采用拍法与场级光影美学、03风格与资产、04场地图及连续走戏、05的`shot_groups[].edit_plan`和逐镜切点。空间、调度、表演、全部实际关系轴／视线轴／运动轴及光声继承04；摄影主轴、观看侧、机位与镜头间的方向衔接由06选择，不要求04预先决定。拍法、高阶效果与本场光影表达取向继承02。镜序、镜数、切点和镜长改变交05；核心拍法或整场光影表达取向改变交02，现场改变交04；07继续负责起落幅、运动或留驻的执行。原有景别、视点、人体与接触、光影及连续性推演保留，交付只留采用结果。

开始设计前完整读取[分镜设计职责与交接](references/分镜设计职责与交接.md)及[从剪辑方案到镜头设计](references/从剪辑方案到镜头设计.md)，并按后者读取05的剪辑方法定义，再按其顺序完成整段设计。主动处理本段涉及的视点、画幅、视线、透视、景深、动作状态、光色材质与跨镜衔接。02未细定的常规画面决定由06在既定观看任务内完成，不把它们留给生成工具默认选择，也不为每项细化退回02。方法参考不复制成交付检查表。

**禁止中景居中。** 单人半身／全身居中摆放、双人居中平排对峙的展示式画面均禁用；不以改称全景、轻微偏移或斜拍绕过，按实际画面关系判断。中景可以采用明确的非居中组织；两人对峙可以采用非中景取景、人物分居两侧，并以机位、纵深、遮挡或留白建立明确关系。基础、高阶、故事板与正式单图同样遵守。不用歪斜地平线或强加遮挡来装饰性规避，也不能为此越轴、挪人或改变既定接触。

## 独立执行与交接

06的新制作、重跑、镜头设计改写及单镜修复，无论单步还是连续委托，都由主 Agent 新建一个独立上下文子智能体执行；可指定时使用`fork_turns="none"`。同一任务内由既有执行者续作与修复。首次交接项目与章节路径、授权范围、有效原件及版本、已有确认、用户约束、可改文件和停止点；执行者完整读取本 Skill、必读参考、项目说明、本范围01—05及必要相邻材料后设计，不以生产聊天或剧情摘要替代。后续只接收变化和新增范围，复用已读有效依据，按镜组补读受影响内容，不重复全文加载。

同一个执行者负责授权范围内整段连续设计和三轮落地，不按页面或镜号分派成互不相干的设计任务，也不递归委派06。按既定连续关系划分送检镜组，三轮沿该分组交接；逐镜生图不等于逐镜汇报。前置已放行且互不依赖的生成请求可并发，文件与真实来源由同一执行者串行登记，组内结果齐备后统一送检；具体例外沿下述独立检查协议。只测第一轮就在第一轮交付后停。子智能体不可用时说明限制，不能由主 Agent 代写后声称独立执行。

主Agent另建独立上下文的检查子智能体，按[独立检查与放行](references/独立检查与放行.md)对照上游完成四关检查。每批仍实际查看全部应检图像及必要接续，一批集中回报一次；主Agent核对范围与版本后一次传达放行或修正。制作与检查不在同一聊天，检查者不继承制作推演或自我通过结论；制作方负责设计、生成、技术验证与修复，不重复专业检查或自行放行，主Agent不另做专业复审。

主Agent管范围、原件与版本交接及必要上游修订，不预填镜头设计。`05_拍摄设计.json`由制作方串行维护，检查者只读；需改02、04或05时列出具体冲突交主Agent转原负责步骤，统一版本后接续。相关范围在收到对应关的独立放行前不得进入下一轮；独立检查不能替代用户审定或完整阶段的完成条件。

## 图像审核优先级

这是一套按影响程度决定处理方式的原则，不是检查项目的封闭清单。用户和文中的例子只帮助理解轻重，不限定检查范围，也不预先决定同类问题的级别。检查者须结合本镜任务、有效设计、实际画面和前后关系主动识别问题；未列举的情况同样适用，不能因未在例子中出现就漏判，也不能按物件名称或关键词机械判级。 同一原则也用于生图前的文字设计：不能实现的画框或与上游矛盾的关系按实际影响处理，不等生成错误后再检查。

判断依据是：画面是否成立，放回上下文是否造成实质矛盾，是否影响观众理解、主要表达或动作完成，以及影响有多明显、多重要。这些也是综合判断的方向，不是要求逐项填满的表。先看正常观看时的实际效果，再为具体疑点查看局部；不放大寻找无关瑕疵。先处理P1、P2，生成仍以采用设计为目标，验收不要求逐像素一致。

| 优先级 | 按实际影响判断，不限定问题类型 | 处理 |
|---|---|---|
| P1：画面本身明显不成立 | 不论发生在哪个对象或表现环节，实际画面存在明确、显著的错误，已经破坏其基本可信性与可用性；不能用有意设计或正常观看变化合理解释。 | 必须修。在已委托的制作／修复范围内直接定向修正，无须再问用户；几何源图错误先修原生图，正式图新增错误由06修正式图。 |
| P2：内容或关系存在重大错误 | 单张可能看似成立，但与有效设定、本镜表达任务或前后关系存在明显、实质性的冲突，使观众误解事件，或破坏连续性、关键表达与行动成立条件。 | 必须修。在已委托范围内直接处理，无须再问用户；查明真实来源，按原负责步骤修正必要成果及依赖，不改已定剧情来迁就错图。 |
| P3：影响有限的可选调整 | 差异可察觉，但主要表达、剧情理解、动作与连续关系仍成立；影响次要，或属于有选择余地的表现取舍，尚不足以判定成图不可用。 | 该镜先放行，不阻断制作；阶段交接仍按完整范围判断。一次集中列为可选调整，让用户决定；用户未要求修改前不重画，不记为阻断或待修。 |
| P4：无影响的微小差异 | 不指出便难以察觉，且不违背剧情、不影响动作、连续性和主视觉阅读。 | 完全放行；不列待办、不要求确认、不触发重画。 |

同一种偏差在不同镜头中可能属于不同级别，按本镜实际作用和后果判断，不给某类对象设置永久必修或永久豁免。例如一个锁扣是否重要，取决于它是否参与当前表达或行动；这是判断方法的示例，不是“锁扣规则”。任何拒收都须有具体可见影响，不能仅以“与文字不完全一致”为理由。用户明确的构图禁令和内容约束仍执行，但不得把无影响的微差包装成违反设计。

独立检查者在每个放行点的一次合并检查中判级并回报主Agent，06制作方按结论定向修复。修后仍由检查者只确认本次P1／P2问题及受影响接切；按既有限次规则处理仍未解决项，不滚动搜新瑕疵、不自动循环全章。P3仅在现有观察备注或汇总中一次说明，P4无需记录；不新增评分、审核矩阵或逐镜优先级字段。用户明确只检查不改、只讨论方法或指定停点时，遵守该范围，不据此启动生产或扩大修改。

## 第一轮：把镜头设计落实为画框指令

先按必读方法把05整段`edit_plan`、节奏区间及镜表还原成连续观看顺序，明确每个切口从什么对象／关系接到什么对象／关系、动作和话语推进到哪里，再选摄影主轴、观看侧及相邻画框。不能读一条镜表就独立生成一张图。决定整段观看关系后，在04连续进程与05各镜入出点内选代表时刻，落实实际裁边、透视、遮挡和清晰关系。分镜表与对应画框指令完成后，交独立检查者按[一次设计检查](references/从剪辑方案到镜头设计.md#分镜表完成后的一次独立检查)核对上游约束、设计内部是否相容、面向关系及完整镜序中同场非相邻、跨段、跨页的重复取景与组合；制作方完成必要修订并获放行后，再据通过版本写生图输入、分页和渲染。

每个摄影镜头只选一刻，每宫对应一个镜号；黑场沿05时间线保留，不另造摄影画面。代表时刻不默认等于首帧，也不等于前后切口；同场、跨页及切回同一对象时，共用原有位置、持物、朝向与动作进度，分页不会重置现场。同一动作或台词跨切可以正确成立，返回已有机位也可以成立；06须按既定进程安排取景重心和可见关系，不强迫每镜新增情节，也不靠远近交替或每镜换轴制造差别。

### 先从04全部轴线中决定怎样观看

实际查看04场地图，找到当前阶段所有实际关系轴、视线轴、运动轴及成立／改变事件。按02拍法和05当前切换的对象选择本镜头组的摄影主轴，决定初始观看侧，再逐镜设计相对位置、高低、拍向和画框。04未选观看侧是正常交接，不是缺材料；不能要求04代定摄影主轴或把现场方位直接抄成银幕左右。

多条轴同时存在时，按当前要表现的交流、观看或行动关系组织摄影，保持其他关系可理解；不能把所有轴两侧的限制同时求交，把相机挤到唯一位置。选择另一条主轴不等于可以清空前镜已经建立的方向。需要换主轴或换侧时，06采用能看清关系转接的共同画面、可见的人物转向／位置变化或连续过轴等具体承接；插入特写、翻页或改轴名称本身不算重新建立空间。05同步必要切点，07落实已定连续运动。实际观看侧可以保持而拍向、远近、高低和主体组合变化，不能以保持轴线为由固定所有画框。

把04阶段与所用关系引用、06采用的摄影主轴／观看侧、相对机位和必要方向承接简写进已有`camera.placement`。有既存`axis_ref / axis_events`时沿用引用记录采用关系及转换，不新增逐镜轴线分析表，也不把摄影选择回写成04现场。普通镜沿既定组内决定简写，变化处才写清承接。缺的若是人物／目标位置、朝向、路线或遮挡事实，交04补齐；改变观看侧或摄影主轴由06处理，改变切点交05，改变人物行动才回04。不能镜像现场、挪人或反转运动方向来拼构图。

### 再把设计写成能画出来的指令

依02观看任务、04现场和05剪辑，对尚未定下的相邻镜组比较真正不同的可行画框组织，再采用一套；比较须落到实际裁边、可见对象、相对大小、观看位置与遮挡，不能只是换景别名称或情绪词。推演尺度、方向、注意交接及动作阶段的方法见[从剪辑方案到镜头设计](references/从剪辑方案到镜头设计.md)。相同景别可以承载不同有效信息；使用已有机位时承接当时已经推进的表演和状态，不为远近交替增加镜头。

逐镜采用的自然语言必须落下以下可见关系，而不只是术语或情绪：

- 根据04实际关系和06本组采用的方向衔接，从哪一侧、什么相对高度和拍向看，形成何种透视。
- 景别对应的实际取景边界：身体裁到哪里，哪些对象完整入画或留在画外。
- 主体在画框的具体区域、相对大小与留白方向，画面主次怎样形成。
- 前后层次、谁遮住谁、空间边线怎样收束；人物的身体朝向、头部转向、目光目标及从本机位可见的脸部，须与目标的高低和纵深相容；持握和接触在哪里可读。
- 代表时刻谁必须清楚、哪些层次同时可辨、哪些只能认出轮廓或仍不可辨；清晰关系用文字交接，不让几何线稿承担虚化渲染。

以上是设计必须解决的内容，不作为交付分栏。已有`composition.scale_in`记录代表景别，`camera.placement`记录合法视点，`composition.frame_description`以一段自然语言记录实际画框和清晰关系；必要时用现有`note`标注清晰要求。几何关系进入组页绘图输入，景深文字随采用画格交接给第二轮单张并由第三轮继承，不精画虚化。少量必要的相对关系说准即可，不填米数、角度、焦距、光圈或位置百分比。不能只给“中景、侧拍、有压迫感”，把画框设计留给生图模型。

人物采用简化形体，仍需推演完整身体的比例、关节、重心和接触。表演取04这一刻已有的姿态与视线，不在此新增动作或神情；空镜也只选择完成本镜任务所需的空间骨架。高阶按H编号落实代表时刻的尺度、透视、遮挡等关系，完整运动留给07。图形信息要能在05采用的镜长内被读懂；先在06职责内调整取景、信息层次及代表时刻。只有具体证明既有切点或用时与已定上游相冲突、用可行画框仍无法实现，才按必读方法反馈05统一修订；相邻图相似、同一动作跨切或景别相同都不是并镜依据，06不得自行放长、并镜或删切。

### 定清透视、景深与观看条件

**透视决定空间怎样被看见。** 比较本镜需要明显的近大远小、较平缓的尺度差还是纵深压迫，在本组采用的方向关系与04真实空间内选相对观看位置和取景范围。采用指令必须指出哪些对象构成大小参照、遮挡如何变化、空间向哪里收束；不能只填“广角感／长焦感”。透视关系、焦距带来的取景变化及光学畸变分开判断；身体比例异常不能借“广角”合理化。特殊形变沿02采用方案。

**景深决定哪些空间层次能被认清。** 从02的信息关系作选择：近远事件须同时读懂，就让对应层次同时可辨；此刻只应认清一人，就明确其他层只能辨认到什么程度；本镜要焦点交接，就选定代表图处于交接前、中或后的哪一刻及该刻清晰对象。普通深景深不自动算高阶，已定双焦点等特殊机制保留02依据。明确“谁清楚、哪些同时清楚、模糊层还能辨出什么”，不能仅写“浅景深”或默认人物清楚、背景全虚。前中后景的空间分层、雾遮挡、暗部隐藏和景深虚化分别落实，不能相互替代。

第一轮线条保持简单，统一粗细不代表所有层次最终都清晰；景深以画框文字或独立短注表达，第二轮据此绘制单张，第三轮保持。07承接该清晰状态与02方案决定焦点变化的触发和过程，不从另一焦点状态开始却把本图误作首帧。

**画框还要承接观看立场与剪辑。** 严格POV按角色眼位关系成立，普通近身观察不冒称主观视点。按[面向关系设计方法](references/从剪辑方案到镜头设计.md#把现场面向落实到摄影画框)从04实际目标推导头身、目光与机位的关系；正反打成对成立，不能把屏幕左右对应当成真实对视。按项目真实画幅设计裁切、头部余量、视线及动作所需空间，不机械套居中或三分法，不靠生成后裁切修正主体位置。检查关键轮廓是否无意粘连、背景线是否穿过重要接触、遮挡是否改变知情；这些属于几何设计，不需增加细节。沿05方法比较相邻镜的注意落点、动作阶段与方向，按既定密度保持可读，不因轻微换角度就认定有有效切换。

### 故事板只画几何镜头示意

第一轮固定采用**无五官人体块＋场地几何骨架＋必要道具轮廓**，白底、清楚的轮廓线；确需区分人物或遮挡层时使用少量平涂，跨页沿用同一对应。不能把“线稿”“草图”理解为精细素描或完成度较低的插画。

| 对象 | 第一轮实际画到哪里 |
|---|---|

### 裁图检查与放行：每镜必经

1. **制作方裁图，检查者实际查看。** 制作方由有效`sheet_ref`及实际`panel_region`无损提取完整画框，保持项目画幅，不挤压拉伸。裁图放本次`临时/`目录，正式依赖仍由采用源页和裁切区域重建。检查者实际打开裁图，不能只看缩略组页或用文件存在、尺寸正确代替画面检查。
2. **带着相邻关系看。** 同时查看上一剪辑镜的采用画格；已有正式图时也对照。遇交叉剪辑、切出后返回或场景切换，另找同一行动线最近的有效画格及04现场，不能只比最近一张图。读取05切点和各图代表时刻，把04在两时刻间已经发生的动作、画外推进计入比较；代表图通常不是切口帧。首镜没有前镜时按上游现场建立依据。前镜也可能画错，冲突必须回查02／04／05和有效06设计确定源头，不把前图当绝对真值。
3. **一次合并检查本阶段实际画面，按上述优先级判断影响。** 以下是主要观察方向，并非穷尽清单；结合本镜内容识别其他实质问题，不另建逐项矩阵。关键关系无法辨认、缺少必要依据或尚未实际查看时不能算通过。P3／P4差异不构成未通过。
   - **裁切完整：** 镜号与画格对应正确，已定画框没有被裁掉，无挤压、拉伸或邻宫残留。
   - **形体与归属：** 主体、肢体和道具的数量与身份符合03及当场状态，没有无依据新增、缺失或重复的手、脚、头；按03既定体型与风格判断骨架比例，关节方向合理，手能归到对应人物，持握、支撑、重心和接触成立，没有穿模或断接。正常遮挡、裁出画外、无五官体块和简化手轮廓不是缺肢或结构错误；不把风格化比例改成写实，不强迫草稿补五指或服饰细节。
   - **镜头、景别与几何投影：** 实际画面与采用的镜头视点、相对视高、拍向、景别及取景边界一致；主体大小、留白和前后层次落实构图，近远大小、透视收束、地平与地面、遮挡先后一致，人体与场地服从同一视点的几何投影。不能只看标签或用拉伸、换构图补救错误景别。有空间依据的透视缩短可以成立；无依据多肢、归属不明或关节反向不能用透视掩盖，也不能用变形的人体或道具凑接触。
   - **现场与跨镜连续：** 对照04检查真实位置、间隔和目标；同框、正反打及切回中的头身朝向、可见脸部、俯仰与目标纵深能否共同成立。画外对象也按原位判断，侧看不自动等于看向后景，左右相反不自动等于对视；轮廓无法辨明关键朝向时不能靠提示词或箭头判通过。动作阶段、用手、接触和持物沿05切点及代表时刻接续，没有因切镜换手、重置或无依据移动。

每个光色状态从本场已有或计划制作的镜头中选一幅能看清主要色彩关系的正式图作固定基准。已有有效采用图直接沿用；没有时先完成该代表镜，按既有样张审定或自主定稿授权采用后再展开同组制作，不另造测试镜或新增审批。将基准镜号及正式路径写入同一`look_setups`说明，后续每镜调用均实附这张固定图，只借它的光色，不借其机位、构图或人物姿态；不能仅附前一镜而逐张传递色偏。新光线状态另立对应基准，切回原状态仍用原基准。

03原件只管固有色、身份和材质，资产展示照明不能覆盖光色基准。每镜按04光区推导肤色、衣物与场景物体的实际受光；换拍向可以改变亮暗面及冷暖光在画中的面积，不能无依据把整场冷白改成暖黄。材质反射、透射和湿润表现沿资产及状态，光晕、拖影、颗粒沿已定机制，不另套滤镜或增加线索。

空气表现也要选择：04已有雾、烟或尘时，明确它位于哪些空间层，哪些受光、哪些压暗，主体周围及关键接触怎样保留可读范围；雾可以有明暗、色彩和已有侧逆光形成的层次，不默认整场铺灰。没有现场依据就不添雾。黑暗、冷色、恐怖和有雾均不自动等于大面积同一中灰；亮部、暗部与空气要共同保住本场采用的主次、颜色和情绪，不能用泛白高光、通篇提亮、浓雾或强虚化遮掉关键关系。

**光影更有力度，明暗反差更鲜明，体积感和空间层次更突出；具体表现服从当前分镜内容、情绪和导演意图。** 力度按02采用的美学建立，可以是高反差、柔和漫射、低调或其他既定方案下更明确的主次与塑形，不等于所有镜头硬光、大黑、逆光、蓝橙、脸必亮或高饱和。第二轮单张检查放行后，以该单张及采用设计为依据，先忽略纹理与小高光，按以下四项作出本镜实际选择：

1. **明暗主次。** 选出当前画框先读的形体或关系，明确它的哪一片形成阅读亮面，哪一片保留暗，次要区域显露到什么程度；用亮暗面积与边界组织先后顺序，不把每个人、雾和地面都抬到同一中灰。
2. **形体转折。** 按04实际光方向、本镜视点和对象朝向推导受光面，选定亮面怎样转入暗面、边缘怎样保留；需要时使用已有软硬光、填充、反射或遮挡，让本镜关键形体有体积。不要只写“重光影”，也不把每张人物脸补成同样正亮。
3. **空间分层。** 决定用哪片背景衬托主体，它比主体更亮、更暗或在色彩上怎样分开；近中远哪些区域退下、哪些保留辨认。把采用的肤色、衣物和物体颜色落实到这套关系；有空气介质时同时定其受光层、暗层与不遮主体的区域。侧光、边缘光、光束或窗影仅按当前场地需要选用，不机械加满。
4. **跨镜连续。** 同时对照固定光色基准和相邻镜，比较相同光区中的肤色、白色物件与固定场景材料是否接得上；结合04判断亮暗变化是否来自真实转向、遮挡或光源事件。画面取景不同造成的总体色彩比例变化可以成立，不要求全图平均颜色一致，也不复制基准的银幕左亮右暗。

每镜实际`board_art_generation.prompt`先写出同一`look_ref`的共用光色要求并指明固定基准附件，再写本镜因视点、朝向、遮挡及光区产生的具体明暗塑形。共用部分从同一采用记录取用，不逐镜另写一套冷暖；只写ID、“同上”或“保持一致”不足以交给生图。保留本镜的亮暗主次、形体转折、背景衬托和空气表现，不能用通用“重光影”代替。用户已否定的样张不能充当基准；第一轮锁几何，第二轮落实独立单张，第三轮在同一光色内增强表现。塑形与填充可参考[ASC布光讲解](https://theasc.com/article/lighting-a-set/)。
