# 07｜运镜提示词设计

本步把已审分镜发展成**能够被执行的运动或固定镜头提示词**。输入是本段原文、02的基础拍法与高阶设计点、04的连续走戏与声音设计、05的段落剪辑方案（`shot_groups[].edit_plan`）及逐镜时码、06的正式图。按各镜 `board_art` 实际查看本镜及前后镜的最终单张彩图，采用的构图、人物关系与光影由这些原件确定；构图组页用于追溯。本步交付范围止于提示词设计。

**职责与输出边界：** 02定拍摄方案，05定剪辑，06定景别、静态机位、构图及代表时刻；07把已定方案展开为整镜的运动或留驻执行，确定触发、先后、路径、速度变化、起落幅与经过代表图的时刻。代表图只是整镜中的一刻，前后取景在既定拍法、现场和切点内发展，不另改已审画框。保留动静比较、视点和焦点配合、节奏与连续性推演，交付只写采用的过程。核心拍法变化交02，现场或表演变化交04，剪辑变化交05，代表画面变化交06，不借运镜重写这些决定。

06的原生imagegen图准确决定构图、镜头、景别与透视，检查通过后由Gemini Nano Banana 2.1完成真人质感和光影的正式单张，两者镜头关系必须一致。07沿用[06图像审核优先级](../novel-director-06/SKILL.md#图像审核优先级)的已有放行结论：P3可选调整不阻断，P4不重新列问题；新发现的明确P1／P2集中交回06处理受影响镜头，不另起整章复审。07引用`board_art`的最终采用图，不把原生几何图或仅生成未采用的Gemini图当作正式结果；历史已采用原图沿有效版本读取，不追写虚假工具来源。07从04读取全部实际轴线及现场事件，从06已有镜头设计读取采用的摄影主轴、观看侧与方向转换方案，细化运动执行；不能把04的全部轴线同时当禁越边界，也不因运动自行换边或重摆人物。改变摄影方向与承接先交06，改变实际现场才交04。沿用主Agent的构图禁令：起幅、留驻与落幅均不设计成中景居中、单人半身／全身居中摆放或双人居中平排对峙，也不借推拉把已审非居中画面收回展示式构图。普通与高阶一致。

按[分镜设计职责与交接](../novel-director-06/references/分镜设计职责与交接.md)读取06代表时刻的清晰对象、清晰范围与光影状态，再从该时刻向前后安排执行。跟焦、移焦、变焦和相机移动分别说清：保持谁清楚、何事触发焦点转给谁、交接时谁变得不可辨、何时经过正式图。02已定近远持续清楚时保留这种关系，不能默认背景虚化；主体前后移动时不能只写“跟拍”而漏掉必要的焦点保持。改变知情顺序交02，改变代表图的清晰状态交06，改变切点／时长交05。

光影和材质的动态变化继承02采用的场级美学、04光区与控光条件、06已经落实的明暗体块及色彩关系。主体进出光区、雾层、反射或透明介质时，写清既有亮面怎样移过身体、背景怎样显露或退暗；相机换角度时按同一现场推导受光，不复制银幕左亮右暗。不能以保持一致为由把变化中的画面统一套灰，也不另换冷暖、饱和或曝光方案。快慢动作、拖影或特殊光学形变只有既定依据才执行，不自行增加曝光闪烁、镜头光晕或随机焦点跳动。常规执行细化由07完成，不要求上游替07逐秒排路径。

02／04 已定的行动、话语与反应并行关系继续成立。摄影机可在交谈和行动进行中启动、跟随或留驻，触发取真正改变注意力的动作或语句；必要停顿沿用表演依据。设计运动时保留同时进行的事件及其进度。镜内运动快慢不代替05的剪辑节奏；若执行必须改镜长或切点，交05同时同步段落方案与镜表，不默默把快切镜延长为普通2—3秒镜头。

## 承接02的高阶设计

**每分钟2–3处高阶设计，包含静态与动态方案。** 读取[高阶设计选型](../novel-director-02/references/高阶设计选型.md)，沿用 02 的 `H` 编号、特殊效果、采用拍法与预计时长，以及 05 的镜号和分钟归属。固定机位的高阶构图、透视或画内调度也计入总数；运镜是其中一种实现方式。组合技法和跨镜发展共用原设计点编号，只计一次。

02负责选型与完整拍摄构想，07根据04现场、05剪辑与06代表图完成执行：动态设计细化路径、视点／焦距的配合、触发、加减速和落幅；静态设计保留既定机位与画框，把04已有的画内变化、注意力交接与留驻时间落实为执行过程。基础平移、推进、跟随和普通遮挡揭示仍按基础动作处理，高阶资格沿用共用标准，不为凑数另创方案。

按本镜方案推演效果如何成立，把摄影机、人物、声音与显露时机连成完整过程。已审分镜是其中的代表时刻，前后变化沿用同一现场。接续旧稿缺少高阶设计时，在授权范围内补 02 对应场次后沿必要依赖更新；新的创意改变既定机制或代表画框时，同步原负责步骤。

在该镜 `intent` 中引用 `H` 编号与特殊效果，`prompt` 写清实际采用的运动或固定方式、事件先后、效果落点与接切。光学变化与机位运动须写清各自如何配合，例如推拉变焦的主体尺寸保持和背景纵深变化。工作中的推演不另做过程文档，交付仍是一镜一段完整提示词。

**上游已确认的长镜头和高阶镜头可以超过3秒，普通单镜最多3秒。** 07根据既定方案、运动、画内事件和辨认时间校准用时，交05分别以`long_take`或`advanced_camera`及来源同步`duration_basis`和声画时序；06同步已有代表帧与显示区间。镜长以05帧段为唯一来源。普通长镜头不自动计入高阶。画框变化交06，段落或总长变化同步04／01及下游08，再核对高阶设计每分钟总数。

## 先决定这一镜怎样发展

1. **找注意力的变化。** 把本镜放回前后镜，确定观众切入时已经知道什么，这几秒要察觉什么，切出时把注意交给哪里。结合本场的情绪与导演拍法，决定摄影机先于人物发现、随人物同行，还是迟半拍跟上。
2. **在既定拍法内比较动与静的执行。** 留驻可以让画内行动、等待或画外声音起作用；摇摄交接方向；移动机位改变遮挡和近远关系；推拉改变距离感；移焦交接清晰对象。POV从角色眼位理解可见范围，手持起伏来自具体身体状态。比较启动早晚、留驻多久、运动幅度与焦点交接怎样完成本镜任务；02已定固定或运动及特殊机制时，以此约束候选。尚未细定的局部执行在该方案内选定。推演运动前后多读到了什么，正文直接写采用的变化，不附选择理由。
3. **把起幅、过程和落幅连起来。** 起幅写实际可见的主体、范围与遮挡；过程写人物正在做什么、同期话语或动作在哪一拍触发摄影机、相机往哪走或转、观众逐渐看见什么；落幅写最后的取景、主体状态，以及是停住等待还是带着动势切出。固定镜同样写画内变化和等待的对象。
4. **安排速度与承接。** 由事件决定先等、起动、追上、变速、停留或带着动势到达05切点。用“肩先转，相机稍后跟上；越过立柱后减速，停在来人的手上”这样的可见关系表达节奏。与前后镜对照银幕方向、采用轴线、动作阶段和视线，依据04现场事件和06方向转换方案细化相机换侧。普通单镜沿用05时长且最多3秒；已确认长镜头和高阶镜头按完整过程校准，再由05同步时长。起落幅与06代表景别共同推演视觉承接，不另加切镜。
5. **让正式图落在正确时刻。** 06选择本镜唯一代表时刻，可能在开头、途中或结尾；07据其代表帧写明何时经过该画面，并向前后推演，不能另指定为首帧。核对的不仅是姿态与构图，还包括该刻谁清楚、谁仍不可辨、光影揭示已发展到哪里。如果正式图已露出信息，不能又写“随后才揭示”；必须改变代表图或切点时分别交06、05同步。光向、人物位置及物件状态沿用同一现场。

推演在工作中完成，交付只留下采用的决定。重点是可见变化、动作先后和摄影机响应，用相对关系说清执行，不默认堆距离、角度、焦距等数字。镜长、必要的代表图时间位置继续保留；光学机制用主体大小与背景变化的配合表达。

## 写成可直接使用的提示词

**一镜一段提示词，对应一张正式分镜。** 每段用自然语言连贯写清：

- 镜头时长、场景与关键主体；参考图决定的构图和光影，以及它在本镜的时间位置。
- 起幅的景别、视点和可见关系；人物的关键动作与摄影机响应各自的先后。
- 移动／转向／焦点的变化、速度起落，运动中要读到的信息，以及遮挡与方向的延续。
- 落幅内容、停留或带速切出，以及与下一镜的承接。

只选择本镜有作用的内容组织成一段。与运镜相关的声音写成触发条件，声音原词与完整时间线沿用 04／05。环境光、景深或特殊效果在会影响显露时机时写进提示词。指代使用明确的角色、物件与方向，让单独收到这一段和参考图的执行者也能理解。

上述条目用于推演，不作为正文分栏。正文不写“起幅：／触发：／过程：／落幅：”指令清单，不另附导演意图、效果说明或逐秒任务表；以“镜头先停在……，人物……时才……，到……便……”这样的自然语言写完整执行。既定动作与话语可同时发生，镜头运动不要求人物停下等待。

## 自然语言输出示例

以下承接05、06的同一组虚构例。02已采用走廊对话中的留驻与随转身轻摇、撤离中的同行拍法，以及独立片段H01的推拉变焦；06已完成相应正式图。实际交付在标题旁引用本镜真实图及代表时刻。

**S001｜2.5秒｜正式图在回身刚开始时**

镜头先停在周川脸上，阿宁画外的“后面有人”继续。他的目光先转，肩膀开始回身时经过正式图中的姿态，摄影机随后顺着肩膀轻摇，阿宁的肩部随之离开画面边缘。周川还没转完便接到下一镜，两人的脚步声不断。

**S002｜2.5秒｜正式图在抓住衣袖时**

从双人偏置中景接住周川尚未完成的回身，阿宁仍向他靠近。两人转为同向后，摄影机沿06采用的消防柜一侧同行，承接04的回身合流，两人留在画面左侧，阿宁处于近层，保留两人上身和抓袖接触，右侧留出通向楼梯口的空间。焦点随两人前移，保持两人的朝向和抓袖接触清楚，楼梯门仍可辨。阿宁抓住周川衣袖时经过正式图，周川的“跟紧，别回头”仍在行进中说完。身后撞门声一响便按05切点切出，摄影机此时仍在同行。

**S010｜6秒｜H01｜正式图在纵深变化将要完成时**

门后的脚步停住时，镜头沿本段06已定观看侧斜对阿宁，以偏置中景让她留在画面左侧，走廊向右侧深处延伸。摄影机朝她靠近，同时缩短焦距，配合拍向微调维持她在画面左侧的大小与位置，身后的门口逐渐退远、走廊纵深被拉长。阿宁持续清楚，门框和墙线保持可辨。前段变化缓慢，随后加快，接近正式图时逐渐收住；经过图中纵深已拉长的画面后停稳。阿宁重新迈步时按既定切点接下一镜，门内始终没有回答。

以下S030为独立虚构例，02已采用“先认清钥匙，再移焦认出来人”，04已给出手停住与来人显露的连续关系，05已定2.5秒镜长，06代表图处于来人刚清楚的一刻。

**S030｜2.5秒｜正式图在来人刚清楚时**

摄影机保持既定机位，钥匙和握钥匙的手先清楚，远处门洞中的人影仍不可辨。手停止转动时，焦点从钥匙移向门洞；来人变得可辨时经过正式图，近处的手随之失焦。焦点留在来人身上切出，脚步声跨切继续。
