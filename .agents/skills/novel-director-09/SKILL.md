# 09｜章节汇报与交接

读取指定章节当前有效成果、03 资产引用、已有检查与确认记录。按委托范围整理一份 `章节交接.md`，回答：**完成了什么、采用哪些决定、有效文件在哪里、哪些状态要延续、还欠什么。** 结论简写，依据链接原件。

| 内容 | 接手者需要知道什么 |
|---|---|
| 当前结论 | 原稿、处理范围、阶段和版本；已定基调、参照导演、美术依据及少量影响续章的决定。已生成、已检查、用户已确认分别标明范围与依据。 |
| 成果入口 | 链接表达表、台本、资产引用、走戏与场地图、剪辑稿、共用JSON、几何故事板及正式净图、07运镜和08声画稿，按实际完成范围列入。镜数与时长引用现有数据；已确认长镜与高阶分别注明。H设计链接02对应采用段落及05镜号，不另要求H设计点表。区分仅完成几何稿、正式单张已生成、图像已观察及动态效果未验证。 |
| 资产与连续状态 | 摘要需要延续的角色外观、服装、伤损、持物、道具归属与场地变化，注明发生镜号、剧情时间和当前末态；详细原件与设计引用 03。 |
| 场景与观众已知 | 哪些地标、空间关系、人物信息已在分镜中交代，发生在哪些镜号；声音按听觉设计标明。已有实际成片时，另注明其实际观看范围。 |
| 已知问题与下一动作 | 沿用前序结论，写“问题｜影响范围｜依据｜负责步骤”。区分未执行、待审和需要修正，实质矛盾集中列出；沿06优先级，P3仅列可选调整、不算缺失或待修，P4不列问题，不重新审图。 |
