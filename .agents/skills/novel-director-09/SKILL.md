# 09｜章节汇报与交接

读取指定章节当前有效成果、03 资产引用、已有检查与确认记录。按委托范围整理一份 `章节交接.md`，回答：**完成了什么、采用哪些决定、有效文件在哪里、哪些状态要延续、还欠什么。** 结论简写，依据链接原件。

| 内容 | 接手者需要知道什么 |
|---|---|
| 当前结论 | 原稿、处理范围、阶段和版本；已定基调、参照导演、美术依据及少量影响续章的决定。已生成、已检查、用户已确认分别标明范围与依据。 |
| 成果入口 | 链接表达表、台本、资产引用、连续走戏与场地图、剪辑时码、共用 JSON、正式分镜原页与净图、07 运镜提示词及 08 分段声画提示词，按实际完成范围列入。引用已有镜数、计划总时长、最长镜长和超限数，注明来自设计。 |
| 资产与连续状态 | 摘要需要延续的角色外观、服装、伤损、持物、道具归属与场地变化，注明发生镜号、剧情时间和当前末态；详细原件与设计引用 03。 |
| 场景与观众已知 | 哪些地标、空间关系、人物信息已在分镜中交代，发生在哪些镜号；声音按听觉设计标明。已有实际成片时，另注明其实际观看范围。 |
| 已知问题与下一动作 | 沿用前序结论，写“问题｜影响范围｜依据｜负责步骤”。区分未执行、待审和需要修正，实质矛盾集中列出。 |

05 提供剪辑与景别，06 提供彩色正式分镜，07 提供运镜提示词，[08](../novel-director-08/SKILL.md) 按 04 的篇幅汇总自然语言声画提示词。检查结论分别读取 `design.review.plan`、`design.review.board`、`motion_design.review` 及 08 文稿已有的核对结论。03 继续维护资产库，报告引用资产原件与连续状态。

提交前集中核对入口、版本和状态是否对应已有成果。交付一份当前有效的 `章节交接.md`，供后续 AI 定位原件和问题。
