# 05｜剪辑设计

本步负责**选定服务导演台本的剪辑方法与节奏，并落实为镜序、镜长、切点和声画承接**。先决定这一段采用哪种剪辑、哪里密集切换、哪里持续观看，再排逐镜时间。01—04提供已确认的内容、拍法和现场；05新增的是怎样剪，不重写台本、表演或现场。06据此设计景别、相对机位、具体构图与代表画面；07承接02固定或运动方案细化执行。

**职责与输出边界：** 上游已确认要呈现的内容必须保留；动作、台词、因果、必要停顿和并行关系不由05删改。05在既定内容内选剪辑方法、组织交替和节奏，决定何时切到谁或什么、动作接在哪一阶段、声音怎样跨切；画外行动按04继续。拍摄方案、同框关系和揭示顺序沿02，空间、调度、表演、轴线与声场沿04。需要删改内容时交原负责步骤统一修订，不能保留“04要求播放、05要求删除”的两套有效稿。每段先交一段采用的剪辑方案，再交“镜号＋起止时码＋自然语言切点与承接”；比较和推演留在工作中。

## 先定剪辑方法与节奏

开始排镜前必读[剪辑方法、选择条件与节奏决策](references/按剧情选择镜头组合.md)。按定义选连续性剪辑及其正反打、反应切换、视线匹配、动作匹配，或交叉剪辑、平行剪辑、已获上游依据的省略蒙太奇／跳切；按需配合J切、L切、匹配转场等。快切、加速、减速和保持长镜属于节奏安排，不能与上述组织方法混称。每段选定主方法和真正使用的辅助手法，不罗列备选，不自造听起来专业的方法名。

1. **以02采用的拍法选择组织方法。** 要看同一时空的接触与后果，就用连续性剪辑并确定动作／视线怎样接；要看双方话语改变彼此，就安排正反打或反应切换及声画错位；要在两条已存在的行动线间积累迫近，就安排交叉剪辑并写明两线及返回顺序。02要求同框或连续发展才能成立的效果，保留其连续观看，不拆成反应插镜。时间省略、跨时空对照或打断连续性的跳切须已有上游依据。具体成立条件见方法参考。
2. **先选这段的节奏形态，再定数量。** 依台本实际转折选定快切、逐步加速、减速、等节拍或保持既定长镜，明确节奏在哪里改变。每个节奏区间写出起止位置、采用方法、总秒数及镜数；需要时补平均镜长或先后镜长，不能只写“紧张”“加快”“适当停留”。例如“追逃的6秒用8镜动作匹配快切，随后17秒用8镜正反打，问答中切向听者，句尾以L切延续”。数字是本段采用的设计，不是所有剧情通用的速率标准。
3. **让台本和节奏共同约束镜表。** 先从04连续行动中找到可执行的交接，再落实所选密度；对白、动作和反应可跨镜同时进行，不要求每镜演完一个动作或说完一句话。不能先把全段按3秒分块，再替每块补“需要确认”的理由。若采用“6秒8镜”，最后交成“6秒2镜”即未执行；若密集切换破坏了02同框效果或04动作关系，同样不成立。调整05方案及镜表须同步，不能只改方法名称来迁就旧排镜。
4. **分别处理普通剪辑和连续效果。** 段内已有H镜或长镜时，单列其区间和“一镜不切”，再给其余区间选方法与密度。不得用全段平均值掩盖普通镜头的节奏，也不拆长镜凑快切数。普通单镜不超过3秒是上限，不能拿它决定默认镜长；不设全章快镜比例，也不为丰富数字硬塞短镜。

## 从连续行动找到剪辑点

1. 读01事项、情绪和预算，02采用拍法与台本，03资产引用，04现场变化与听觉设计，登记原件与段落引用。按正常速度推演同一时间内的行动、对白与听者反应，保留同步和交叠，找出既定的等待、认出、误判或注意改变。环境交代、空镜、转场和上游已确定的时间省略放在同一条时间线上，不再写一套观看策略或状态摘要。
2. 在已选剪辑方法和节奏内，比较动作、话音或信息改变处的候选切点：提前切会不会抢先揭示，晚切会不会重复已经读懂的事，切换后接什么？同一小动作可以完整留在镜内，对话可以延续到听者反应镜。入场、走近、站定及必要等待沿用上游已定内容，安排观看对象的切换。认为某段应删省时先交上游修订，不能在本稿直接删掉。
3. 从既定拍法推演每个镜号的入出时刻。核对必须同框的对象关系、仍须留在画外的信息及辨认所需时间；这些是判断切点的依据，不再生产`intent`、体验目标或代表图需求。依赖同框成立的因果和知情差保持，02已定的早知、误判与延迟揭露不变。
4. 按前镜末态与后镜初态排声画：动作接在哪一阶段，目光往哪去，哪句话或环境声跨切继续。沿04实际方位、全部关系／视线／运动轴及其事件变化定初排切点，不重排现场，也不替06选择摄影主轴或观看侧。06采用摄影方向与转换方案后，所需切点变化由05同步。普通单镜最多3秒；上游已确认的连续长镜头和高阶镜头可按完整方案用时超过3秒，分别用`long_take`和`advanced_camera`登记既定来源，高阶保留H编号。不能把普通镜头超时改名为长镜头。连续效果保留完整发展，固定构图保留必要辨认及画内事件时间；同一高阶点跨镜仍只计一次。总长受01预算约束。07校准后交05同步时码和声音，06同步已有代表帧与显示区间；段落或总长变化交01／04及下游同步。保留跨切信息、动作、注意和尺度比较，不为远近交替增加切镜。

## 交付

06交接的是本段完整`edit_plan`、镜序、切点及上游原件引用；由独立06执行者按[从剪辑方案到镜头设计](../novel-director-06/references/从剪辑方案到镜头设计.md)成组设计画面，分镜表及对应画框指令完成后交另一[独立检查者](../novel-director-06/references/独立检查与放行.md)对照上游核对设计相容性、面向与重复取景，向主Agent回报通过后再生图。动作、台词在切换中连续并不要求合镜。06画框重复或生图未执行设计时，先在06修正；只有既定切点／时间与上游要求存在无法由画框解决的具体冲突，才由05改剪并同步段落方案、镜表与共用数据，不能仅因两张图相似就撤销切点。

动作锚点、台词／OS 的声音区间与听者反应共用全局时码；同步发生的内容保留重叠区间，事件不因切镜重新开始。总时长取剪辑后的实际经过时间，不把行动、对白与反应逐项相加。上游有无依据的串行等待时，交 02／04 调整表演，保持台词、因果及动作可理解性。

- **`05_剪辑时码表.md`** 沿04段落分组，段首用一段自然语言定“采用哪种剪辑、在哪些对象之间怎样组织、每个节奏区间多少秒多少镜、哪里变速或保持一镜”。随后逐镜写“镜号｜起止时码”及切入、切出、动作与声音的承接；高阶镜号随标题带已有`H`编号。只交采用方案与镜表，不加理由、术语解释、候选比较或审核报告，不抄整段走戏，不规定景别与构图。
- **`05_拍摄设计.json`** 是05—07逐步补全的共用容器。段首采用方案同源写入`shot_groups[组号].edit_plan`，只用一段自然语言，不拆成方法、情绪、论证等字段。逐镜写镜序、帧段、`edit.description`中的切点与承接，必要的声音时间映射及超3秒依据。场地、段落和上游原件用ID及路径引用，不重写内容。05不另造上游体验目标、连续状态、动作表、画面需求或`design_frames`；06开始设计后再写分镜字段。严格按[拍摄数据约定的05最小范围](references/拍摄数据约定.md#05实际需要生产的数据)执行，不复制完整06／07示例当05填表模板。
- 一次合并自检：先对照02，判断采用方法是否成立、节奏是否实现既定拍法；再把段首所定秒数、镜数、交替顺序和变速位置与逐镜时码对上。方法名用错、只有快慢形容词、说快切却全部2—3秒、说加速却密度不变，均不能通过。全章机械铺满2—3秒，抹平台本已定的突发、追逃、缓和等变化，也不能因“普通镜未超3秒”而通过。反之，不以镜长数字丰富或镜头够短代替剪辑成立。
- 同次自检核对既定内容、同框关系、延迟揭露、并行动作、接切与预算；普通单镜最多3秒，长镜头与高阶镜头均有上游依据。依02的H编号核对每分钟2–3处，同一设计点只计一次，普通长镜头不自动计入高阶。`review.plan`只简记实际范围及实质问题；结构校验通过不等于剪辑设计通过。

## 自然语言输出示例

以下为虚构片段，S001、S002与06、07示例对应。行动、声音、H01推拉变焦及长镜均假定已有02／04依据。实际交付只使用下面的段首决定与逐镜正文，不附这些前提解释。

**E01｜催促离开｜00:03—00:08**

这5秒采用连续性剪辑，以反应切换配合L切，共2镜，每镜2.5秒。“后面有人”说到一半切向周川，句尾留在他的反应上；回身中接回两人的行动，抓袖接触保留在第二镜，撞门声起时硬切进入逃跑段。

**S001｜00:03—00:05.5**

阿宁说到“后面有人”时切向周川，后半句跨切继续。画面留在周川的反应上，在他肩膀开始回转时切出，下一镜从同一动作阶段接上。

**S002｜00:05.5—00:08**

从前镜未完成的回身接回两人，把催促与抓袖保留在同一镜内；抓袖发生前已经切回，接触不落在画外。撞门声刚响便切向阿宁，余响和脚步跨切延续。

**E02｜穿门逃跑｜00:08—00:12**

这4秒采用动作匹配快切，共5镜，依次0.5、0.75、0.75、1、1秒。回头、拉走、越障、穿门和带门依次交接，脚步与撞门余响不断；门合上时结束快切。

**S003｜00:08—00:08.5**

撞门声起时切向阿宁，回头尚未完成便切向周川已经开始的拉拽；余响跨切继续。

**S004｜00:08.5—00:09.25**

从袖口已被攥住的状态接入，第一次拉动不停顿、不重演；在两人开始跨越倒木时切向脚下，拉拽在画外继续。

**S005｜00:09.25—00:10**

接同一次跨越，脚落过倒木就切向仍在前移的阿宁，落脚声延续到下一镜。

**S006｜00:10—00:11**

切入时阿宁已经来到门槛前，穿门动作连续保留；周川开始带门时切向他，不重演阿宁的通过。

**S007｜00:11—00:12**

接同一次带门，门合上即切出；关门声的余响跨入后段。

**E03｜察觉逼近｜00:24—00:30**

这6秒保留H01一镜不切，从门后脚步停住持续到阿宁重新迈步，期间不插入门后的画面；衣料声跨切接入后段。

**S010｜00:24—00:30｜H01**

门后的脚步停住时切到阿宁，H01效果完整留在这一镜内，中途不切。等既定变化停止、她重新迈步时切出，下一镜从同一动作阶段接上，衣料声不断。

**E04｜撑门通过｜00:40—00:47**

这7秒保留已定长镜，一镜完成撑门、通过与跟入，关门声落下才切到下一段，喘息跨切延续。

**S020｜00:40—00:47｜已定长镜头**

从两人到达门前接入，撑门、通过与跟入连续保留，中途不切；关门声落下后切出，喘息跨切延续。

## 交接与停止点

视觉交接按[分镜设计职责与交接](../novel-director-06/references/分镜设计职责与交接.md)执行。05选定动作匹配、视线匹配、交叉或反应切换时，写清已有动作阶段、观看对象及返回进度；06据此安排相邻画框的尺度、注意落点与清晰范围。05不替06定景别、焦点或照明。06先调整自己负责的画框，不能把一次设计或生成失败视为剪辑冲突；确实无法在既定密度和切点内呈现上游必要内容时，明确具体冲突交05统一调整段落方案与镜表，不在下游各自改时长。

05单步交剪辑初排后停。06直接读取01—04有效原件及本步段落剪辑方案、逐镜切点，在已定节奏下完成景别、机位、构图、代表时刻与绘图，不只拿05摘要生图。06在既定切点内调整景别与画框，由06更新；需要增删、拆合、重排镜头或改镜长、切点时，由05同时更新段落方案和镜表。07校准用时后也由05同步方案与同一时间线，不能只改秒数而破坏采用节奏。核心拍法改变交02，现场和表演改变交04；各步在授权范围内交原负责步骤处理，不自行覆盖上游决定。
