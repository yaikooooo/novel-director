# 05–07 共用的拍摄数据

`05_拍摄设计.json`是逐步补全的共用容器，不是05必须生产的字段全集。05新增段落采用的剪辑方法与节奏，以及落实该方案的镜序、时码、切点与声画承接；06新增景别、机位、构图、代表时刻和图像；07新增运镜执行。上游内容以原件引用为准，不为填满容器另写一版。文稿只展示自然语言采用决定。

所有新生产同时遵守[共用阅读器数据接口](../../../../前端/导演阅读器/数据接口.md)，字段形状参照[可运行示例](../../../../前端/导演阅读器/示例/05_拍摄设计.json)。页面直接读取当前 JSON，程序集中在 `前端/导演阅读器/`。交付时运行一次共用校验，并查看本次代表镜头。

专业设计沿[分镜设计职责与交接](../../novel-director-06/references/分镜设计职责与交接.md)确定唯一负责步骤。该表用于工作方法，不另建章节检查数据。06第一轮的清晰对象、清晰范围和代表时刻随已有画框文字交接，后两轮必须执行；07动态焦点和08声画写作沿同一决定，不靠图像模糊程度猜测采用意图。

## 数据归属与版本

本容器允许按镜逐步写入，阶段是否完成按[主Agent](../../../../AGENTS.md#如何推进)的完整制作范围判断；局部字段或数据校验通过不授权提前推进07／08。

06由[主Agent](../../../../AGENTS.md#调度与交付边界)派出的独立执行者串行维护。先读取整段`edit_plan`、`shot_order`及各镜`edit.description`，连同完整上游原件，按[镜头设计执行指令](../../novel-director-06/references/从剪辑方案到镜头设计.md)成组设计并写入已有画框字段，分镜表完成后交另一[独立检查者](../../novel-director-06/references/独立检查与放行.md)对照上游核对；制作方按回报将必要修订同步到字段及生成输入，通过后才生图；不新增切口分析表、候选表、自检报告或子智能体过程字段。故事板、原生单张和BANANA重渲染使用同一套采用设计。

新制作采用 `schema_version: 4`，顶层为 `data_revision`、`design_revision`、`design_status`、`design`；07 执行后增加 `motion_design`。

- `data_revision` 随有效数据变化；`design_revision` 随已采用的拍法、现场状态、图幅或时序变化。运镜提示词记录所依据的 `source_design_revision`。
- `design_status`：working 表示设计中；review_ready 表示 05 设计与 06 图像已一致、可审；approved 记录本次实际审定或自主定稿授权的依据。05 单步完成的文字初排仍为 working，其本步结论写 `review.plan`。
- `design`可逐步包含`project`、`beats`、`shot_groups`、`shot_order`、`scenes`、`board_sheets`、`lighting_setups`、`look_setups`、`effect_setups`、`shots`、`review`。这是可用集合，不要求05建齐，更不要求为空集合补造内容。除设置、顺序和摘要外，各集合以稳定ID引用。
- 未执行的图像或提示词部分保持缺省。旧编号按实际职责识别，有效图像与时码继续沿用；退役工程和实现记录归入临时目录。

| 写入者 | 维护部分 |
|---|---|
| 05 | `shot_groups[].edit_plan`中的段落剪辑方法与节奏；`shot_order`、每镜`frame_range`、`edit`中的切点与承接，必要的跨切声音时段及超3秒依据。镜号、场号、段落号和来源路径用于关联上游；不另写上游体验目标、观看策略、动作状态或画面需求。 |
| 06 | 第一轮将轴线选择、机位、景别、画框和清晰关系写入已有镜头字段，board_sheets保存原生故事板；第二轮原生imagegen逐镜另画独立单张，在同一design_frames内以design_ref及design_generation登记；第三轮BANANA重新渲染，以board_art及对应生成记录登记最终净图。三轮同镜号与代表时刻，review.board由制作方按主Agent收到的独立结果转记，包含检查者、阶段、有效版本与镜号、放行或待修结论。裁图不算第二轮完成，改剪仍交05同步。 |
| 07 | `motion_design` 中逐镜导演意图、完整运镜提示词与自检；按采用结果补独立相机标注，同源导出 `07_运镜提示词.md`。 |

## 走戏、镜组与生图上下文

02每段采用拍法决定观看组织，03提供资产，04场地图与连续走戏提供现场依据。05据此选定剪辑方法与节奏，再落实镜序、声画切点与镜长，不删改上游已确认要呈现的内容。06直接读取01—04原件、05段落方案及镜表完成画面设计，07读取这些来源及正式图设计执行。下面是各步可用的共用字段，不是05的待填表。

| 位置 | 内容与用法 |
|---|---|
| `scenes[场号]` | 04场地图`plan_ref`和走戏`source_ref`、固定地标、稳定对象ID与03原件引用；全部实际关系轴／视线轴／运动轴及光源、状态通过原件定位，不重抄轴表。04不供摄影主轴或观看侧；06依据这些现场关系自行采用摄影方向及衔接，不另建场地尺寸、坐标或位置。 |
| `shot_groups[组号].continuity` | 兼容已有上游状态摘要，05不重新生产；新制作通过`source_ref`读04连续走戏。 |
| `shots[镜号].story_moment` | 对应动作时刻；回忆、并行线、省略等需要区分时，说明剧情时序与剪辑顺序的关系。 |
| `board_sheets[页号]` | `image_ref`为第一轮采用的几何故事板，`group_refs`和`frame_ids`关联所含画框；`generation`记录故事板提示词及实附的04场地图、相邻采用画格与各自用途。高细节角色、风格和场景美术原图供后两轮，不混入组页参考。 |
| `design_frames[].sheet_ref / panel_id / panel_region` | 每个摄影镜头以唯一代表图关联原页的一宫，`panel_region` 供阅读器定位实际画框；代表时刻属于本镜，显示区间覆盖本镜。格位来自实际原图，不据模板假定。 |
| `design_frames[].design_ref / design_generation` | 新三轮制作中，design_ref为第二轮原生独立单张的章节相对路径；design_generation保存实际tool、prompt、references、实测resolution_px。首个几何参考用image_ref及panel_region指回采用故事板，实际调用时实附裁图；其他参考注明角色身份、当场造型或场景用途。裁图、复制或放大不能登记为独立生图。旧稿未记录本轮则保留历史来源，不补造记录。 |
| `design_frames[].board_art / board_art_resolution_px / board_art_generation` | 第三轮BANANA最终图的章节相对路径、实测宽高及真实生成输入。board_art_generation.references的首个几何参考为design_ref指向的第二轮独立单张，不再引用故事板裁图；必要03资产与固定光色基准另附。board_art只指向实际完成并采用的最终图，07／08读取它。 |

第一轮先设计整段连续镜头，再分页生成几何故事板。一宫对应一个镜号，按剪辑顺序排列；只用无五官人体块、场地骨架和必要道具轮廓表达景别、机位、透视、位置、遮挡与关键动作。跨页顺序生成，后次实附前页采用画格，局部特写之后补最近能说明同场关系的画格，同时继承同一04阶段。姿态、事件与实际关系取自04／05对应时刻，摄影主轴、观看侧和方向承接沿06采用决定，不能把04全部轴同时当禁越边界；分页不重置现场。每镜实际画框遵守中景居中等构图禁令，不靠改变景别名称、轻微偏移或斜拍绕过。

三轮来源分别记录：board_sheets[].generation记原生故事板；design_frames[].design_generation记第二轮原生独立单张；board_art_generation记第三轮BANANA重渲染，不能以计划代替实际调用。各记录含tool、完整prompt及references；第二轮另记实测resolution_px，第三轮实测尺寸仍用board_art_resolution_px。第一轮的景深及表演通过画框文字交接，第二轮据03／04恢复并画成独立单张，第三轮保持镜头、身份、动作和清晰关系，在同一光色内增强质感。第二轮的裁图参考登记正式原页及panel_region，第三轮首个参考登记design_ref；不依赖临时副本。采用的故事板、原生单张与BANANA最终图均须保留，失败样张和可重建裁图不进入正式交付。

逐镜裁图后、任何正式单镜渲染前，06独立检查者必须按[裁图检查规则](../../novel-director-06/SKILL.md)实际看本镜草稿、上一剪辑镜及必要的同一行动线前镜，对照04现场、05切点和代表时刻，一次检查裁切、数量与人体结构、比例透视、支撑接触、构图及跨镜空间和动作。未检查、结构有错或跨镜关系无法成立的草稿均不放行；不能以原页已采用或用户已授权代替实际观察。修正后的几何画格须成为正式故事板的有效来源，同步`image_ref`、实际格位和受影响引用，再从该来源取得本次渲染参考；不保留“临时草稿已修、正式原页仍错”的两套有效图。变化仅在图像执行时按原设计修正，不偷偷改现场、镜序或时间。

独立检查者直接向主Agent回报，制作方原意转记在已有`review.board`的`scope / findings`或原页`observation`简记，注明检查者、阶段、受检版本与镜号、有效来源页／宫和比较镜号及结论，不新增检查表或放行字段。草稿通过后，未生成的正式图仍省略`board_art`，逐幅生成状态仍为`required_not_generated`；不得把草稿通过写成正式图`adopted`。按[06图像审核优先级](../../novel-director-06/SKILL.md#图像审核优先级)，未解决P1／P2在现有观察中记`needs_revision`，缺少必要依据记`blocked`；P3先放行，仅在现有备注一次列可选调整，P4直接通过且不列问题。BANANA正式图已生成并获独立检查放行，仅有P3／P4时，可填`board_art`并将逐幅观察记为`adopted`，不等于用户已审，不因此跨越委托停点。此结论只对实际看过的有效图与比较来源成立，修图或相关现场／时序变化后，定向验收受影响关系再使用，不能沿用旧结论。

以下仅为写法示例，不代表已验证任何章节；示例用于解释如何依据实际影响分级，不限定检查范围，也不为同类问题预定级别：“S102｜P04/P02草稿：已修正多出的手和肩臂连接；对照S101及04门口阶段，人物仍在原门柱旁，画面间隔缩短来自侧向取景，未发生额外走近。定向验收通过，可生成正式单张。”未通过时写具体阻断，例如“S102仍把未移动的人画到门口，草稿待修，不生成正式单张”；不附逐项打勾清单。正式图的非主视觉杯子颜色不同但不影响剧情和动作，可写“已采用；杯色差异为可选调整，不阻断后续”；眼区特写略露鼻尖且无畸形、无叙事影响，不按裁边违约拒收；难察觉且无影响的背景锁扣无需记问题。

## 坐标与时间

- `project` 记录画幅、`resolution_px`、`pixel_aspect`、`fps: {num, den}`、全局 `frame_range` 与预算。单镜、声音和工具规格沿用[主 Agent](../../../../AGENTS.md)。
- 全局帧从 1 起，首末帧均计入；时码左闭右开。硬切后镜首帧为前镜末帧加一；叠化记录实际重叠。镜长来自选定入出点，声音以实际持续帧段计时。
- 02／04 已定的行为、话语与反应映射到同一时间线，同时发生的动作锚点与声音区间保留重叠。动作和话语可跨镜延续；总长按剪辑时码计算，重叠内容只计一次。
- 场地空间沿用04图中的方位、地标、相对位置和轴线，不要求米制原点、长度、角度或相机参数。SVG区域、图像裁切和标注坐标只是文件显示数据，不代表现场测量；有依据的旧字段保持兼容，不为填满字段补造数值。
- 05写事件与信息范围；06选代表时刻和景别，用相对位置、裁切、层次与大小关系表达构图；07用可见关系描述起落幅和运动。画内`bbox`或点位为可选显示辅助。时码、帧段、画幅、图像尺寸等必要交接数据照常维护。

## 镜组与每镜设计

| 位置 | 最终采用的数据 |
|---|---|
| `beats / shot_order` | 01事项、预算及对应镜号；当前镜头顺序。06反馈改剪时由05同步镜数与时码，06同步图号及受影响的画面。 |
| `shot_groups[组号]` | 05维护`edit_plan`、`shot_ids`和`source_ref`；`edit_plan`只交采用的剪辑方法与节奏，已有`beat_refs`等引用沿用。`intent`、`viewpoint`、`knowledge_change`、`strategy`、`adaptation`保留旧数据兼容，不列为05生产要求；拍法直接读02。 |

## 07 运镜提示词数据

`motion_design` 包含 `source_design_revision`、`status`、`shots` 和 `review`。每镜保存 `frame_id`、一句 `intent` 与完整 `prompt`。镜长、正式图路径和代表时刻通过镜号、图号读取同一份 `design`。字段与示例见[阅读器接口](../../../../前端/导演阅读器/数据接口.md)。

提示词表达起幅、动作与相机的先后、移动或留驻的过程、节奏变化、经过正式分镜的时刻和落幅承接。声音只作为已有声点的触发。已确认长镜头和高阶镜头由07承接既定方案细化执行并校准用时，可超过3秒；05在`duration_basis`区分登记。核心方案变化交02，画框或时码变化分别交06、05。段落或总长变化同步04／01及下游08，并按新时间线核对高阶设计次数。

`review` 记录本次纸面与图像推演的实际范围、结论和待办。`status` 为 working、review_ready 或 approved，采用依据按实际确认记录填写。修改提示词或标注递增 `data_revision`；改变 05／06 的有效设计递增 `design_revision`，旧提示词由版本关系标明待同步。

07 同源导出 `07_运镜提示词.md` 供复制与交接；阅读器按镜号展示 JSON 中的提示词。08以04段落读取本数据及台本、资产引用、正式图与运镜稿，结合实际画框补全、强化表演及同框活动，写成连续声画，每镜正文开头明确镜号、由05有效帧段与帧率换算的时长及分镜引用，交付`08_分段声画提示词.md`；不回写设计字段或再维护一份JSON。09引用已有设计、声画稿与核对结论。
