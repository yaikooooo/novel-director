# 05–07 共用的拍摄数据

`05_拍摄设计.json` 维护一份有效设计：05 写镜组、景别与剪辑，06 绘制彩色正式分镜，07 设计逐镜运镜提示词。各步串行维护自己的部分。

所有新生产同时遵守[共用阅读器数据接口](../../../../前端/导演阅读器/数据接口.md)，字段形状参照[可运行示例](../../../../前端/导演阅读器/示例/05_拍摄设计.json)。页面直接读取当前 JSON，程序集中在 `前端/导演阅读器/`。交付时运行一次共用校验，并查看本次代表镜头。

## 数据归属与版本

新制作采用 `schema_version: 4`，顶层为 `data_revision`、`design_revision`、`design_status`、`design`；07 执行后增加 `motion_design`。

- `data_revision` 随有效数据变化；`design_revision` 随已采用的拍法、现场状态、图幅或时序变化。运镜提示词记录所依据的 `source_design_revision`。
- `design_status`：working 表示设计中；review_ready 表示 05 设计与 06 图像已一致、可审；approved 记录本次实际审定或自主定稿授权的依据。05 单步完成的文字初排仍为 working，其本步结论写 `review.plan`。
- `design` 下包括 `project`、`beats`、`shot_groups`、`shot_order`、`scenes`、`board_sheets`、`lighting_setups`、`look_setups`、`effect_setups`、`shots`、`review`。除设置、顺序和摘要外，各集合以稳定 ID 引用。
- 未执行的图像或提示词部分保持缺省。旧编号按实际职责识别，有效图像与时码继续沿用；退役工程和实现记录归入临时目录。

| 写入者 | 维护部分 |
|---|---|
| 05 | `design` 中镜组、现场状态依据、每镜的景别与观看重点、唯一代表画面需求、声画时序；`review.plan`。 |
| 06 | `board_sheets` 中正式分镜组页与采用的生成输入；`shots[].design_frames` 中格位、逐镜净图路径 `board_art`、代表时刻与图像观察；`review.board`。设计变更反馈 05 后同步同一数据。 |
| 07 | `motion_design` 中逐镜导演意图、完整运镜提示词与自检；按采用结果补独立相机标注，同源导出 `07_运镜提示词.md`。 |

## 走戏、镜组与生图上下文

04 的连续走戏是现场依据。05 读懂这一段的动作与人物关系，选定观看顺序和景别；06 将已有上下文整理成镜组生图输入。数据记录采用的决定与来源，逐镜常识由 Agent 结合整段自行推理。

| 位置 | 内容与用法 |
|---|---|
| `scenes[场号]` | 场地原点、固定地标、有关尺度、稳定对象 ID 与 03 原件引用、轴线、光源、`plan_ref`，以及 04 走戏 `source_ref`。 |
| `shot_groups[组号].continuity` | 对应走戏段落、当前人物与场地的关键关系、本组发生的变化和向后承接；只记录影响镜头或生成的内容。 |
| `shots[镜号].story_moment` | 对应动作时刻；回忆、并行线、省略等需要区分时，说明剧情时序与剪辑顺序的关系。 |
| `board_sheets[页号]` | `image_ref` 为生成的正式分镜组页，`group_refs` 和 `frame_ids` 关联所含画框，`generation` 记录采用的组提示词及实附的已定风格、当场人物／场景资产和前组参考及各自用途。 |
| `design_frames[].sheet_ref / panel_id / panel_region` | 每个摄影镜头以唯一代表图关联原页的一宫，`panel_region` 供阅读器定位实际画框；代表时刻属于本镜，显示区间覆盖本镜。格位来自实际原图，不据模板假定。 |

一次生图请求包含共同现场和本页各独立镜头的画框设计，一宫对应一个镜号，按剪辑顺序排列。跨页顺序生成，后次实际附入前页采用图并注明参考格位；上一格若只见局部，再附能说明同场空间的已采用图。参考图提供稳定关系，本镜姿态和事件状态取自 04／05 对应时刻。项目风格图决定色面和材质画法，04 的光源和 05 的显露顺序指导 06 落实画面亮暗；这些文件通过工具的图像参考参数传入。

`generation` 中的实际参考项记录原图路径、用途及页号／格位，配合采用的提示词即可复查该请求收到哪些图。按格显示或提供下游引用时，保留原页及格位关系，所用构图来自同一采用图像。

## 坐标与时间

- `project` 记录画幅、`resolution_px`、`pixel_aspect`、`fps: {num, den}`、全局 `frame_range` 与预算。单镜、声音和工具规格沿用[主 Agent](../../../../AGENTS.md)。
- 全局帧从 1 起，首末帧均计入；时码左闭右开。硬切后镜首帧为前镜末帧加一；叠化记录实际重叠。镜长来自选定入出点，声音以实际持续帧段计时。
- 米制、右手系 `+X 东、+Y 北、+Z 上`；每场有原点地标。已有其他坐标时给转换依据。长度 `_m`、焦距 `_mm`、角度 `_deg`。
- 05 写代表时刻的景别和信息范围，06 用相对位置、裁切、层次与大小关系表达构图。画内 `bbox` 或点位为可选辅助；07 用可见关系描述运镜。数值注明来自资料、估定或实测。

## 镜组与每镜设计

| 位置 | 最终采用的数据 |
|---|---|
| `beats / shot_order` | 01 事项、预算及对应镜号；当前镜头顺序。05 与 06 共同定稿时同步镜数、图号与时码。 |
| `shot_groups[组号]` | `beat_refs`、`shot_ids`、`intent`（体验起点与落点）、`viewpoint`、`knowledge_change`、`strategy` 与 `adaptation`。说明当前戏采用的观看组织。 |
| `shots[镜号].scene_ref / frame_range / kind` | 场号、镜头帧段、camera／black 等类别；非摄影段按同一时间线登记。 |
| `intent / composition` | 05 给观看任务、主体、代表景别与必须看清的内容；06 补代表画框的裁切、层次、比例与遮挡。沿用 `scale_in` 表示计划景别，起幅／落幅尺度在 07 提示词中推演承接。 |
| `camera` | 05 阶段可省略。06 为代表帧按需补静态视点、拍向与透视说明；07 的运动决定单独写入 `motion_design`。 |
| `axis_ref / axis_events` | 关联 04 的有序轴与人物方向；06 落实代表画框的银幕方向，07 描述运动途中如何换侧与重新交代方位。 |
| `blocking / anchors` | 本镜动作与变化、持物手、接触、重心与关键事件帧，引用现场对象；承接镜组走戏。 |
| `lighting_ref / look_ref / effects` | 04 提供场地光源与光区，06 确定代表画面的光影与效果，07 描述与镜头运动有关的动态变化。对应 setup 维护主导光源、来向、软硬、填充与暗部细节、主体和背景的明暗关系；06 将每格具体的受光面、背光面、空间分层与注意中心写入采用的生图提示词。动态变化关联事件帧。 |
| `sound_cues` | 02 原词、04 声音来源、说话人／声源、听点、入出及重音帧。持续声用同 ID 跨切，只交文字。 |
| `edit` | 前后镜、接法、具体入出动作／信息／声点、注意落点如何承接、必要重叠或省略。 |
| `design_frames` | 保留数组结构，每个摄影镜头仅含一项：图号、代表全局帧、覆盖整镜的显示帧段和代表构图需求。06 补 `sheet_ref`、`panel_id`、实际画框区域、`board_art` 及 `observation`。`design_ref` 可引用原页；采用单格原件时记录来源页与格位。黑场等非摄影段按类型显示。 |
| `design_frames[].annotations` | 06 按净图落动作／视线箭头。07 定好运动后在同一列表串行补 `camera` 箭头或固定 `note`，标 `author_step: "07"`，保留 06 的标注。箭头是 `motion_design.shots[镜号]` 决定的显示层。单纯补显示标注更新 `data_revision`，已审画框、时码或采用的剪辑改变才更新 `design_revision`。 |

`generation` 在镜组页保存一次采用的方式、完整组提示词和实际附图及用途。`observation` 单列画面符合情况和偏差。新拍法经 05 取舍采用后更新设计；生成偏差继续以有效设计为修正目标。

`review.plan` 记录 05 对镜组观看价值、动作完整性、实际切点和预算的判断；`review.board` 记录 06 对一宫一镜、机位、透视、景别、构图、标注、同场关系、风格和光影的判断。摘要列镜数、代表图数量、总时长、最长镜长、超限数、相似景别对数及实质问题镜号；完整交付的代表图与摄影镜头一一对应。05 比较计划，06 比较实际彩图；相似景别对为 0 才通过该项，单张或静帧结论注明范围。

## 07 运镜提示词数据

`motion_design` 包含 `source_design_revision`、`status`、`shots` 和 `review`。每镜保存 `frame_id`、一句 `intent` 与完整 `prompt`。镜长、正式图路径和代表时刻通过镜号、图号读取同一份 `design`。字段与示例见[阅读器接口](../../../../前端/导演阅读器/数据接口.md)。

提示词表达起幅、动作与相机的先后、移动或留驻的过程、节奏变化、经过正式分镜的时刻和落幅承接。声音只作为已有声点的触发。静态构图或时码需改变时，分别交 06、05，同步设计版本后再更新受影响的提示词。

`review` 记录本次纸面与图像推演的实际范围、结论和待办。`status` 为 working、review_ready 或 approved，采用依据按实际确认记录填写。修改提示词或标注递增 `data_revision`；改变 05／06 的有效设计递增 `design_revision`，旧提示词由版本关系标明待同步。

07 同源导出 `07_运镜提示词.md` 供复制与交接；阅读器按镜号展示 JSON 中的提示词。08 以 04 的段落篇幅读取本数据及台本、资产引用、运镜稿，汇成 `08_分段声画提示词.md`，不回写设计字段或再维护一份 JSON。09 汇报引用已有设计、分段汇总与检查结论。
