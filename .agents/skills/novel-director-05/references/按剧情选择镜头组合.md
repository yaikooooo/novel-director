# 按剧情选择剪辑组合

05 考虑观众怎样从一个画面读到下一个画面。以下是剪辑选择，顺序和镜数随戏而定。

| 这一段的任务 | 怎么组织信息与切点 |
|---|---|
| 新场地、转场或跨章重返 | 按 01 的回查判断观众已经知道什么。给一个仍需辨认的地标、行动目标或变化，再切到具体行动。空镜也可表达等待、时间跳跃或事后余波。 |
| 职业、规则或操作 | 让说明声与可见操作并行；切到真正影响理解的证据或结果，留够读字与辨认关系的时间。 |
| 对话、对抗、关系改变 | 先决定哪句话让谁改变态度。必要时在说话人说完前切到听者，或保留两人同框直到关系真的改变。 |
| 发现、误会、悬念 | 安排人物反应、所见对象和观众独知线索的先后。让观众比人物早知、同拍认出或稍后才懂，三种剪法给同一事实不同的效果。 |
| 突发事件与后果 | 分清冲击落在事情发生、人物认出还是身体反应；把最强的尺度或声音反差留给那一拍，随后给后果可读的时间。 |
| 连续动作或交叉行动 | 从准备、接触和结果找真正需要换关注对象的时刻。切前与切后动作进度、视线与方向能接上；交叉剪辑每次返回都带来新进展。 |
| 时间压缩、回忆或梦境 | 决定进入的触发、可以省略的过程、返回现时的依据。用声桥、匹配、并行、叠化或硬切表达这次时间关系。 |

相邻景别按主体可见范围判断。换角度、换人物或换名称，观众仍看到差不多大的同类画面时，需要重排尺度或重新考虑这次切换。现场方位沿 04，画面取舍交 06，跨切的摄影运动归 07。
