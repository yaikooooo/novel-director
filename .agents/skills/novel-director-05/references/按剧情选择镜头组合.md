# 剪辑方法、选择条件与节奏决策

本文件是05排镜前必读的方法参考。按下面的明确含义使用术语，方法服务02已经采用的拍法。表内的选择推演留在工作中；最终只写本段采用的方法、具体组织与节奏，再落实镜表。不能把“压迫感剪辑”“情绪递进剪辑”等效果形容当成方法名，也不能只写“蒙太奇”而不说明实际怎样组接。

## 可选的剪辑方法

### 组织镜头

| 方法 | 实际怎样剪 | 何时采用／何时不成立 |
|---|---|---|
| 连续性剪辑（continuity editing） | 保持同一事件的时间、空间与行动连续，在已有行动中换关注对象；具体接切从下表选择。 | 02要观众跟清现场因果、操作或交谈时采用。只写“顺剪”不够，还要选动作匹配、反应切换等实际做法和节奏。 |
| 交叉剪辑（cross-cutting） | 在两条或以上同时进行、相互影响的行动线之间交替；每次返回接该线已经推进到的阶段。 | 如门内解锁与门外逼近。必须写出两线和交替次序，不能把同一对话的两个人轮流出现称为交叉剪辑。不能新增另一条剧情线、暗示不存在的同时性，或切开02规定同框成立的关系。 |
| 平行剪辑（parallel editing） | 交替呈现上游已定的两组事件，以对照或关联组织，不强加同时发生。 | 用于已定的跨时空对照等；不能由05新增回忆、寓意或改剧情时间。本项目为避免混淆，用“交叉”明确同时推进，用“平行”明确对照；不同教材的术语范围可能重合。 |
| 省略剪辑／压缩时间的蒙太奇段落（elliptical editing / montage sequence） | 从上游允许省略的经过中选取既定阶段，组接成明确的时间推进。 | 仅在02／04已明确可省略哪些经过时采用，并落实从哪一阶段跳到哪一阶段。快切不等于省略，动作在画外继续也不等于时间被删掉。 |
| 跳切（jump cut） | 同一主体、相同或相近视点之间明显跳过时间或动作阶段，主动保留不连续感。 | 只有上游已采用这种断裂表达及省略范围时使用；不是硬切的别名，不能用来遮掩接不上的动作。05选时间跳点，06落实对应画面。 |

连续性、平行行动和蒙太奇的基本含义参照[哥伦比亚大学剪辑词条](https://filmglossary.ccnmtl.columbia.edu/term/editing/)与[平行剪辑词条](https://filmglossary.ccnmtl.columbia.edu/term/parallel-editing/)。交叉／平行的上述项目用语及跳切辨识参照[MIT Film Lexicon](https://shea.mit.edu/ramparts/commentaryguides/glossary/filmlexicon.htm)。省略范围与上游职责限制是本项目约定。

### 连接具体镜头

| 方法 | 实际采用决定必须说清什么 | 使用限制 |
|---|---|---|
| 正反打（shot/reverse shot） | 在互动双方之间怎样轮换，哪句话或反应把观看交给另一方。 | 不是一人一句机械轮换，也不要求每句都换镜。05定对象与切点；06从04全部实际关系中采用摄影主轴、观看侧及方向衔接，定机位和画框。 |
| 反应切换（reaction cut） | 从事件或说话者切向谁的反应，何时返回；需要时让原话留在反应画面上。 | 反应必须已存在于02／04，不补新表演；反应发生在话语中就切在话语中，不能先等整句结束。 |
| 视线匹配（eyeline match） | 从谁的看切到已定所见对象，是否返回其反应；对象显露的时点沿02。 | 不能因人物看了一眼，就提前展示02要求隐藏的对象；06沿04视线与轴线落实画面。 |
| 动作匹配（match on action） | 在同一动作进行中切，下一镜接住同一次动作的同一进度。 | 不把动作重演一遍，不擅自跳过接触；与另一时空的相似动作转场分开。 |
| 插入／切离（cut-in / cutaway） | 从当前行动切到已有关键细节，或暂切至同场另一对象，再接主行动已推进的时刻。 | 只选上游已有对象与事件，不能为凑镜数加空镜；不必把行动从头再演，具体景别归06。 |
| J切／L切（split edit） | J切是后镜声音先入、画面后切；L切是画面先切、前镜声音继续。写明哪段声音和哪个画面切点错开。 | 不能只写“声桥”。不删字、不改变04声源时序，不因画面切换重播声音；原有环境底声持续不必每镜强贴J／L标签。 |
| 匹配转场（graphic / action / sound match） | 在两个已定场景或时段之间，以哪两个已有形状、动作或声音相接，切在哪一刻。 | 不等同于同一动作的连续匹配。05提出匹配对象和时间关系，06完成图形对应，07承接已有运动；若须改拍法才能成立，先交02。 |
| 硬切／突切、叠化、淡入淡出 | 硬切直接换画面；突切（smash cut）利用已定的强烈声画反差；叠化让两镜短暂重叠；淡变明确进入／退出画面的区间。 | 普通硬切不必每镜重复报术语，也不能独自代替整段剪辑方案。突切必须有实际反差；叠化／淡变须符合既定时空表达，不用转场特效掩盖连续性问题。重叠时间写入同一时间线，不另加段长。 |

动作匹配、正反打、视线与连续关系参照[Tom Barrance 的连续性制作方法](https://learnaboutfilm.com/film-language/sequence/)；J／L切的声画关系参照[Adobe 官方分离剪辑说明](https://helpx.adobe.com/premiere/desktop/edit-projects/trim-clips/perform-j-cuts-and-l-cuts.html)。这些方法可配合使用，但不能把叠加的名称当作已完成设计。

### 决定剪辑节奏

组织方法不自带速度。交叉剪辑可以从容，也可以密集；正反打可以快切；连续性剪辑也能突然加速。段落方案必须同时落下实际节奏，下面的数字仅示范明确程度，不是通用模板。

| 节奏选择 | 必须落下的决定 | 可核对的示例 |
|---|---|---|
| 快切（rapid cutting） | 哪一段密集换镜、共多少秒多少镜，切换的对象或动作怎样推进。 | “这5秒在解锁与逼近两线间交叉剪辑，共5镜，平均1秒一镜，门锁弹开时结束。”全部2—3秒不能只贴“快切”标签。 |
| 加速剪辑（accelerated editing） | 从哪个事件开始加密，按哪些阶段逐步缩短镜长，到哪里达到峰值。 | “逼近的6秒分三轮交叉：先3秒2镜，再2秒2镜，最后1秒2镜。”不是靠人物跑得更快来冒充剪辑加速。 |
| 减速剪辑／节奏缓落 | 从哪个事件开始减少切换，用哪些更长的镜头承接后果。 | “脱险后的6秒依次用1、2、3秒的3镜，最后一镜留到喘息回稳。”不把演员停顿和每镜用满3秒当成减速方案。 |
| 等节拍剪辑 | 在明确区间按相同镜长反复切换，节拍与哪组已有事件相配，何时打破。 | “敲门的4秒切4镜，每镜1秒；敲门停后接一镜3秒的等待。”只有采用了持续等节拍，等长镜头才是设计结果。 |
| 保持既定长镜／高阶镜，前后改变密度 | 标出连续效果的起止时刻，一镜不切；前后普通区间另定节奏。 | “前5秒5镜快切，进入H01后连续6秒不切，效果完成即接2秒2镜反应切换。”长镜由上游采用，05不能为绕开3秒上限自行增加。 |

本项目用“区间秒数＋镜数＋组织次序／节奏转折”把采用方案变成可执行结果；并无适用于所有影片的快慢秒数定律。实际落点要符合台本与连续行动：不能先填节拍数字，再编动作凑数；也不能以“观众需要确认”为由把任何事件都一律延长到3秒。

## 从导演台本选到采用方案

先认出02采用的观看机制，再选方法；同为“紧张”也可能分别需要连续等待、两线交替或突然快切，不能从情绪词直接套速率。以下是候选比较路径，最终只能留下本段采用的那一条。

| 上游实际采用的拍法／事件关系 | 应作的剪辑决定 |
|---|---|
| 新场地必须交代、职业操作必须辨认 | 以连续性剪辑组织已定地标、操作和证据，具体采用视线匹配或插入；给出这段实际秒数与镜数，保留已经明确的辨认内容。不能因是交代段就自动每镜3秒。 |
| 同场对话或对抗，关键是对方在话中的变化 | 选正反打、反应切换与必要J／L切，确定哪些话跨切、何时回到说话者；按实际互动给出密度，不把对白逐句分镜或排成说完才反应。 |
| 两条行动线分别推进，迫近或相遇产生压力 | 采用交叉剪辑，定返回顺序与各轮密度；02要求越逼越紧时明确采用加速，并给出各轮秒数、镜数，不能只保持等长轮换。 |
| 同一场追逃／冲突，连续变化要求紧迫切换 | 在动作连续性内采用动作匹配快切，先选一段具体密集区间，再定镜数和交接。接触与必要后果仍须可见，不能把完整动作都拆成各自从头开始的碎片。 |
| 悬念由持续同框、人物未察觉或画内慢变化成立 | 保持02已定连续观看，按其时长一镜不切；前后区间另选方法。不为“悬念”一词擅自插线索、切反应、改成加速。 |
| 突发之后转向后果、耗损或短暂松弛 | 在既定突发点硬切／突切或结束快切，后段采用减速或保持已有连续镜，给出变化前后的实际镜长安排；不能只在文字里写“缓一口气”。 |
| 既定时间压缩、回忆、梦境或跨时空对照 | 依已经采用的时间关系选择省略蒙太奇、平行剪辑、跳切或匹配转场，再定各部分密度。不能借方法新增这些叙事结构。 |

## 采用决定的写法

下面各段是相互独立的虚构例子，假定行动和拍法均已有上游依据。实际交付在段首这样写，然后逐镜展开与之吻合的时码和切点，不复制解释表。

**【门内解锁，门外逼近】**

这6秒采用交叉剪辑，在门内解锁与门外逼近之间交替三轮，共6镜。第一轮3秒2镜，第二轮2秒2镜，最后一轮1秒2镜；每轮先看锁的进展，再回到继续逼近的人。脚步贯穿门内画面，锁舌弹开的声音先进入最后一镜，下一段再接门打开。

**【追逃转为耗竭】**

前7秒保留H02一镜不切。随后6秒采用动作匹配快切，共8镜，依次0.5、0.75、0.75、0.5、0.75、0.75、1、1秒；每次避让、拉拽和落脚在切换中连续推进。转入边退边问答后，17秒采用正反打与L切，共8镜，依次1.5、2、2、2、2.5、2、2.5、2.5秒，句尾留在听者反应上。全段30秒17镜。

这类方案的判断顺序是：方法是否真正组织了台本中的对象与行动，节奏是否配合02采用的拍法，镜表是否实现已定次序和密度。数值相加正确只解决最后一部分；与台本无关的方法或不可能执行的快切，数字再整齐也不成立。06读取整段方法与切点后，按[镜头设计执行指令](../../novel-director-06/references/从剪辑方案到镜头设计.md)先完成适应该密度的取景主次与相邻画框。动作连续或两张图相似不能单独证明05切错；仅在明确既定密度与必须呈现内容的冲突、且无法在06职责内解决时，才反馈05统一修订方案与切点，不由06默默放长或07另改一版时长。
