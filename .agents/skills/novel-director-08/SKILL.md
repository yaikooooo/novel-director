# 08｜分段声画提示词

**08先结合上游与实际分镜判断哪里需要强化，再创作、补全和强化具体表演，写成连续声画。** 情绪须通过人物做出的行为、当句声气和彼此回应充分表现；同框其他人物与环境也有连贯的活动和状态。

沿[分镜设计职责与交接](../novel-director-06/references/分镜设计职责与交接.md)，02／04提供动机、情绪走向、关键行动及关系。08可在这些依据内创作尚未展开的具体行为、反应和声气，已有明确决定继续继承。补充表演须符合角色、镜长、实际取景、走位、持物接触及代表状态；改变剧情事件、关键行动或情绪走向交02／04，改剪交05，改画框交06，改运镜交07。

## 输入与独立执行

正式制作按[阶段完成条件](../../../AGENTS.md#如何推进)，同一完整范围的06、07依次完成且必要版本同步后开始08。分段是正文组织方式，不能挑材料齐全的段提前替代完整上游。局部单测与已完成制作单元的修订按用户指定范围及有效输入执行。

新写、重跑和整稿改写由主Agent委派独立上下文的08执行者。只交项目与章节路径、有效输入版本、用户要求与已有确认、可改文件和停止点；执行者自行读取原件，不兼做上游或平台操作。具体调度沿[主Agent](../../../AGENTS.md#调度与交付边界)。

读项目说明（如有），按下表取得本次范围及必要相邻段的有效内容：

| 输入 | 使用内容 |
|---|---|
| 04 连续声画走戏 | 段号、银幕起止时间、连续事件、表演方向与当场状态、关键行动和话语的先后／同步、声源及段末状态。 |
| 02 导演台本 | 台词、OS和叙述原词，说话对象、情绪走向及已定强度、潜台词与回应；基础拍法和H点的表达任务。 |
| 03 角色与资产 | 母本用于认人；当场服装、妆造与状态取对应剧情变体，不把母本展示服写成出演服装。声线取03已确认的角色绑定及项目资产库内样音，直接复用、不重复询问，结合既定表演方向；候选或缺确认依据的旧绑定交03提审，不另选或当作已定声线。 |
| 05 剪辑与共用JSON | 镜序、镜长、切点、声音起止与同步点；sound_cues.cue_ref关联同一声点，只有source_ref时沿引用读取02／04原词。 |
| 06 正式分镜与采用决定 | 按镜序实际打开各镜board_art最终采用图，连同前后镜确认在场人物、可见身体范围、姿态、头身朝向与目光目标、持物、遮挡、环境元素及代表时刻，建立附件对应；图像决定表演在哪里、通过什么能被看见。附件取最终采用图，故事板、第二轮原生单张和未采用试片不能替代；历史交付沿有效原件。 |
| 07 运镜及motion_design | 固定或运动、触发、路径、速度、停顿、焦点和动态光影，以及高阶效果必需的配合；作为执行依据，不把逐镜原文当08底稿。 |

以04的银幕段落为单位，一段可以包含多镜。05／07须与有效设计版本一致；普通单镜不超过3秒，已确认长镜与高阶沿同步后的时长。04／05时间冲突或缺必要原词、附图、运镜时，集中列出具体缺口及负责步骤，补齐受影响输入后成文；不把08的新创作当作补齐上游。上游完整交付后的局部修订只同步受影响内容，等价用户材料可替代步骤文稿。

读取正式图是为了落实表演与附件对应，沿用[06图像审核优先级](../novel-director-06/SKILL.md#图像审核优先级)的独立放行结论，由主Agent核对对应版本及完整范围，不能以制作方自述或局部通过替代。P3可选调整不阻断写作，P4不重新列问题；只将新发现的明确P1／P2证据集中交回06处理受影响镜头，不启动整章图像复审。

## 先贯通表演，再写声画

资料齐备、开始写正文时，先读[用户原始范例与完整交付示例](references/自然语言提示词示例.md)。原始范例是成文标准，完整示例展示如何保留这种写法并加入逐镜引用；不套用示例剧情、人物或音乐。

1. **先找需要强化的地方。** 读02／04中人物要达成什么、受什么触动、情绪如何变化，并对照本镜及相邻正式图。辨明哪些地方只写了情绪名称，哪些动作还没显出态度、转折或冲突，哪些听者和同框人物缺少回应；据此决定本段重点补强什么。已有充分表演直接继承，判断留在内部，正文只交采用的表演。
2. **创作能演出来的情绪发展。** 依据人物性格、关系和现场处境，选择有表现力的行为，让情绪在动作幅度、速度、姿态、表情和声气之间相互带动，充分释放上游要求的强度。动作须有具体对象、做法及衔接，台词随意图写出当句说法；可以边说边做、突然变势或延续一个反应，不套“看向—眉动—嘴角—台词”的顺序。不用比喻或抽象心理代替表演，也不把捏拳、敲一下、按压物件等当通用情绪动作；原剧情明确需要的动作保留。强化来自符合人物的表现与变化，不靠每镜追加小动作、统一提高音量或把全员演成同一种激动。
3. **让整幅画面持续发生。** 依实际取景写主表演，并简洁交代画内其他人物正在怎样听、做和回应；多人同一活动可合写，活动随主次组织，不逐个轮流表演。已有风、水、烟雾、机械等延续符合现场的运动，受动作牵动的衣发和道具自然跟随；静物维持其状态，不为凑动态凭空加风、加人或挪动物件。近景看不到的动作不能承担可见情绪，遮挡人物按可见部位或已有声源表现。台词逐字保留，OS标“内心独白（OS，无口型）”，画外对白保留现场身份。跨镜续句只发声一次，跨段沿既有词界接续；持物、接触、并行与声音落点沿04／05，环境音、呼吸和动作声穿插在发生处。
4. **把既定摄影接到表演上。** 按07写固定或运动及触发、发展和落点，保留高阶光学、焦点交接、持续清晰与光影揭示所需配合；同场光色沿06固定基准及04已定变化，不随情绪强化另写一套冷暖。参考图是代表时刻，表演应自然经过它所示状态，前后可以发展；静态布局由图承载，不把一张图的姿态冻结成整镜，也不为新动作改机位、挪人或越出既定拍法。
5. **正面写正在演什么。** 将上游防错措辞转成实际动作和状态，例如“镜头不推近、不摇动”写成“镜头固定”，“不重复落笔”写成“笔轻触桌面，响了一声”。正文不叙述未发生的行为，不夹纠错理由、制作流程或校验结论，也不逐镜复述未变的物件和光色。每镜开头必须写明镜长；镜内具体秒点只在决定同步或已授权拆分接续时写入，不拆成逐秒动作清单。

## 交付格式

只维护章节内的`08_分段声画提示词.md`，文首简记有效来源链接、版本与范围，不另建JSON、网页或过程报告。每段依次给出：

1. 段号、段名、04起止时间与时长、覆盖镜号。
2. 附图清单：镜号、@图片N、最终单张原件的有效相对链接；额外资产或音频另注用途，附件号按本段上传顺序管理。
3. 一份可整体复制的正文：首行“不要背景音乐，不要字幕。”，随后写段长和必要角色／参考映射。声线以实际样音固定，只在实附时写简短的“@音频1 对应角色某某／@图片N”，不写声线ID、样音版本或重复的音域、音色与人物声线总述；这些资产信息沿用03与资产库。当句语气、情绪、呼吸和表演写在发生处并保留。在第一镜及每次切镜处就近写“镜头S001，时长2.5秒，分镜参考 @图片1”或“切到S002，时长1.5秒，分镜参考 @图片2”，接该镜连贯声画。每镜时长从05当前有效帧段（首末均计入）及项目帧率换算，保留分数秒，不自行取整、平均分配或改变切点；不能只在段首或附件表写时长。同镜内发展沿用当前引用，纯黑段按既定时序写黑场。

环境底声、音效、对白、OS与呼吸按既定设计保留；原稿若依赖配乐，交01／04改定听觉方案。@图片是待绑定标记，平台绑定同一原件后才算上传；只有实际附了样音才写@音频。完整输出见上述示例，正式交付替换为本段真实内容与原件链接。

## 一次合并核对

执行者提交前对照原件与用户范例核对一次：

- **先看表演。** 找出的表演缺口是否已补强，去掉情绪标签和比喻后，实际行为与声气是否仍有足够力度和人物差异；是否反复套用同一反应或用无关小动作填空。对照实际图确认主表演可见、同框其他人物及应持续活动的元素已有交代，彼此回应和跨切进度连贯。
- **再看继承。** 原词、事件与动作终点、先后和并行、镜序时长、运镜与必要光学关系完整；每镜正文均有明确时长，逐镜数值、切点和段总长与05有效数据一致；代表图、逐镜标记与附件一致，段首限制齐全。源稿与正式图冲突交原负责步骤，不能自行改写一套现场；数据校验不能替代文字与图像对照。

文末只简记核对范围与必要待办，不把文字通过称作配音或视频已验证。主Agent只核对交接、范围和代表段落，不另起整章复审。单步交付后停，连续委托沿主Agent范围交接；章节汇报按需调用[09](../novel-director-09/SKILL.md)。
