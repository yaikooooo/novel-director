# 08｜分段声画提示词汇总

本步把分散在各文件里的已有设计汇成连贯的自然语言，交给同时拿到分镜图的执行者。**先读 04，以它确定每段的事件范围、时长和篇幅，再合并其他文件。** 一段可以包含多个分镜，保留原来的切换与运镜；不按单镜另拆一套段落，也不把多个镜头改写成一个长镜头。

无论单独调用、连续制作还是重跑，本步都由主 Agent 委派给一个新建、独立上下文的子智能体执行。执行者只接收当前项目与章节、有效原件路径和版本、用户约束、输出文件与停止点；不继承整章生产对话，不兼做上游制作或平台铺节点。

执行者在开始写正文时必须读取[用户提供的自然语言示例](references/自然语言提示词示例.md)，不能只看 Skill 中的概括或主 Agent 转述。学习其中动作、声音、对白与摄影机响应相互穿插，以及情绪、语气、态度如何随交谈变化；不能只学自然段形式或删掉时码。场景、人物、台词和情绪仍取本次材料。完成必要资料读取后即写本步，不在示例与正文之间穿插其他步骤。读取成功只代表拿到材料，提交时还要核对写法与表演是否落实。

## 从04确定段落，再取各文件的有效内容

先确定用户指定的项目、章节和范围，读项目说明及当前 `04_连续声画走戏.md`。采用 04 的段号、起止时间、连续事件及段末状态，一段交付一份完整提示词。这里的“篇幅”是该段承担的行动与时间长度，不是统一字数。根据段内事件密度写够所需内容，不为凑长短添加表演。

| 输入 | 汇入什么 |
|---|---|
| 04 连续声画走戏 | 段落边界、银幕时长、人物与物件状态、动作先后、声源、听点、环境音效及跨段承接。 |
| 02 导演台本 | 台词、OS／心声、画外叙述的完整原词，说话对象、语气、情绪与表演依据。 |
| 03 资产引用及角色卡 | 附图中的角色身份、当场造型／状态和已配置的声线、表演方向；仅取本段需要的内容。 |
| 05 剪辑时码及共用 JSON | 本段覆盖的镜号、镜内时长、动作锚点、切点和声音起止；通过 `sound_cues.cue_ref` 取 `design.sound_timeline` 的原词与声源，不能只抄声音ID。 |
| 06 正式分镜原件 | 确认实际附图、人物身份、镜号及图中状态。静态构图由提供的分镜承载，不在正文重写。 |
| 07 运镜提示词及 `motion_design` | 采用的固定、推拉、摇移、跟随、焦点变化，运动触发、先后、速度与停顿。合并成段内叙述，去掉重复的静态构图说明。 |

05／07 必须与本次有效设计版本相符。04 决定段的篇幅，05 负责段内精确声画时间，两者相符后使用。04 若另列未经剪辑的走戏时间，采用它明确标出的银幕段落时间；若与 05 有冲突，集中指出具体段号和差异，不自行改段长、剪台词或挪动动作。跨 04 段界的镜头按实际重叠时段关联，并保留动作进度。

局部委托只汇总对应段落；用户指定截取时注明截取区间。缺少本段必要的台词、分段时长、实际附图或运镜时，列明缺口，可先完成材料齐全的段，不把缺失部分臆写成已定设计。等价的用户指定材料可替代步骤文稿，不要求重跑上游。单镜最多 3 秒仍适用于 05 的摄影镜头，08 的段落总长沿用 04，不套用 3 秒或某个平台默认片长。

## 每份提示词最上方写清限制与附图

每个可独立复制的提示词都以这句开头：**不要背景音乐，不要字幕。** 环境音、动作音效、台词、OS 和呼吸等非音乐声音按已有设计保留。示例或上游稿出现背景音乐时，本步按这条要求不纳入背景音乐；不把对白改成字幕。

随后按本段实际附件顺序写 `@图片1`、`@图片2` 等，每项明确是谁或是什么、参考用途。例如角色形象、场景，或覆盖哪些镜号的分镜图。多宫分镜还要说明格位与阅读顺序；人物图不能误写成首帧，组页不能当成一个连续画面。每段的编号与本段交付的附图清单一致，可从1开始编号。

查看实际原图再命名，不能仅凭文件名猜角色或格位。附图清单链接正式原件，使用相对于交付稿的有效路径；公共资源按其实际位置相对引用。提示词中的 `@图片` 标记是附件对应关系，不代表已上传到外部平台。采用声线时，用角色卡已有的音色与表演方向自然说明；只有实际提供了音频参考才写 `@音频` 对应项。

## 写成连贯的自然语言

- 正文直接呈现正在发生的声画：谁带着怎样的情绪做了什么、怎样对谁说话、对方受到什么影响、传来什么声音、摄影机如何随之响应。每个自然段围绕一个连续行动或反应展开。制作流程、校验结论和操作注意事项不夹进声画叙述；能指导当前表演的心理意图、人物态度与关系必须保留，并落实在声音、表情或动作上。分镜已有的静态信息不再逐项转述。
- 精确时码是写作依据，不能把每个切点都译成“第几秒切……”充当正文。总时长放在顶部；普通切换用动作、台词落点或声音自然衔接，保留05镜序与07运动。只有不写秒数就会改变执行的同步点、回忆边界或已授权的平台拆分接续，才在相应位置写必要的段内时点，不添加一串时间标签。
- 用实际状态承载连续性，例如“他的声音从画外继续传来”“她的嘴角一直僵着”。不要反复写“口型随现场话语”“不在换镜时重起”“把方向交给下一段”“按既定切点执行”等制作说明。明确说话人及现场对白即可表达正常开口说话；OS、无口型和特殊声画关系仍须写清。关键禁令若无法由状态表达、且会改变剧情，简明保留。
- 按 04 的事件顺序写谁先动、如何接触或移动、谁作出什么反应，以及段末留下什么状态。区分左右手、持物和视线对象等影响执行的关系；动作必须写到已定终点，不能用“接近”替代“触碰”。
- 把镜头响应接在触发事件上，例如人物停手后相机才靠近、听见画外声后切向反应、人物向前时镜头克制后退。沿用 07 的采用决定；固定或运动写清。05 已定的镜头切换用自然的“切到……”“接着……”衔接，保留必要时点，不另排镜序。
- 台词逐字保留并加引号，点明说话人、已有语气和对象；角色不在画面时说明声音来自何处。OS 写为“某人的内心独白（OS，无口型）”；独立的画外叙述按原声部说明，不能因为声音在画外就改成心声。
- 同一段里跨镜延续的台词或 OS 只完整写一次，在对应动作间交代延续、停顿和落点。跨段声音按已有边界注明接续，不能每段从头重说。若只有整句帧段而没有跨段的词界，不凭平均语速伪造精确断词；保留已知衔接并指出尚待明确的位置。
- 环境音、动作声、呼吸、笑声等穿插在实际发生处，保留声音与动作的先后、同拍关系及远近变化。关键同步点沿用 05，必要时换成本段内秒数，不留下“按既有锚点”“沿用心声”这类必须翻其他文件才能理解的指令。
- 不复述景别、静态机位、焦距、画幅比例、画框布局和静态光影。分镜已经提供这些信息。保留动作与运镜必需的方向、主观视角、焦点交接、遮挡显露和真实动态光影变化，避免因删去构图文字而丢失动作因果。
- 正文采用自然段，不写成“动作：／台词：／运镜：”的分栏清单，不把制作分析或内部字段名塞入提示词。长短由本段内容决定；示例中的泳池、暧昧语气和音乐不套进其他剧情。

## 情绪、语气与人物反应的注意事项

- 写前从02的表演与潜台词、03角色卡及04当场状态确认：角色此刻想让对方做什么、在掩饰或压住什么、听到回应后如何变化。用已有剧情支撑表演强度，不凭空增加人物动机、哭喊、接触、台词、音效或新的摄影运动。原件确实缺少依据时说明具体缺口，不把一律平静或一律激烈当作补齐。
- **声线身份与当句语气分别落实。** 段首的“成年低男声”“气息略弱”只说明稳定的声音身份；正文中的关键台词仍需交代当时的态度与声气。按该句需要，选择语速、停顿、重音、声量、气息或尾音等可听细节，贴着对应台词自然叙述。不要反复复制“客气逐渐变冷”代替段内变化，也不要给每一句机械堆满形容词。
- **动作与表情带着情绪发生。** 抬眼、前倾、停手等已有动作，写清是在试探、请求、压制、退让或其他有原件依据的状态下发生；让眼神、眉口、姿态或呼吸相互配合。厘米位置和物件状态不能占满正文，把人物写成只执行走位的身体。克制的表演仍须有明确态度，不能只写音量平稳。
- **情绪要随往来推进。** 在关键对白与反应处体现“对方刚做了什么／说了什么，角色因此怎样听、怎样回应”。长台词按已有意群写出态度与声气的变化，同一人的下一句可能是在掩饰、争取或结束谈话，不能用一个“急切”“冷冷”包住整段。沉默也应带着具体的等待、受挫或回避，不只记录闭嘴和站定。
- **表演意图不是应当删除的制作解释。** 用户示例的“带着看破不说破的笑意”“体现出男子的从容与防备”，都在说明可执行的态度与人物关系，应学习这种写法。禁止的是“这样设计为了让观众理解”“此处完成信息交接”等制作论述；不要把与声画相连的心理意味一并删掉。
- **OS与低声也要有当下情绪。** 标明OS身份与无口型后，仍按原件写出它是安稳盘算、压着担忧还是试着抓住希望等当时状态；“贴近”“低声”只描述声场或音量，不能独自承担情绪。不要擅自把OS变成对旁人可听的发言。
- **镜头响应服务于正在发生的表演。** 沿用07的实际运动，让它跟住一次迟疑、退让、逼问或其他既定变化。按需要简明写出与动作相连的心理关系，不反复以“迟半拍—轻靠—停住”替代人物表现，也不为了情绪另加运镜。
- 重写时先贯通段内表演，再组织动作、声音与镜头。不能只删时码、换连接词，或在旧稿的“他说”前加一个情绪词就认定符合示例。正文要能让执行者读出角色当下怎样说、怎样听、为何作出这一反应；这些提示须与本次台本相符。

## 交付与一次核对

只维护本章的 **`08_分段声画提示词.md`**。文首简记所用 04／02／03／05／07 文件链接、有效数据版本及本次范围，作为来源；每段按以下顺序交付：

1. 段号、段名、04 的起止时间与时长、覆盖镜号。
2. 本段实际附图清单及原件链接，与提示词里的 `@图片` 逐项对应。
3. 一个可整体复制的文本块：首行“不要背景音乐，不要字幕。”，随后是参考图说明、本段时长，再接完整自然语言正文。

本步从上游原件汇总，既有 `design` 与 `motion_design` 仍是设计来源；不另建重复的 JSON、独立网页或过程报告，不回写上游设计。共用阅读器通过“章节文稿与原件”读取此 Markdown。

提交前由执行者集中对照一次，同时核对内容、写法和表演：段落与时长是否对应04；动作终点、台词／OS原词、声源和必要同步点是否完整；镜序与运镜是否沿用05／07；段首限制及附图映射是否齐全；对照用户示例，关键台词是否有当句的声气与态度，已有动作是否承载人物情绪，对方的回应是否带来可辨的变化，长台词和OS是否也有具体表演。不能只凭段首声线说明、零星情绪词或自然段形式判定通过；同时排除密集秒数、机械逐镜列举和制作解释，避免无依据地加戏。数据校验通过不能代替这次文字与表演核对。核对范围与待办简记在文末，不能把文字核对标成实际配音或视频已验证。已有冲突一次列出负责步骤，不循环审核、修改再审核；主 Agent 只查看代表段落，不另发起整章复审。

单步委托交提示词后停；章节汇报与交接按需交 [09](../novel-director-09/SKILL.md)。
